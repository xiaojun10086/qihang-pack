# 考前冲刺

## 执行前置

- 本文所有包内相对路径均以本 `SKILL.md` 所在目录为基准，不以用户当前工作目录（cwd）为基准。
- 执行任何业务步骤前，先完整读取并遵守 `../using-qihang/SKILL.md` 中的共享行为准则及安全兜底，再完整读取 `../../config.yaml`。这里只加载共享规则和配置，不重复总入口路由。
- 本会话已完整加载上述文件时可复用；必需文件不可读时，停止本包执行并说明缺失或不可读的文件，不猜测规则。

## Overview

基于已知考点和剩余时间，给出当天就能开始的复习安排；只补问会改变计划的关键信息。

## When to Use

考前一周内的复习安排、突击计划、开卷考试索引。**不适用**：从零系统学一门课 → `faster-cycle`；长期记忆排程 → `recall-schedule`。

## 执行流程

### 冲刺安排

1. 复用用户已给的信息；不知道考试范围时，不编造考点。
2. 若考试临近，先给今天可执行的复习块；需要整段计划时再依据剩余时间倒排。
3. 每个复习块结合主动回忆、针对性练习和错题回顾；安排应适配用户可用时段。
4. 仅当范围或时间会明显改变建议时，提出一个最关键的追问。
5. 可附 1–3 道短练习或请用户发一道错题，以反馈调整后续安排。

**两档方案**：

| 档 | 适用 | 结构 |
|---|---|---|
| 突击 3 步 | ≤6 天 | 高频考点 → 针对性练习 → 错题回炉 |
| 系统 7 步 | ≥7 天 | 通读 → 分章 → 做题 → 小结 → 模拟 → 补漏 → 复盘 |

**判定顺序**：先判剩余时间够不够走系统档，不够则走突击档 → 再判考点范围是否明确，不明时先补一个最关键的追问 → 最后才排今天可执行的那一块。

### 开卷索引

1. 确认考试是否开卷、可带资料范围（问清规则）
2. 按章节 / 考点归成 8–12 个检索块
3. 每块只放「触发词 → 公式 / 定理编号 → 页码」
4. 加一页「常用结论 + 易错条件」速查
5. 用一份真题演练检索速度，删掉查不到的项

**索引粒度判据**：一个检索块 =「一类问法」。太粗会翻不到，太细会查不完。

| 块内字段 | 作用 |
|---|---|
| 触发词 | 题干里可能的措辞 |
| 公式 / 定理编号 | 直指结论 |
| 页码 | 一处定位，不写两处 |

**验收**：随机抽 5 道真题，全部能在 30 秒内定位 → 索引合格。

**判定顺序**：先判考试是开卷还是闭卷，闭卷改走记忆排程 → 再判检索块按哪类问法切 → 最后才填触发词、编号与页码。

## 常见误判

### 冲刺安排

- ❌ 把「才看到第 3 章」当复习进度 → ✅ 那是范围信息，决定主攻哪几章，不是节奏
- ❌ 剩余天数不明就按系统档排满 → ✅ 先定剩余时间，突击档与系统档的结构完全不同
- ❌ 把「帮我讲这道题」当冲刺计划 → ✅ 单题讲解不属本 skill，应改走讲解路径
- ❌ 把「背不下来」当计划问题 → ✅ 先分「没理解」与「理解了但记不住」，后者才排间隔重复
- ❌ 一次性排完整段计划 → ✅ 先给今天可执行的一块，再按反馈细化

**纪律**：只有在模拟练习对当前目标有帮助时才出题；不代考、不买卖答案。

### 开卷索引

- ❌ 把「闭卷要背下来」当开卷索引 → ✅ 闭卷属记忆排程，索引解决不了背不下来的问题
- ❌ 按章节顺序做索引 → ✅ 按「一类问法」切块，按章节切会翻不到
- ❌ 一个知识点写多个页码 → ✅ 一处定位只写一处，多写反而当场选不出来
- ❌ 索引只写公式名 → ✅ 块内要有题干可能出现的措辞，否则临场对不上词
- ❌ 做完不试抽 → ✅ 要拿真题抽验定位速度，抽不出来就说明切块太粗
