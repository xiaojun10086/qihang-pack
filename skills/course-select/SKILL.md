# 选课与培养方案

## 执行前置

- 本文所有包内相对路径均以本 `SKILL.md` 所在目录为基准，不以用户当前工作目录（cwd）为基准。
- 执行任何业务步骤前，先完整读取并遵守 `../using-qihang/SKILL.md` 中的共享行为准则及安全兜底，再完整读取 `../../config.yaml`。这里只加载共享规则和配置，不重复总入口路由。
- 要查开课清单时，另需完整读取 `../../references/dlut-field-map.md`，按其中的字段与取数口径执行，不凭记忆推断系统里的字段名与分类。
- 本会话已完整加载上述文件时可复用；必需文件不可读时，停止本包执行并说明缺失或不可读的文件，不猜测规则。

## Overview

做对照与提示，逐项标来源；要实际选课则转 `portal-operator` 代操作，提交前先复述待选课程。

## When to Use

选课规划、学分缺口核对、培养方案解读。**不适用**：教务系统的实际操作 → `portal-operator`。

## 执行流程

1. 取本专业培养方案与自己的已修成绩单
2. 按必修 / 限选 / 任选三类逐项打勾，算学分进度
3. 列出待修缺口与开课学期
4. 确认选课 / 退补选时间节点（以教务通知为准）
5. 输出核对表与时间节点（学分口径、方案与通知均标来源）；用户要实际选课 → 转 `portal-operator` 代操作，提交前复述待选课程

**学分核对口径**：

| 类别 | 判据 | 常见坑 |
|---|---|---|
| 必修 | 方案标「必修」 | 同名不同课的学分不互认 |
| 限选 | 需在方向模块内选满 | 选够门数但不在模块内 |
| 任选 | 总量达标即可 | 重复算同一门 |

**时间节点**：选课、退补选、重修报名三者窗口不重叠，逐个记。

**开课清单从哪来**：公开网只有选课工作安排通知，**没有开课目录**；逐门课的开课情况（开课单位、任课教师、时间地点、容量与余量）只在综合教学管理系统的「公共服务与查询 → 全校开课查询」内，属需登录数据，由 `portal-operator` 接入读取（入口取 `../../config.yaml` 的 `school.entry_jwgl`；落地路径形如 `/student/for-std/lesson-search/index/<入口ID>`，入口 ID 每次不同、不写死，点开后新开一个标签页）。接口、字段与取数口径见 `../../references/dlut-field-map.md`。

**两条口径**：① 系统里**没有「人文类」这类字段**，课程性质只有通识类课程 / 全校选修类课程 / 素质课程 / 专业课程等；要出人文类这类清单只能按**开课单位 + 课程名**人工归类，交付时必须声明是人工归类。② 网络通识课按**课程号以 `y`（尔雅·超星学习通）/ `z`（东西部联盟·智慧树）结尾**识别，线上学习、不排课。通识课、网络通识课、创新创业教育课、全校公共选修课**每学期各最多选 2 门**，且补退选窗口通常在 9 月中截止，过点只能找本学院教务老师或教学运行保障中心运行管理室。

**登录判断**：先判要用的数据在哪——培养方案与教学运行保障中心的选课工作安排通知 公开可查，直接给；**开课目录与逐门课程清单并不在公开栏目**，它连同个人成绩单、课表、选课与退补选入口 需登录，转 `portal-operator`。需登录时按 `../using-qihang/SKILL.md` 共享行为准则第四条给出登录要求（**先给最快捷做法**：让用户用专用配置目录加 `--remote-debugging-port=0` 启动一次，登录一次即长期免登录，端口写入该目录的 `DevToolsActivePort`；用户本人用**自己的浏览器**登录，本包不代开浏览器、不代填凭证；要本包直接操作页面需带调试端口启动，用户确认已登录后本包才接入）；完整流程见 `../portal-operator/SKILL.md`。

**判定顺序**：先判是不是「代登录 / 代选课」请求（是则转 `portal-operator` 代操作，先给核对清单）→ 再判学分缺口属必修 / 限选 / 任选哪一类 → 最后才排选课顺序与时间节点。

## 常见误判

- ❌ 把「帮我登录把课选上」当规划 → ✅ 转 `portal-operator` 代操作，先给待选清单，提交前复述课程
- ❌ 只算总学分不分类别 → ✅ 必修、限选、任选三类各有判据，总量达标不等于满足方案
- ❌ 同名课当同一门互认 → ✅ 同名不同课学分不互认，逐门对方案号
- ❌ 限选只看门数 → ✅ 限选要在方向模块内选满，选够门数但不在模块内等于白选
- ❌ 把选课、退补选、重修当一个窗口 → ✅ 三者窗口不重叠，逐个记时间点
- ❌ 学分口径与时间节点不标来源 → ✅ 逐项标来源，以官方培养方案与教务通知为准
- ❌ 成绩单、课表、选课入口当公开信息查 → ✅ 这些在教务系统内需登录，先给出登录要求再转 `portal-operator`
- ❌ 到公开网站找「开课目录 / 课程清单」 → ✅ 公开网只有选课工作安排通知，逐门开课情况在教务系统内，需登录
- ❌ 把「人文类」当系统里的现成分类去筛 → ✅ 系统没有该字段，只有课程性质；人文类须按开课单位与课程名人工归类并在交付时声明
- ❌ 用「课程类型」下拉判断网络通识课 → ✅ 该下拉是旧分类，网络通识课按课程号 `y` / `z` 结尾识别
