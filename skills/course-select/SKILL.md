# 选课与培养方案

## Overview

做对照与提示，逐项标来源；要实际选课则转 `portal-operator` 代操作，提交前先复述待选课程。

## When to Use

选课规划、学分缺口核对、培养方案解读。**不适用**：教务系统的实际操作 → `portal-operator`。

## 执行流程

1. 取本专业培养方案与自己的已修成绩单
2. 按必修 / 限选 / 任选三类逐项打勾，算学分进度
3. 列出待修缺口与开课学期
4. 确认选课 / 退补选时间节点（以教务通知为准）
5. 输出核对表与时间节点（学分口径、方案与通知均标来源）；用户要实际选课 → 转 `portal-operator` 代操作，提交前复述待选课程

**学分核对口径**：

| 类别 | 判据 | 常见坑 |
|---|---|---|
| 必修 | 方案标「必修」 | 同名不同课的学分不互认 |
| 限选 | 需在方向模块内选满 | 选够门数但不在模块内 |
| 任选 | 总量达标即可 | 重复算同一门 |

**时间节点**：选课、退补选、重修报名三者窗口不重叠，逐个记。

**判定顺序**：先判是不是「代登录 / 代选课」请求（是则转 `portal-operator` 代操作，先给核对清单）→ 再判学分缺口属必修 / 限选 / 任选哪一类 → 最后才排选课顺序与时间节点。

## 常见误判

- ❌ 把「帮我登录把课选上」当规划 → ✅ 转 `portal-operator` 代操作，先给待选清单，提交前复述课程
- ❌ 只算总学分不分类别 → ✅ 必修、限选、任选三类各有判据，总量达标不等于满足方案
- ❌ 同名课当同一门互认 → ✅ 同名不同课学分不互认，逐门对方案号
- ❌ 限选只看门数 → ✅ 限选要在方向模块内选满，选够门数但不在模块内等于白选
- ❌ 把选课、退补选、重修当一个窗口 → ✅ 三者窗口不重叠，逐个记时间点
- ❌ 学分口径与时间节点不标来源 → ✅ 逐项标来源，以官方培养方案与教务通知为准
