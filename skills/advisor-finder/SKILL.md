# 导师与教师资料

## 执行前置

- 本文所有包内相对路径均以本 `SKILL.md` 所在目录为基准，不以用户当前工作目录（cwd）为基准。
- 执行任何业务步骤前，先完整读取并遵守 `../using-qihang/SKILL.md` 中的共享行为准则及安全兜底，再完整读取 `../../config.yaml`。这里只加载共享规则和配置，不重复总入口路由。
- 本会话已完整加载上述文件时可复用；必需文件不可读时，停止本包执行并说明缺失或不可读的文件，不猜测规则。

## Overview

只查公开信息，逐项标注来源与核验状态，不编造。

## When to Use

了解导师研究方向、查找院系与联系方式、准备联系导师前的背景调查。**不适用**：课程答疑与作业讲解（如「老师讲的没听懂」）→ `explain-stepwise`；学校 / 学院 / 部门 / 机构 / 平台入口等公开信息与联系方式 → `campus-search`；答辩与汇报准备 → `paper-outline`；升学整体规划不在本包范围内。

## 执行流程

1. **锁定检索目标**：明确要查的是「某位具体教师」还是「某方向 / 某学院的教师群体」（群体查询先给检索路径，不逐个罗列）
   ① **教师主页平台** https://faculty.dlut.edu.cn/ ——教师自建主页，方向、成果、联系方式最全
   ② **研究生院** https://gs.dlut.edu.cn/ ——导师信息、**招生简章与流程等公开栏目**（公开栏目只给简章、流程与已公示名单；**个人申请状态、名额余量、录取结果属登录后字段**，见下方「登录判断」）
   ③ **学部学院导航** https://www.dlut.edu.cn/xbxy.htm ——到具体学院官网查「师资队伍」页
2. **信息卡字段**：姓名 ｜ 院系 ｜ 职称（若公开）｜ 研究方向 ｜ 主页链接 ｜ 公开联系方式（若有）｜ 来源与核验状态
3. **核验纪律**（状态只取三档，不混用）：
   - 每个字段标来源 URL 与**访问日期**；多个来源冲突时并列呈现，不擅自裁决
   - 状态三档：**已核验**（本次回源并取到）/ **未核验（来源已登记）**（来源在册但本次未取到页面）/ **信息库未收录**（来源不在册）；不新增第四档说法
   - 未取到的字段**不留空、不猜、不补**；**历史基准不冒充实时**：招生名额、职称、团队等年度数据须标年份，不当作当年实时状态
   - 信息库未收录的站点 → 固定回复「信息库未收录，建议访问 https://www.dlut.edu.cn/ 核实」
4. **群体查询模式**：按方向找导师 → 给「学院师资页 + 教师主页平台的检索入口 + 该学院已知的方向关键词」，由用户自行浏览筛选
5. 输出「信息卡（标注来源与核验状态）」

**导师信息核验分级**：

| 来源 | 可信度 | 用途 |
|---|---|---|
| 教师主页平台 | 高 | 方向 / 成果 / 联系方式 |
| 学院官网 | 高 | 招生方向 / 团队 |
| 研究生院招生栏目 | 高 | 招生名额 / 流程 |
| 论坛 / 二手转述 | 低 | 仅供参考，须回源核验 |

表中「高」只表示来源权威，**不代表实时**；招生名额与职称类数据须标年份，见「核验纪律」。

**登录判断**：先判要查的字段在哪——教师主页平台 / 研究生院 / 学院官网师资页 公开可查，直接给信息卡；招生系统内的个人申请与名额状态 需登录，转 `portal-operator`。需登录时按 `../using-qihang/SKILL.md` 共享行为准则第四条给出登录要求（**先给最快捷做法**：让用户用**独立配置目录**加 `--remote-debugging-port=0` 启动一次，登录一次即长期免登录，端口写入该目录的 `DevToolsActivePort`（**Chrome / Edge 136 起会忽略默认配置目录上的调试端口，必须用独立目录**，理由见共享行为准则第四条）；用户本人用**自己的浏览器**登录，本包不代开浏览器、不代填凭证；要本包直接操作页面需带调试端口启动，用户确认已登录后本包才接入）；完整流程见 `../portal-operator/SKILL.md`。

**判定顺序**：先判是不是「代联系 / 打探非公开名额」请求，是则只给公开信息卡 → 再判来源可信度分级 → 最后才逐项标来源与核验状态。

## 常见误判

- ❌ 把「帮我联系导师问名额」当信息查询 → ✅ 不代联系，也不探非公开名额
- ❌ 论坛转述当依据 → ✅ 论坛与二手转述仅供参考，须回源核验
- ❌ 联系方式凭印象写 → ✅ 只查公开可核验信息，不臆造联系方式
- ❌ 只给结论不标来源 → ✅ 逐项标来源与核验状态，便于用户自己复核
- ❌ 招生名额从非官方渠道找 → ✅ 名额与流程以研究生院招生栏目为准
- ❌ 招生系统内的名额状态当公开信息查 → ✅ 需登录，先给出登录要求再转 `portal-operator`；公开源只给信息卡

**纪律**：只查**公开可核验**信息，逐项标来源与核验状态；不臆造联系方式、不代联系导师。
