# 导师与教师资料

## Overview

只查公开信息，逐项标注来源与核验状态，不编造。

## When to Use

了解导师研究方向、查找院系与联系方式、准备联系导师前的背景调查。**不适用**：升学整体规划不在本包范围内。

## 执行流程

1. **锁定检索目标**：明确要查的是「某位具体教师」还是「某方向 / 某学院的教师群体」（群体查询先给检索路径，不逐个罗列）
   ① **教师主页平台** https://faculty.dlut.edu.cn/ ——教师自建主页，方向、成果、联系方式最全
   ② **研究生院** https://gs.dlut.edu.cn/ ——研究生导师信息与招生相关公开栏目
   ③ **学部学院导航** https://www.dlut.edu.cn/xbxy.htm ——到具体学院官网查「师资队伍」页
2. **信息卡字段**：姓名 ｜ 院系 ｜ 职称（若公开）｜ 研究方向 ｜ 主页链接 ｜ 公开联系方式（若有）｜ 来源与核验状态
3. **核验纪律**：
   - 每个字段标来源 URL；多个来源冲突时并列呈现，不擅自裁决
   - 未在上述来源找到的字段标「未在公开源找到」——**不留空、不猜、不补**
   - 信息库未收录的站点 → 固定回复「信息库未收录，建议访问 https://www.dlut.edu.cn/ 核实」
4. **群体查询模式**：按方向找导师 → 给「学院师资页 + 教师主页平台的检索入口 + 该学院已知的方向关键词」，由用户自行浏览筛选
5. 输出「信息卡（标注来源与核验状态）」

**导师信息核验分级**：

| 来源 | 可信度 | 用途 |
|---|---|---|
| 教师主页平台 | 高 | 方向 / 成果 / 联系方式 |
| 学院官网 | 高 | 招生方向 / 团队 |
| 研究生院招生栏目 | 高 | 招生名额 / 流程 |
| 论坛 / 二手转述 | 低 | 仅供参考，须回源核验 |

**判定顺序**：先判是不是「代联系 / 打探非公开名额」请求，是则只给公开信息卡 → 再判来源可信度分级 → 最后才逐项标来源与核验状态。

## 常见误判

- ❌ 把「帮我联系导师问名额」当信息查询 → ✅ 不代联系，也不探非公开名额
- ❌ 论坛转述当依据 → ✅ 论坛与二手转述仅供参考，须回源核验
- ❌ 联系方式凭印象写 → ✅ 只查公开可核验信息，不臆造联系方式
- ❌ 只给结论不标来源 → ✅ 逐项标来源与核验状态，便于用户自己复核
- ❌ 招生名额从非官方渠道找 → ✅ 名额与流程以研究生院招生栏目为准

**纪律**：只查**公开可核验**信息，逐项标来源与核验状态；不臆造联系方式、不代联系导师。
