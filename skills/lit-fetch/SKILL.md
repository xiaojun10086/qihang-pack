# 文献检索与获取

## 执行前置

- 本文所有包内相对路径均以本 `SKILL.md` 所在目录为基准，不以用户当前工作目录（cwd）为基准。
- 执行任何业务步骤前，先完整读取并遵守 `../using-qihang/SKILL.md` 中的共享行为准则及安全兜底，再完整读取 `../../config.yaml`。这里只加载共享规则和配置，不重复总入口路由。
- 本会话已完整加载上述文件时可复用；必需文件不可读时，停止本包执行并说明缺失或不可读的文件，不猜测规则。

## Overview

开放获取优先，绝不绕付费墙。给出去重后的中文交付清单，每条引文给可核验锚点。

## When to Use

检索式设计、文献筛选、合法全文获取、文献去重、综述方法框架。**不适用**：精读单篇 → `reading-note`；核验引文 → `citation-verify`。

## 执行流程

### 检索到全文

1. **明确需求**：主题、年份范围、目标篇数、语言、是否必须全文
2. **拆检索式**：把题目拆成 2–4 个概念块 + 同义词 / 缩写 / 中英双语
3. **分层检索**：
   - 广泛发现：Google Scholar / Semantic Scholar / OpenAlex / Crossref
   - 中文库：知网 / 万方（经 DUT 图书馆入口访问）
   - 全文入口：DOI 页 / 出版社页 / 开放获取版本 / 预印本 / 作者主页
4. **合法获取全文（按序尝试）**：
   ① 开放获取（OA 期刊 / PubMed Central / Unpaywall 查合法版本）
   ② **DUT 图书馆电子资源**（校内 IP 或校外访问入口——最常用的合法通道）
   ③ 预印本 / 机构仓储 / 作者主页版本
   ④ 馆际互借 / 文献传递（图书馆服务）
   ⑤ 邮件联系作者
   **遇到登录墙 / 403 / 付费墙 → 如实记「暂不可得」，绝不算成功，更不绕过**
5. **状态用中文人话记录**：已下载 PDF ｜ 已存网页版 ｜ 需经学校图书馆 ｜ 建议馆际互借 ｜ 建议联系作者 ｜ 未找到合法全文
6. **去重整理**：按 DOI / 题名去重；每条记录「题名、年份、来源、DOI、全文状态、下一步」
7. 输出「文献清单 + 全文状态表 + 下一步路线」

**合法获取渠道分级**（按优先级，与上文「合法获取全文（按序尝试）」一致）：

| 顺序 | 渠道 | 适用 | 备注 |
|---|---|---|---|
| 1 | 开放获取（OA） | 有 OA 版本 | 认准出版社 / 机构库链接 |
| 2 | 图书馆订阅库 | 已在馆藏 | 走 `lib.dlut.edu.cn`；校外经 WebVPN 需登录 |
| 3 | 预印本 / 机构仓储 / 作者主页 | 有合法预印本或自存档版本 | 与已发表版可能不同，须标版本 |
| 4 | 馆际互借 / 文献传递 | 馆藏缺失 | 走图书馆服务台 |
| 5 | 作者索取 | 通讯作者有公开邮箱 | 附礼貌信模板 |

**纪律**：只走上述合法渠道；**不提供盗版站点（如 Sci-Hub）线路、不给破解下载法**；拿不到就如实说「拿不到」并给下一步合法路线。

**字段口径**：借阅状态等字段（如 `library.on_loan_count`）归本 skill 消费，字段归属与取数口径见 `../../references/dlut-field-map.md` 第一～三节；只读取授权且站点限制允许的字段。

**DUT 特化**：合法获取优先走 DUT 图书馆订阅库与文献传递服务；校外访问走 `../../references/dlut-official-sites.md` 登记的「图书馆电子资源校外访问」入口（`lib.dlut.edu.cn/wxzy1/xwfw.htm`），经 WebVPN 时注意其有 Referer 校验、只能从门户点资源卡进入（见 `../../references/dlut-login-sites.md`）；开发区 / 盘锦校区学生对应分馆服务，馆际互借走本校图书馆服务台。

**登录判断**：先判全文要在哪个源上取——OA / PMC / Unpaywall / 预印本 / 作者主页 公开可查，直接取；DUT 图书馆订阅库（校外需 WebVPN）需登录，转 `portal-operator`。需登录时按 `../using-qihang/SKILL.md` 共享行为准则第四条给出登录要求（**先给最快捷做法**：让用户用**独立配置目录**加 `--remote-debugging-port=0` 启动一次，登录一次即长期免登录，端口写入该目录的 `DevToolsActivePort`（**Chrome / Edge 136 起会忽略默认配置目录上的调试端口，必须用独立目录**，理由见共享行为准则第四条）；用户本人用**自己的浏览器**登录，本包不代开浏览器、不代填凭证；要本包直接操作页面需带调试端口启动，用户确认已登录后本包才接入）；完整流程见 `../portal-operator/SKILL.md`。

**判定顺序**：先判是不是「要盗版 / 破解渠道」请求，是则只给合法路线 → 再判馆藏是否有、是否有 OA 版 → 最后才按渠道分级给获取路线。

### 综述方法框架

1. 明确综述问题（用 PICOS / SPIDER 结构）
2. 设计检索式并在 2–3 个数据库检索、记录命中数
3. 定纳入 / 排除标准，做标题 / 摘要 / 全文三级筛选
4. 画 PRISMA 流程图并记录各阶段数量
5. 给偏倚风险评估工具与数据提取表模板

**PRISMA 各阶段必录数量**：检索命中 → 去重后 → 标题筛选 → 全文筛选 → 纳入。

| 结构 | 适用 |
|---|---|
| PICOS | 量化 / 干预类问题 |
| SPIDER | 质性 / 经验类问题 |

**判定顺序**：先判需求是「方法框架」还是「帮我找文献」（后者走本 skill「检索到全文」的常规流程）→ 再判问题类型选 PICOS 还是 SPIDER → 最后才排检索式与各阶段记录。

## 常见误判

### 检索到全文

- ❌ 把「给个免费下载站」当检索需求 → ✅ 盗版渠道一律不给，只给合法路线
- ❌ 拿不到就说到此为止 → ✅ 拿不到要如实说明并给下一步合法路线
- ❌ 跳过图书馆直接找作者 → ✅ 按渠道分级逐级走，OA 与馆藏优先
- ❌ 作者索取不写信 → ✅ 作者索取要附礼貌信模板，否则多半不回
- ❌ 校外访问不走学校入口 → ✅ 校外访问走学校 VPN 登录图书馆电子资源入口，需登录就先给出登录要求
- ❌ 图书馆订阅库当公开入口直接给 → ✅ 校外访问需登录，先给出登录要求再走 WebVPN 入口，或转 `portal-operator`

### 综述方法框架

- ❌ 把「帮我找几篇相关文献」当综述需求 → ✅ 普通检索不属于本流程，走本 skill「检索到全文」。
- ❌ 结构选错 → ✅ 量化 / 干预类用 PICOS，质性 / 经验类用 SPIDER，混用会让筛选标准无从落地。
- ❌ 只给流程图不记数量 → ✅ 任一阶段缺数量即不可复现，必须退回补录。
- ❌ 先筛后定标准 → ✅ 纳入 / 排除标准须在筛选前锁定，事后改标准等于重做。
- ❌ 把范围综述当系统综述 → ✅ 范围综述不合并效应量，别套用系统综述的偏倚评估口径。

**判据**：流程图任一阶段缺数量 → 该综述不可复现，退回补录。
