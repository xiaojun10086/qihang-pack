# 课堂与笔记整理

## 执行前置

- 本文所有包内相对路径均以本 `SKILL.md` 所在目录为基准，不以用户当前工作目录（cwd）为基准。
- 执行任何业务步骤前，先完整读取并遵守 `../using-qihang/SKILL.md` 中的共享行为准则及安全兜底，再完整读取 `../../config.yaml`。这里只加载共享规则和配置，不重复总入口路由。
- 本会话已完整加载上述文件时可复用；必需文件不可读时，停止本包执行并说明缺失或不可读的文件，不猜测规则。

## Overview

按用户指定的粒度整理，保留疑问与待核对项，标清哪些内容来自哪份材料。

## When to Use

整理课堂材料、归一散乱笔记、建双链知识网络。**不适用**：精读论文或专著 → `reading-note`；笔记用于提交的作业 → 属作业范畴，按学术诚信处理。

## 执行流程

### 讲义/录音 → 结构化笔记

1. 收集并标记每份材料的来源名、章节、页码或时间戳；多份来源先分别识别，不把来源不明的内容拼成事实。
2. 确定粒度：明确要求摘要/速记时提炼核心结论；未要求压缩或要求完整时，按材料章节整理全部重要定义、结论、公式、推导、代表例题和老师强调的考点。
3. 跨来源互补处合并表达，观点冲突处并列标明来源与分歧；保留必要页码、时间戳和来源名。
4. 生成概念图（层级：章 → 节 → 关键概念），保留推导关系和前置概念；根据用户需求加入自测题，默认不以题目数量替代知识覆盖。
5. 标注未理解点和待核验项；推断与原文事实分开标记。
6. 建立材料章节/页码到笔记小节的覆盖核对；长材料按完整章节或主题分批，每批注明范围和未处理部分。

**粒度口径**：摘要笔记才压缩为 5–8 条核心；完整笔记按原材料章节覆盖重要内容。两者均须保留来源线索，且不得将少量摘要标成完整笔记。

| 保留 | 丢弃 |
|---|---|
| 定义、结论、公式 | 语气词、重复举例 |
| 老师强调的考点 | 跑题的闲谈 |
| 章节 / 页码 / 时间戳与来源名 | 无法核实的补充背景 |

**未理解点**：凡听不懂处一律标出，供下次复考 —— 不猜测、不补全。

**判定顺序**：先判材料是不是课堂侧的原始记录（录音、板书、讲义）——若只是把已有笔记换个格式，走本 skill 的「散乱笔记归一」 → 再判用户要的粒度是摘要还是完整 → 最后才按来源对齐逐节产出，并标出未理解点。

### 散乱笔记归一

1. 收集用户提供的材料，并登记来源名称、讲次/章节和可定位页码或时间戳。
2. 按讲次或章节对齐各来源，标出覆盖范围、缺失段和互相冲突处。
3. 统一成四段结构：章节 → 概念 → 例题 → 待补；每条保留来源线索。
4. 对同一概念的多份表述，合并完全重复内容；保留具有不同条件、例子或结论的材料，不为缩短篇幅删掉独有信息；冲突内容并列标注，不替来源裁决。
5. 检查材料清单与笔记章节一一对应，输出「待补章节清单」和来源索引。

**统一结构四层**：章节 → 概念 → 例题 → 待补。

| 原始形态 | 归一到 |
|---|---|
| 零散便签 | 挂到「概念」层 |
| 拍照板书 | 转写成「概念 + 例题」 |
| 语音转写 | 按章节切段 |

**纪律**：只做结构整理，不做讲解、不做补全 —— 缺的地方标「待补」。
来源无法定位或读取不完整时，明确标记缺口；不以通用知识悄悄填补材料中的空白。
用户未要求摘要时，归一不得改变原材料的信息粒度或省略独有定义、条件、例题和结论；长材料按完整章节/主题分批，并登记本轮覆盖范围。

**判定顺序**：先判材料是不是同一门课同一进度的多份记录——只有单份材料且结构已经统一，就无需归一 → 再判各来源能否对齐到同一章节骨架 → 最后才按统一结构落段，并把对不上的部分登记为待补。

### 双链知识网络

1. **建节点命名规范**：一概念一页，文件名 = 概念名（如「极限的定义.md」），不加日期前缀——链接要指向稳定的概念，不是指向某天
2. **三类链接规则**：
   - 双链 `[[概念]]` 指向库内其他概念页（自动跟踪重命名）
   - `[[概念#小节]]` 指向某页的具体小节
   - 外部 URL 才用普通 Markdown 链接（如 DUT 课程平台页面）
3. **标签层级**：`#课程/高数` `#课程/大物` 一级按课程，`#类型/概念` `#类型/错题` `#类型/易混点` 二级按性质——标签管检索，链接管关系，不混用
4. **嵌入引用**：错题页用 `![[原概念]]` 嵌入被考的概念页，复习错题时不用跳转
5. **索引页（MOC）**：每门课建一张「课程地图」页，用链接列出该课全部概念页并按章节组织——新笔记先在地图上找挂点，找不到再开新页
6. **连接仪式**：每次记完新笔记，强制问「这和哪些旧概念有关？」并补 ≥ 1 个双链——没有链接的新页是孤儿页，等于白记
7. 输出「本页链接清单 + 建议挂载点」

**建链两原则**：

| 原则 | 说明 |
|---|---|
| 概念即节点 | 一个概念一个文件 |
| 链接即关系 | 关联 / 派生 / 对立 三类边 |

**复习路径**：从一个节点出发，沿「关联」边向外走 —— 覆盖度比翻文件夹高。

**DUT 特化**：节点与标签结构对接 DUT 课程教学大纲的章节—知识点层级，双链命名与课程名 / 章节号一致，复习时可按课程与教师授课顺序回溯，直接对齐期中期末考核范围。

**判定顺序**：先判用户手上有没有现成的笔记可组织——只有散材料、还没成笔记的，走本 skill 的「讲义/录音 → 结构化笔记」 → 再判是结构已乱要归一，还是结构可用要连网，前者走本 skill 的「散乱笔记归一」 → 最后才定节点命名、链接与标签层级。

## 常见误判

### 讲义/录音 → 结构化笔记

- ❌ 把「原原本本转成文字」当整理笔记 → ✅ 逐字转写属格式归一，不属本 skill
- ❌ 用户没说要摘要就默认压缩 → ✅ 未要求压缩时按章节覆盖全部重要定义、结论与例题
- ❌ 把多份来源按文件顺序堆叠 → ✅ 按主题综合，冲突处并列标明来源
- ❌ 把听不懂的地方凭常识补全 → ✅ 未理解点只标出，不猜测、不补全
- ❌ 把摘要笔记当成完整笔记交付 → ✅ 少量摘要不得标成完整笔记，须核对来源范围与笔记小节覆盖

**多来源纪律**：按主题综合而非按来源堆叠；每个关键知识点保留来源线索。来源间冲突时并列呈现，不擅自调和。长材料可先按现成章节或主题分段处理，但不依赖联网抓取、并行代理或后台日志。详尽笔记应核对来源范围与笔记小节覆盖；不能因输出长度而隐去关键推导、条件或例题，单轮放不下时按完整主题分批并说明边界。

### 散乱笔记归一

- ❌ 把「把这几条笔记互相链接」当归一 → ✅ 那是互连构网，本 skill 只统一结构
- ❌ 来源对不上就顺手补全 → ✅ 定位不到或读不全的只标缺口，不拿常识填
- ❌ 归一顺手压缩内容 → ✅ 未要求摘要时不得改变信息粒度，独有条件与例题要保留
- ❌ 把冲突表述自行调和 → ✅ 冲突并列标注，不替来源裁决
- ❌ 单份材料也强行套满结构层 → ✅ 没有的内容标「待补」，不虚设层级

### 双链知识网络

- ❌ 把「帮我整理这节课的笔记」当建网 → ✅ 那要从材料生成笔记，本 skill 只组织已有的笔记
- ❌ 用文件夹加日期前缀分层 → ✅ 概念名即文件名，链接要指向稳定概念而非某天
- ❌ 用标签替代链接 → ✅ 标签管检索、链接管关系，两者不混用
- ❌ 新页不挂链接就交付 → ✅ 每页都要补双链，孤儿页等于白记
- ❌ 把「格式乱、要统一结构」当互连需求 → ✅ 那是结构归一，先归一再连网
