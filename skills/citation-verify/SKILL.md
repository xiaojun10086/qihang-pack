# 引文核验

## 执行前置

- 本文所有包内相对路径均以本 `SKILL.md` 所在目录为基准，不以用户当前工作目录（cwd）为基准。
- 执行任何业务步骤前，先完整读取并遵守 `../using-qihang/SKILL.md` 中的共享行为准则及安全兜底，再完整读取 `../../config.yaml`。这里只加载共享规则和配置，不重复总入口路由。
- 本会话已完整加载上述文件时可复用；必需文件不可读时，停止本包执行并说明缺失或不可读的文件，不猜测规则。

## Overview

只做核验与标注：真实、存疑、无法核验三种核验结果；绝不替用户补一个「看起来对」的字段。**状态词口径**：对外的最终结论一律用下文的引文级回源状态（已回源 / 部分回源 / 无法定位）；「真实 / 存疑 / 无法核验」与字段级的「一致 / 待核验」等标记只作内部判据，不单独作为最终状态输出。

## When to Use

投稿或提交前的引文真实性核对、DOI 与页码校验。**不适用**：格式规范化 → `cite-normalize`。

## 执行流程

1. 列出待核验引文的现有字段
2. 逐条标回源状态：已回源 / 部分回源 / 无法定位
3. 对「部分回源」标出缺失字段与可能来源
4. 对「无法定位」的条目一律建议删除，不放凑数文献
5. 输出核验表：条目 / 状态 / 缺字段 / 处置

**核验字段与回源状态**：

| 字段 | 判据 | 回源状态标 |
|---|---|---|
| 题名 / 作者 | 与源页面逐字一致 | 一致 / 有出入 |
| 年份 / 卷期页 | 源页面明示 | 已核验 / 待核验 |
| DOI | 可解析到同一文献 | 可解析 / 不可解析 / 未给 |
| 会议 / 期刊全称 | 用规范全称 | 规范 / 缩写待展开 |

**登录判断**：先判核验字段要在哪个源上比对——DOI 解析、Crossref / OpenAlex、出版社与期刊页面、PubMed 公开可查，直接核；需机构订阅的数据库全文（知网 / 万方等订阅库）需登录，转 `portal-operator`；校外访问通道见 `../../references/dlut-official-sites.md` 的「图书馆电子资源校外访问」条目（`lib.dlut.edu.cn/wxzy1/xwfw.htm`），WebVPN 的 Referer 限制见 `../../references/dlut-login-sites.md`。需登录时按 `../using-qihang/SKILL.md` 共享行为准则第四条给出登录要求（**先给最快捷做法**：让用户用**独立配置目录**加 `--remote-debugging-port=0` 启动一次，登录一次即长期免登录，端口写入该目录的 `DevToolsActivePort`（**Chrome / Edge 136 起会忽略默认配置目录上的调试端口，必须用独立目录**，理由见共享行为准则第四条）；用户本人用**自己的浏览器**登录，本包不代开浏览器、不代填凭证；要本包直接操作页面需带调试端口启动，用户确认已登录后本包才接入）；完整流程见 `../portal-operator/SKILL.md`。

**判定顺序**：先判是不是「补全 / 生成引文」请求，是则只标「未给」并给回源方法 → 再判字段是否与源页面一致 → 最后才给回源状态标。

## 常见误判

- ❌ 把「按惯例补全」当格式整理 → ✅ 不生成不补全，漏字段一律标「未给」
- ❌ 凭常识补年份或卷期页 → ✅ 只核验已存在的引文，字段必须来自源页面
- ❌ 一条引文给多个状态 → ✅ 一条引文只给一个最终状态（一律取「已回源 / 部分回源 / 无法定位」），字段级标记（一致 / 待核验等）只写在核验表里，冲突时以 DOI 解析结果为准
- ❌ 期刊名用缩写 → ✅ 会议与期刊要用规范全称，缩写标「待展开」
- ❌ 题名有出入也算通过 → ✅ 题名与作者要逐字一致，有出入要标出来
- ❌ 需订阅的数据库全文当公开可查 → ✅ 走图书馆账户或 WebVPN 需登录，先给出登录要求，拿不到就标「无法核验」

**纪律**：只核验**已存在**的引文，缺字段就标「未给」，**不得据常识补全**；一条引文只给一个最终状态，冲突时以 DOI 解析结果为准。
