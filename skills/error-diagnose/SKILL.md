## Overview

要的是共性归因，不是逐题重讲。先看学生的解法，再判断断在哪一类，最后按优先级排再练顺序。

## When to Use

多题同问「为什么错」、错题整理、变式再练、模拟卷复盘。**不适用**：单题求讲解 → `explain-stepwise`；考前整体安排 → `exam-sprint`。

## 执行流程

### 错因四分类

1. 收 3–5 道错题（标明是作业题还是自练题）
2. 逐题判断错因四类：概念不清 / 方法不会 / 计算失误 / 审题偏差
3. 统计各类占比，找出占比最高的那一类
4. 针对最高类给 1 条纠正动作
5. 按「先修概念、再练同类」排出再练顺序，留白不给答案

| 错因 | 判据 | 再练顺序 |
|---|---|---|
| 概念 | 同类题全错 | 先补概念 |
| 方法 | 概念懂但换形就不会 | 归纳题型模板 |
| 计算 | 思路对、步骤错 | 专练运算 |
| 审题 | 题意理解偏 | 练读题标注 |

**判定顺序**：先判「这题该不该归因」——只对**已发生**的错归因，尚未做过的题转讲解；再判是概念还是方法（看同类题是否全错）；最后定**唯一主因**。

### 模拟卷与变式

1. 明确考试范围与题型分布（问老师或看往年卷）
2. 按题型比例组一份限时模拟卷（只用历年真题结构）
3. 限时做完后逐题归因（知识 / 方法 / 粗心 / 时间）
4. 对高错因类型出 2–3 道变式题
5. 计算知识点覆盖率，列出未覆盖章节

**错因四分类与回炉顺序**：

| 错因 | 回炉动作 | 优先级 |
|---|---|---|
| 知识（不会） | 回补概念 → 变式题 | 高 |
| 方法（想不到） | 归纳题型套路 | 高 |
| 粗心（算错） | 建立检查清单 | 中 |
| 时间（做不完） | 调整做题顺序 | 中 |

**判定顺序**：先判用户要的是「组卷 + 错因回炉」还是「单题讲解」，后者改走分步讲解 → 再判错因属知识 / 方法 / 粗心 / 时间哪一类 → 最后才排回炉优先级。

## 常见误判

### 错因四分类

- ❌ 把「不会做」当错因 → ✅ 没做过的题没有错可归因，属讲解范畴
- ❌ 把概念问题当方法问题 → ✅ 同类题全错属概念，换形才错属方法
- ❌ 一题挂多类错因 → ✅ 主因只取一类，多因会让纠正动作失焦
- ❌ 把「粗心」另立一类 → ✅ 粗心必须落到计算或审题，不新开类别
- ❌ 只按答案对错归类 → ✅ 须看步骤——思路对而步骤错属计算，不因答案错就判概念

**纪律**：只对**已发生的错**归因，不预测、不代做；同一错题只归一类主因。

### 模拟卷与变式

- ❌ 把「讲讲这道题」当组卷需求 → ✅ 单题讲解改走分步讲解，模拟卷不做逐题答疑
- ❌ 错因一律归为「不会」→ ✅ 先分知识、方法、粗心、时间四类，回炉动作各不相同
- ❌ 用来源不明的押题卷 → ✅ 只用历年真题或老师给的样题
- ❌ 卷子做完就结束 → ✅ 做完要跑错因回炉，否则分数不会动
- ❌ 粗心当能力问题 → ✅ 粗心靠检查清单压，不是回去重学知识

**组卷纪律**：只用历年真题 / 老师给的样题，不用来源不明的「押题卷」。
