# 论文结构与答辩

## 执行前置

- 本文所有包内相对路径均以本 `SKILL.md` 所在目录为基准，不以用户当前工作目录（cwd）为基准。
- 执行任何业务步骤前，先完整读取并遵守 `../using-qihang/SKILL.md` 中的共享行为准则及安全兜底，再完整读取 `../../config.yaml`。这里只加载共享规则和配置，不重复总入口路由。
- 本会话已完整加载上述文件时可复用；必需文件不可读时，停止本包执行并说明缺失或不可读的文件，不猜测规则。

## Overview

给结构大纲、各节字数与论证链自查，再做一次「审稿人视角」预审；演示部分遵循「行动标题 + 幽灵测试」。

## When to Use

论文结构、摘要打磨、汇报演示、开题/中期/答辩问答准备、学位论文格式自检。**不适用**：实验报告骨架 → `lab-report`；参考文献格式 → `cite-normalize`。

## 执行流程

### 结构大纲与预审

1. 明确类型（课程论文 / 综述 / 报告）与字数
2. 出结构大纲并分配字数
3. 检查论证链：每节是否有主张 → 证据 → 推理
4. 跑一次模拟审稿（挑 3 个最可能被质疑的点）
5. 给引用格式规范（GB/T 7714 或 APA）
6. 输出文件落点

**论证链自查**：主张 → 论据 → 反例 → 回应，四环不能断。

| 节 | 字数建议 |
|---|---|
| 引言 | 15% |
| 主体 | 60% |
| 结论 | 15% |

**预审视角**：以审稿人身份问「这个结论证据够不够」，标记证据薄弱处。

**判定顺序**：先判需求是「结构骨架 + 预审」还是「摘要 / 引用等单点打磨」（后者改走对应流程）→ 再判论文类型与字数 → 最后才排大纲、分字数并跑预审。

### 摘要五要素

1. 按五要素把现有摘要切成 5 块，标出缺失或混叠
2. 检查是否含具体结果（数字 / 结论）而非空泛表述
3. 检查是否混入了正文才该有的铺垫与引用
4. 检查关键词是否覆盖主题词与检索词
5. 给「逐句改写方向」，不整段代写

**五要素判定细则**：

| 要素 | 缺失信号 | 合格标准 |
|---|---|---|
| 背景 | 上来就说方法 | 一句话说清领域缺口 |
| 问题 | 无明确研究问题 | 有可检验的问题句 |
| 方法 | 只说「进行了研究」 | 有具体方法名 / 数据量 |
| 结果 | 无数字、无结论 | 至少 1 个具体结果 |
| 意义 | 无或夸张 | 克制陈述贡献 |

**判据**：任一要素缺失 → 先补该要素，再谈语言精简。

**判定顺序**：先判用户要的是「代写摘要」还是「改已有摘要」，前者一律只给骨架 → 再判五要素中缺哪几个 → 最后才谈语言精简。

### 论证式演示

1. **定类型**：学术场合默认「论证式」（论点 → 证据 → 推理），只有面向非专业听众的科普场合才允许叙事式
2. **先出逐页大纲再动手**（≥10 页或内容复杂时必须先确认）：每页一行 `标题 | 论据类型 | 要点`，用户确认后才细化
3. **行动标题**：每页标题写成**完整的结论句**（如「实验组错误率下降 40%」），不写主题词（❌「实验结果」）
4. **幽灵测试**：把所有页的标题按顺序连读——必须不依赖正文就能讲通整个论证；讲不通就改大纲，禁止先做后改
5. **一页一论据**：每页只放一个图表 / 一个论点；在图上直接标出关键发现（别让听众自己找）
6. **页内纪律**：正文 ≤ 40 词 / 页；左对齐；结论页放最后且留在屏幕上（Q&A 期间评委看的必须是结论，不是「谢谢」）
7. **引用即纪律**：页内引用写进页脚，末页（或倒数第二页）放参考文献页——学术诚信延伸到幻灯片
8. 输出「逐页大纲（含行动标题）+ 幽灵测试通过声明」

**论证结构四段**：问题 → 方法 → 结果 → 结论，每段 1 张主图。

| 单页原则 | 说明 |
|---|---|
| 一页一论点 | 标题即结论 |
| 证据可追溯 | 图注标来源 |

**边界**：只管讲什么、按什么顺序讲；视觉美化走学校 / 课程规定模板。

**DUT 特化**：论证结构对接 DUT 开题 / 中期 / 学位答辩与课程汇报的规定模板与时间限制，视觉模板一律沿用学校或课程指定样式，不另造配色。

**判定顺序**：先判要的是「讲什么、按什么顺序讲」还是「怎么美化」，后者不属本域 → 再判是哪一类汇报（开题 / 中期 / 答辩 / 课程汇报）→ 最后才排论证四段与单页论点。

### 学位论文格式自检

1. 取得本校《学位论文格式规定》与学院补充要求
2. 过结构自检表（封面 / 中英文摘要 / 目录 / 章节 / 致谢 / 附录）
3. 检查章节编号与图表题注的连续性
4. 检查参考文献体例（与 `cite-normalize` 联用）
5. 输出「不符项清单 + 定位到页 / 节」，不给改后的正文

**格式自检表（高频扣分点）**：

| 部位 | 常见不符 |
|---|---|
| 封面 / 页眉 | 校名、日期、密级缺失 |
| 中英文摘要 | 关键词条数不符、英文摘要与中文不对应 |
| 章节编号 | 跳号、缺 2.1 直接到 2.2、图表跨节编号断 |
| 图表题注 | 图下表上位置错、单位缺失、来源未注 |
| 参考文献 | 体例混用（GB/T 7714 与 APA 混排） |

**不做**：代排版、代改正文 —— 只给「哪一页哪一处不符」。

**判定顺序**：先判用户要的是「代写正文」还是「格式核对」，前者一律只给清单 → 再判是格式不符还是体例混用 → 最后才逐页定位到具体位置。

### 答辩问答演练

1. **内容防守筛选**：把工作分成两类——「守得住」（有数据 / 推导支撑）与「讲不顺」（论证链有断点）；断点内容移入「已知局限」主动交代，**不让评委先发现**
2. **幽灵测试**：只读幻灯片标题（或论点清单）连读——标题讲不通的地方就是评委会追问的地方，先补论证再上场
3. **三问自审（红队）**：站在最挑剔评委视角，对核心论点提 3 个最致命的问题（如「样本量怎么定的」「为什么不采用 B 方案」），逐一生成「应答骨架」：承认边界 → 给证据 → 给下一步
4. **预设问题清单**：按评委类型生成 10 个高概率问题（方法 3 个 / 结果 3 个 / 意义 2 个 / 局限 2 个），每个配「20 秒短答 + 展开版」两档
5. **应答纪律**：
   - 听完再答，不打断
   - 不会的问题答「这是我目前的边界，我的下一步计划是——」（承认边界比硬编强）
   - 每个回答收在结论上，不跑题
6. 输出「预设问题清单 + 应答骨架 + 已知局限声明」

**质询分类与应答纪律**：

| 质询类型 | 典型问法 | 应答策略 |
|---|---|---|
| 事实型 | 数据哪来的 | 直给来源与核验状态 |
| 方法型 | 为什么用这个检验 | 讲前提匹配 |
| 边界型 | 结论能推多广 | 明说不能推的部分 |
| 攻击型 | 这工作有什么新意 | 讲守得住的贡献 |

**纪律**：只排练**守得住**的内容；答不上来的问题**不编说法**，改为「承认边界 + 给后续计划」。

**DUT 特化**：按 DUT 开题 / 中期 / 学位答辩常见节奏组织问题清单（选题意义 → 方法 → 结果 → 创新点 → 展望），可直接用于校内答辩预演。

**判定顺序**：先判是不是「编个说法糊过去」请求，是则只给承认边界的话术 → 再判质询属哪一类（事实 / 方法 / 边界 / 攻击）→ 最后才按类型给应答策略。

## 常见误判

### 结构大纲与预审

- ❌ 把「帮我写摘要」当骨架需求 → ✅ 单点打磨不是本流程，改走摘要打磨
- ❌ 大纲只给章节名不给字数 → ✅ 不给份额，各节膨胀比例无从约束
- ❌ 预审只说「证据不足」 → ✅ 要指出断在主张、论据、反例还是回应，并说明补什么
- ❌ 顺着请求代写正文 → ✅ 只给大纲、字数与自查，正文不代劳
- ❌ 参考文献未核验就写进大纲 → ✅ 未核验条目不得进终稿，只标占位

### 摘要五要素

- ❌ 把「帮我写个摘要」当代写 → ✅ 只给五要素填空骨架与自查清单，正文不代劳
- ❌ 先改语言再补要素 → ✅ 要素缺失优先补要素，句子再漂亮也救不回缺结果
- ❌ 背景段铺陈过长 → ✅ 背景只用一句话说清领域缺口，篇幅让给结果
- ❌ 意义段用「重大突破」类措辞 → ✅ 克制陈述贡献，不夸大适用范围
- ❌ 结果段只写「效果良好」→ ✅ 至少落到一个具体结果，否则摘要无可检验内容

### 论证式演示

- ❌ 把「做得好看点」当演示优化 → ✅ 视觉美化不属本域，只给论证结构与单页论点
- ❌ 一页塞多个论点 → ✅ 标题即结论，一页只承一个论点
- ❌ 图注不标来源 → ✅ 证据要可追溯，图注写清出处
- ❌ 先定模板再排内容 → ✅ 先定论证顺序，再套学校或课程规定的模板
- ❌ 按论文目录顺序照搬成幻灯片 → ✅ 汇报按听众关心的问题排，不按论文目录排

### 学位论文格式自检

- ❌ 把「帮我写第三章」当结构请求 → ✅ 代写正文不代劳，只给章节骨架与自查清单
- ❌ 只报「格式有问题」→ ✅ 要落到哪一页哪一处不符，否则改不动
- ❌ 把体例混用当排版问题 → ✅ 先统一参考文献体例，再谈版式
- ❌ 图表题注位置随手放 → ✅ 图下表上，题注含单位与来源
- ❌ 摘要关键词条数随字数调整 → ✅ 条数与对应关系按学校规定执行，不自定

### 答辩问答演练

- ❌ 把「编个说法糊过去」当应答技巧 → ✅ 不编说法，承认边界比糊过去更稳
- ❌ 所有问题都用一套话术 → ✅ 质询分类不同应答策略不同，攻击型要讲守得住的贡献
- ❌ 结论范围被追问就含糊 → ✅ 边界型追问要明说不能推的部分
- ❌ 只排练好答的问题 → ✅ 只排练守得住的内容，答不上来的改「承认边界 + 给后续计划」
- ❌ 数据来源被问就现场想 → ✅ 事实型追问直给来源与核验状态
