# 校园公开信息检索

## Overview

优先使用官方或一手来源；每项事实附出处与日期，未实时核验的要明说，不编造 URL、电话或单位名。

## When to Use

查学校、课程、通知、机构、地点、场馆、联系方式等公开信息。**不适用**：查导师的研究方向 → `advisor-finder`；查截止时间 → `notice-track`。

## 执行流程

### 公开信息检索

1. **确定范围**：确认要回答的具体问题与时效要求；一次只处理一个清晰目标。
2. **按信息类型选择 DUT 官方入口**：
   | 要查什么 | 官方入口 |
   |---|---|
   | 部门电话 / 联系方式 | 全校部门联系方式总表 https://office.dlut.edu.cn/info/1032/1492.htm |
   | 通知 / 公告 / 制度文件 | 信息公开网 https://info.dlut.edu.cn/ |
   | 机构与学院设置 | 组织机构总览 https://www.dlut.edu.cn/xxgk/zzjg.htm |
   | 新闻 / 活动报道 | 新闻网 https://news.dlut.edu.cn/ |
   | 楼宇 / 单位位置 | 校园地图系统 http://map.dlut.edu.cn/ |
3. **交叉核对**：重要、易变或有争议的事实尽可能再找一个独立可靠来源；记录页面发布日期/更新时间与访问日期。来源冲突时并列说明，不替用户掩盖差异。
4. **组织结果**：每项关键事实附标题、发布方、URL、日期和核验状态；把来源直接支持的事实与推断/建议分开。只读到目录页时，不声称核实了页面正文。
5. **未找到或工具不可用**：明确说当前未能核实；给官方入口或可复制检索式，或请用户提供网页/文件。不得用模型记忆编造 URL、电话、人名或搜索结果。

**来源优先级**：

| 顺序 | 源 | 用途 |
|---|---|---|
| 1 | 原始公告、制度、数据集或机构页面 | 直接支持结论的第一手材料 |
| 2 | 本包登记的 DUT 官方入口 | 快速定位要访问的页面；仍需打开页面核实 |
| 3 | 其他官方/权威来源 | 交叉核对背景与时效；需注明发布方 |

**纪律**：只引用实际访问到或用户提供的来源；没有浏览能力时只提供入口/检索式，不声称已经核验。当前事实标注访问日期；历史基准日期不冒充实时结果。

**DUT 特化**：区分主校区 / 开发区 / 盘锦校区入口差异；涉及仅 i大工 APP 可办的事项时，说明 APP 内路径，或转 `portal-operator` 代操作。

**判定顺序**：先判是不是「要非公开信息」请求，是则只给公开渠道 → 再判来源优先级（一手材料 / 登记入口 / 其他官方）→ 最后才给入口与检索式并标访问日期。

### 机构与场馆

1. 明确要查的机构 / 场馆与目标信息
2. 在公开站（信息公开网 / 组织机构总览 / 学部学院导航）定位
3. 输出职能 / 地点 / 公开联系方式，标注来源与核验状态
4. 未收录项固定回复「信息库未收录」给核实入口
5. 需要登录才能看到的内容 → 转 `portal-operator` 代操作

**公开信息查询路径**：

| 要查 | 首选入口 |
|---|---|
| 部门职能 / 电话 | 信息公开网 · 部门联系方式总表 |
| 学院的谁负责 | 学部学院导航 → 学院官网 |
| 场馆开放 | 场馆中心 / 图书馆官网 |

**判定顺序**：先判是不是「查他人非公开联系方式」请求，是则只给公开查询入口 → 再判要查的对象类型（部门 / 学院 / 场馆）→ 最后才给首选入口。

## 常见误判

### 公开信息检索

- ❌ 把「查内部非公开电话」当检索需求 → ✅ 只提供公开联系渠道，非公开号码不在范围
- ❌ 没有浏览能力却声称已核验 → ✅ 明说未核验并给入口或检索式；要实际登录查询 → 转 `portal-operator`
- ❌ 拿历史基准日期冒充实时结果 → ✅ 当前事实要标访问日期，历史基准不冒充实时
- ❌ 用信息库代替实时页面 → ✅ 信息库只用于找登记入口，不代替实时核验
- ❌ 三校区入口混用 → ✅ 区分主校区、开发区与盘锦校区入口差异

### 机构与场馆

- ❌ 把「查同学联系方式」当机构查询 → ✅ 不查询他人非公开联系方式，只给公开入口
- ❌ 信息库没有就猜一个 → ✅ 未收录就固定回复「信息库未收录」并给核实入口，不臆造
- ❌ 部门职能与电话分头找 → ✅ 部门职能与电话首选信息公开网的部门联系方式总表
- ❌ 找学院负责人直接搜名字 → ✅ 走学部学院导航到学院官网再定位
- ❌ 找同学绕开辅导员 → ✅ 需联系同学建议经辅导员转达

**判据**：信息库未收录 → 固定回复「信息库未收录」+ 给核实入口，**不臆造**。
