# 实验数据与统计

## 执行前置

- 本会话已完整加载上述文件时可复用；必需文件不可读时，停止本包执行并说明缺失或不可读的文件，不猜测规则。

## Overview

先框定问题再碰数据，看原始数据再选检验，前提检查必须报告，效应量与 p 值并重。

## When to Use

实验数据处理、统计检验选择、图表规范、实验设计要素检查。**不适用**：写报告正文 → `lab-report`。

## 执行流程

### 数据分析主线

1. 确认数据类型（连续/分类）与样本量
2. 明确要检验的假设
3. 选检验方法并说明前提（正态性、独立性）
4. 跑分析，出出版级图表（标注单位与误差棒）
5. 给一句话结论 + 明确列出不能下的结论
6. 输出脚本与图表

**数据—假设—检验匹配**：

| 数据类型 | 常见假设 | 首选检验 |
|---|---|---|
| 两组连续 | 均值差异 | t 检验（先查正态 / 方差齐） |
| 三组及以上 | 组间差异 | 方差分析 + 事后比较 |
| 分类变量关联 | 独立性 | 卡方检验（查期望频数） |
| 连续相关 | 线性关系 | 相关 / 回归（查残差） |

**判定顺序**：先判是不是「调结果 / 凑显著」请求，是则只做前提与检验力检查 → 再判数据结构与假设类型 → 最后才选检验并附「不能下的结论」。

### 统计规范流程

1. **先框问题再碰数据**：写下 ① 假设 ② 因变量与自变量 ③ 设计类型（独立 / 配对 / 重复测量）——选检验由设计决定，不是反过来
2. **看原始数据**：每组的 n、均值、标准差、缺失值；先画直方图 / 箱线图再谈检验——异常值、天花板 / 地板效应要向用户点名，不得静默处理
3. **选检验速查**：
   - 两组独立均值 → 预设 Welch t 检验（不假定方差齐性）
   - 配对均值 → 配对 t 检验（对配对差值做）
   - 多组 → Welch ANOVA；秩比较 → Mann-Whitney / Kruskal-Wallis
   - 关联 → Pearson（线性）/ Spearman（单调）；按科学问题选，不用正态性预检来选
4. **查前提并报告**：正态性（Q-Q 图 + 检验）、方差齐性、独立性——**前提检查结果必须写进报告**（评阅人会看）
5. **效应量必算**：p 值只说「与零模型不相容到什么程度」；效应量（Cohen's d / η² / r）+ 置信区间才支撑「实际重要性」的判断
6. **结果写作模板**：`描述统计（M±SD）+ 检验统计量 + 精确 p 值 + 效应量[95%CI] + 前提核查声明`
7. 输出「分析决策表 + 结果段落草稿（数据留空由用户填）」

**六步强制顺序**（不得跳步、不得回退凑）：

| 步 | 内容 | 卡点 |
|---|---|---|
| 1 | 问题 | 研究问题未定不选检验 |
| 2 | 数据 | 结构 / 缺失 / 类型未清不动手 |
| 3 | 检验 | 依数据定检验 |
| 4 | 前提 | 前提不过换非参 |
| 5 | 结果 | 报效应量与区间 |
| 6 | 报告 | 附「不能下的结论」 |

**纪律**：顺序即纪律——**防「先选好检验再找数据凑」**；任何一步缺失就停下追问，不跳过。

**DUT 特化**：报告口径对齐 DUT 学位论文与课程报告格式要求（题注、单位、显著性标记），便于直接在答辩 / 提交场景落地。

**判定顺序**：先判第 2 步（数据）是否已清 → 再判第 1 步（问题）是否已定 → 最后才按第 3–6 步选检验、查前提、报结果、写报告。

### 方法选择与边界

1. 确认数据结构（分组数、样本量、配对与否、分布假设）
2. 选检验方法并说明所需假设
3. 做检验力/效应量评估，判断"不显著"是没效应还是样本不够
4. 列出「不能下的结论」：不推因果 / 不外推总体 / 不称证明
5. 给下一步：需要多少样本或哪种设计

**检验方法速查 + 前提检查**：

| 前提 | 检查方式 | 不满足时 |
|---|---|---|
| 正态性 | 直方图 / QQ 图 / 正态检验 | 换非参 |
| 方差齐性 | Levene 检验 | 用校正 t / Welch |
| 独立性 | 抽样设计核验 | 换配对 / 混合模型 |
| 样本量 | 检验力估算 | 报备检验力不足 |

**判定顺序**：先判是不是「补造 / 删改数据」请求，是则只给合规处理选项 → 再逐项检查前提（正态、方差齐、独立、样本量）→ 最后才报能下的结论。

### 实验设计要素

1. 把假设转成可检验的研究问题（自变量 / 因变量）
2. 操作化变量并定测量方式
3. 设计对照与随机化，必要时加盲法
4. 用功效分析思路估样本量（给口径不给数字承诺）
5. 列可能的混淆变量与控制方案

**变量操作化检查**：每个变量都要有「操作性定义 + 测量工具 + 单位」。

| 设计要素 | 检查点 |
|---|---|
| 对照 | 有无空白 / 安慰剂对照 |
| 随机 | 分组是否随机 |
| 盲法 | 单盲 / 双盲是否可行 |
| 样本量 | 依据效应量 + 功效估算思路 |

**判定顺序**：先判是不是「为凑显著调整数据」请求，是则改走统计自查 → 再判设计要素（对照、随机、盲法、样本量）是否齐 → 最后才做变量操作化检查。

### 图表规范

1. 明确图要表达的关系（比较 / 分布 / 相关 / 构成）
2. 按关系选图型并给出「不建议」的图型
3. 检查坐标轴单位、量程、误差棒与样本量标注
4. 落显著性标注与图注要素
5. 给分辨率 / 矢量图 / 配色可达性要求

| 关系 | 推荐图型 | 不建议 |
|---|---|---|
| 比较 | 条形 / 箱线 | 3D 饼图 |
| 分布 | 直方 / 密度 | 折线代替分布 |
| 相关 | 散点 + 拟合 | 双 Y 轴硬凑 |
| 构成 | 堆叠条 | 多饼图 |

**分辨率**：位图 ≥ 300 dpi，线图优先矢量（PDF / EPS）。

**判定顺序**：先判是不是「改图让结果更显著」请求，是则只给真实数据的规范要素 → 再判要表达的关系（比较 / 分布 / 相关 / 构成）→ 最后才选图型与分辨率。

## 常见误判

### 数据分析主线

- ❌ 把「调一下让它显著」当统计需求 → ✅ 不调结果，不显著也是结论
- ❌ 先选好检验再找数据 → ✅ 先确认数据结构与假设，再选检验
- ❌ 跑完只报 p 值 → ✅ 跑完必须附「不能下的结论」，不替数据说话
- ❌ 不看前提直接跑 t 检验 → ✅ 两组连续要先查正态与方差齐，不过换非参
- ❌ 分类变量也套均值检验 → ✅ 分类变量的关联用卡方并先查期望频数

**纪律**：**先确认数据结构与假设，再选检验**；跑完必须附「不能下的结论」一行，不替数据说话。

### 统计规范流程

- ❌ 跳过数据整理直接问选哪个检验 → ✅ 数据未清不定检验，先追问三项要素
- ❌ 研究问题没定就开始跑 → ✅ 研究问题未定不选检验
- ❌ 前提不过就凑结论 → ✅ 前提不过换非参，不得回退凑
- ❌ 只报显著性不看效应量 → ✅ 结果要报效应量与区间
- ❌ 报告里不写局限 → ✅ 报告要附「不能下的结论」

### 方法选择与边界

- ❌ 把「按均值补上缺失」当清洗 → ✅ 不补造缺失值，缺失要如实标注并说明处理方式
- ❌ 删掉不利数据点 → ✅ 不删不利数据点，异常值要按规则处理并说明
- ❌ 前提不过仍用原检验 → ✅ 前提不过要换非参或校正方法
- ❌ 只报能下的结论 → ✅ 要同时明确列「不能下的结论」
- ❌ 检验力不足不报备 → ✅ 样本量不足要报备检验力不足

**纪律**：只报**能下的结论**，明确列「不能下的结论」；不补造缺失值、不删不利数据点。

### 实验设计要素

- ❌ 把「算出显著结果」当设计需求 → ✅ 为凑显著性调数据改走统计自查路径
- ❌ 变量只写名称 → ✅ 每个变量要有操作性定义、测量工具与单位
- ❌ 无对照也算实验 → ✅ 对照是设计要素，缺对照只能做描述
- ❌ 混淆变量不控制就下因果结论 → ✅ 混淆未控制时结论只能相关不能因果
- ❌ 样本量凭感觉 → ✅ 样本量要有效应量与功效的估算思路

**判据**：混淆变量未控制 → 结论只能相关不能因果；先按本 skill「统计规范流程」核过前提与检验力，再谈因果。

### 图表规范

- ❌ 把「改成看起来更显著」当美化 → ✅ 不篡改误差棒，也不选择性呈现
- ❌ 用 3D 饼图做比较 → ✅ 比较用条形或箱线，3D 饼图会误读
- ❌ 用折线表示分布 → ✅ 分布用直方或密度，折线代替分布会掩盖形态
- ❌ 双 Y 轴硬凑相关性 → ✅ 相关用散点加拟合，双 Y 轴会造出假相关
- ❌ 图导出分辨率不足 → ✅ 位图不低于 300 dpi，线图优先矢量格式
