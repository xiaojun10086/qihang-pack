# 校园事务办理

## Overview

先查 DUT 信息库锁定入口与电话，再给办理路径；查不到就明说未收录，不编造。

## When to Use

校园卡挂失补办、缴费、网络、图书馆等校内各类事务的办理路径咨询。**不适用**：需要开证明 → `campus-proof-guide`；宿舍与离校 → `dorm-life`；选课与培养方案 → `course-select`。

## 执行流程

1. 判定线上线下（线上给门户链接，线下给楼宇与电话）
2. 列出所需材料清单
3. 给出办理时长与常见卡点
4. 未收录则固定回复：信息库未收录，建议访问 https://www.dlut.edu.cn/ 核实
5. 输出办理卡片

**办事三问**：去哪办 / 带什么 / 多久办完。

| 类型 | 入口 |
|---|---|
| 学籍 / 证明 | 学院教务 + 教务处 |
| 一卡通 / 网费 | 校园门户 / 一卡通 |
| 报修 / 后勤 | 后勤处入口 |

**判定顺序**：先判是不是「代提交 / 代操作」请求（是则转 `portal-operator` 代做，不可撤销操作先复述确认）→ 再判办事类型（学籍证明 / 一卡通 / 报修后勤）→ 最后才给材料清单与办理周期。

## 常见误判

- ❌ 把「帮我把课都选好」当咨询 → ✅ 若用户要代为操作，转 `portal-operator`；只问路径时才给入口与材料
- ❌ 查不到就编一个入口 → ✅ 未收录时固定回「信息库未收录」并引导去官网核实
- ❌ 只答「去哪办」→ ✅ 办事三问要一起给：去哪办、带什么、多久办完
- ❌ 把周期说成确定天数 → ✅ 周期以部门答复为准，只给大致区间
- ❌ 办事类型不问就按默认入口给 → ✅ 先分学籍证明、一卡通、报修后勤三类，入口各不相同

**纪律**：查不到的信息固定回「信息库未收录」，不编造入口；需要代为操作系统时转 `portal-operator`。
