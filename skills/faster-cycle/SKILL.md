# 整门课系统学习

## 执行前置

- 本文所有包内相对路径均以本 `SKILL.md` 所在目录为基准，不以用户当前工作目录（cwd）为基准。
- 执行任何业务步骤前，先完整读取并遵守 `../using-qihang/SKILL.md` 中的共享行为准则及安全兜底，再完整读取 `../../config.yaml`。这里只加载共享规则和配置，不重复总入口路由。
- 本会话已完整加载上述文件时可复用；必需文件不可读时，停止本包执行并说明缺失或不可读的文件，不猜测规则。

## Overview

先确认课程、教材版本、章节范围与期望的讲解方式，再按基础与目标设计分章学习，每章讲完让学生回讲一遍来检验。路线只用于导航，不能当作教学内容交付。

## When to Use

从零入门、系统学一门课或一本教材、制定跨周学习计划。**不适用**：单点答疑 → `explain-stepwise`；考前突击 → `exam-sprint`。

## 执行流程

1. **补齐课程输入**：对整门课/整本教材级请求，确认课程名称、教材及版本（或明确没有指定教材）、章节/大纲范围、期望讲解方式。最多分 3 问；当前基础只在会改变讲解路线时询问，也可先用一个短诊断题判断。不得自行假定教材、章节、用户年级或 DUT 课程要求。
   若课程与章节范围已明确但没有教材材料，可先讲解可靠的通用知识，并明确这不是对特定教材/DUT 教学进度的核验；只有用户要求逐页贴合教材或事实无法可靠确认时，才先索取材料。
2. **选模式**（按目标四选一；依据已确认目标与基础，不从用户身份臆测）：
   - 均衡：理论 + 练习 + 应用各三分之一（默认推荐）
   - 应试：以真题回忆和模考为主
   - 理论：吃透概念与心智模型
   - 实践：以项目 / 实验任务驱动
3. **画课程路线**：只依据用户提供或已核验的教材目录/课程大纲列出章节先后、先修关系和每章目标；资料不足时先标为待确认，不编造章节。
4. **F 忘（归零）**：用一题或简短自述检查相关先修概念，标记「确认 / 存疑 / 待补」，不把诊断当考试。
5. **A 练（动手）**：每个已讲知识点配一个最小练习；按选定讲解方式安排概念直觉、例题、证明或代码演示。
6. **S 态（状态）**：按用户可用时间设置学习时段；只有用户需要安排地点时，才推荐经核验的 DUT 图书馆/自习资源。
7. **T 教（回讲）**：每完成一个主题，用自己的话复述关键概念、条件和例子；讲不顺处回到对应章节补学。
8. **E 恒（节律）与 R 复（间隔）**：按确认的课程进度安排每周循环与薄弱点回顾；涉及 DUT 教学周、考试周或课表时，优先以用户提供或公开核验的信息为准，不调用未授权私密站数据。
9. 输出分章路线、首个学习单元、薄弱点与复习节奏；若用户此轮要开始学习且材料足够，立即讲解首个完整单元，不只给路线或要求下轮再开始。逐章讲解时每轮只推进用户指定范围。

**FASTER 六步**：Forget → Act → State → Teach → Enter → Review。

| 步 | 关键动作 |
|---|---|
| Teach | 用自己的话讲，讲不顺=没懂 |
| Review | 间隔回访，非连续重读 |

**验收**：能不看资料把该知识点讲给他人听 → 才算过。

**教学完整度**：按已确认的章节范围，围绕每个关键概念解释直觉、定义/符号、成立条件、必要推导、代表例题和常见误区；按主题选用自测。教材或课程大纲仅提供路线时，明确区分「已讲内容」与「待讲内容」。资料不够支撑某项事实时标为待核实，不猜测 DUT 的课程章节、教材版本、教师进度或考试安排。单轮容量不足时按完整章节主题分批，说明剩余范围，不以简短提纲声称覆盖完整内容。

**DUT 特化**：以 DUT 学期与课程进度组织循环；只按用户提供或核验过的教学周、期中/期末安排分档。信息不足时用相对周次，不推断具体日期；把「教学回讲」放在课程推进期间，并按实际考试安排调整回顾节奏。
课程目录、教材版本、教师进度和考试周均不得由学校名推断；优先使用用户提供的课程大纲/教材目录，或经核验的公开校方信息。需要登录平台查看时转 `portal-operator` 代操作。

**判定顺序**：先判用户要的是「长期循环学习」还是「短期冲刺排程」，后者改走冲刺排程 → 再判可用资料能覆盖到哪一步 → 最后才按章节主题分批并排回顾节奏。

## 常见误判

- ❌ 把「考前突击计划」当学习循环 → ✅ 短期冲刺改走冲刺排程，循环法需要多轮间隔才起效
- ❌ 资料不够就凭学校名推断章节与进度 → ✅ 只按用户提供或核验过的信息排，不足时用相对周次
- ❌ 用简短提纲声称已覆盖完整内容 → ✅ 单轮容量不足就按完整章节主题分批，并说明剩余范围
- ❌ 讲不顺也当作已掌握 → ✅ 要能不看资料讲给他人听才算过，讲不顺等于没懂
- ❌ 连续重读代替间隔回访 → ✅ 复习靠拉开间隔回访，连续重读只是熟悉感
