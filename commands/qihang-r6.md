# 学生公开信息搜集

直接说要查什么即可。R6 是学生核心信息搜集入口，不限于科研人员；只处理公开信息。

| 需求 | 选用方法 |
|---|---|
| 校园、课程、联系方式、制度或一般学习/校园资料 | 使用公开信息检索；DUT 信息从官方站点库和官网开始 |
| 导师/教师研究方向与公开主页 | 只查公开教师主页与机构资料 |
| 报名、考试、评奖通知 | 提取发布方、截止时间、适用对象和原始公告链接 |
| 部门职能、办事地点、场馆开放 | 查机构/场馆官方页面，并注明校区与更新时间 |
| 学术论文、DOI、系统综述 | 转用学术文献检索流程，不与一般网页结果混为一谈 |
| 课表、成绩、一卡通等登录内容 | 转到校务办理与隐私规则；本入口不读取私密页面 |

## 检索与交付

1. 只有时间、校区、对象等缺失会改变结果时才追问；不要求用户先填槽位表。
2. 优先使用官方/一手来源；关键或易变信息尽可能交叉核验。
3. 每条事实附来源标题、发布方、URL 和发布日期/访问日期；把事实、推断和建议分开。
4. 不可访问网页时，说明未能实时核验，并给官方入口或检索式；不得声称已搜索或编造 URL、电话、人名。
5. 只检索公开信息；拒绝私人联系方式、家庭/行程等非公开个人信息及负面舆情聚合。
