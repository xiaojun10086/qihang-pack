## 六、关于「残余缺陷概率 < 5%」的诚实结论

### 6.1 我观察到的事实

| 发现轮次 | 新增产品缺陷 |
|---|---|
| L1 全量机械检查 | 7 |
| L2 可行性契约 | 20 |
| L3 语义通读 + 可疑模式 | 7 |
| L4 计数口径交叉核对 | 3 |
| L5 回归/幂等/确定性 | 3 |
| 修复后验证轮 ×3（4 个检查器） | **0** |

发现数呈下降并落到 0，是**必要**的收口证据，但**不足以**支撑 < 5%。

### 6.2 为什么不能宣称 < 5%

1. **Rule of Three**：若连续 *k* 轮独立复核均发现 0 个缺陷，则缺陷率的 95% 置信上界为 `3/k`。
   要让上界 ≤ 5%，需要 **k ≥ 60 轮**。本次只有 3 个验证轮 → 上界约 **100%**（`3/3`），毫无约束力。
2. **重复跑同一个确定性检查器不会累积统计证据**。`aligncheck.py` 连跑 5 轮必然全绿——它每轮检查的是**同一批断言**。把同一脚本跑 60 遍凑 k=60 是**假证据**。
3. **要真正逼近 < 5%，只能增加「独立透镜」**，因为漏检率按 `(1−p)^k` 衰减（p = 单个透镜的检出率，k = 独立透镜数）。
   从本次数据看，各透镜**互补性很强、重叠很低**（机械透镜与语义透镜的交集仅约 2 项）——这既说明多透镜有效，也说明 **p 并不高**，k 必须更大。
4. **本次结论还额外受并发改写侵蚀**（§5），在这条变量消掉之前，任何概率结论都有保质期。
