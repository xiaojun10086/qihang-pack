# 多轮压测报告 v3 · 行为回归与稳定性

> 压测日期：**2026-10-02** ｜ 对象：`qihang-pack` v2.7.0
> 执行方式：`bash scripts/regress.sh 3`（**连跑 3 轮**，逐轮独立进程）
> 结论：**每轮 40 项断言全部通过，累计 FAIL = 0，三轮结果逐项一致（确定性成立）**

---

## 一、为什么要有这个脚本

v2.6 的「验收」是**一次性手测**：跑几条命令、把结果抄进 `acceptance-v2.md`。
它有两个致命弱点，本轮都暴露了：

1. **样本可挑选** —— 只测了 `缴费`，恰好掩盖了 `缴费金额` 能绕过 L3 门禁（见 `review-report-v2.4.md` P0-1）。
2. **不可重复** —— 手测结果无法在改动后自动重跑，所以 21 项缺陷能一路活到 v2.6。

`regress.sh` 把「行为」变成可重复断言：**改任何东西，跑一遍就知道有没有退化**。

## 九、如何复用

```bash
bash scripts/regress.sh        # 跑一轮（改完东西必跑）
bash scripts/regress.sh 3      # 连跑三轮（发版前跑，验证确定性）
bash scripts/selfcheck.sh      # 静态结构与计数
bash scripts/audit.sh          # 安全、合规、门禁
```

三个脚本职责不重叠：**selfcheck 管「结构对不对」，audit 管「安不安全」，regress 管「行为对不对」。**
