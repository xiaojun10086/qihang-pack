## 0. 真实运行记录协议（本文件的**唯一**证据口径）

本节规定：真实运行发生后**必须记什么、记在哪个字段、怎么判**。**只有按本节格式记录下来的实录**
才可作为「真实使用过程 / 成效」的证据；下文 3 条演示是**设计预期（expected）**，不是证据。

**什么算一条证据**：一次真实宿主会话（LearnBuddy / WorkBuddy 实机运行），有真实输入与真实时间。
设计稿、事后复述、推测、模型自述、他人转述**一律不算**。

**怎么记**：`python scripts/metrics.py emit ...`（字段口径唯一真相源 = `scripts/metrics.py` 头部）。
埋点默认**关闭**，须用户明确启用（`SKILL.md` 硬规则 5「本地指标默认不记录」）。

| 必须记录的字段 | 对应演示的哪一步 | 为什么必须 |
|---|---|---|
| `ts` / `sid` | 全局 | 时间与可追溯性；**无时间戳的记录不得作为证据** |
| `gate` | ① 需求明确 | 澄清门实际判定（`确定` / `复述` / `追问` / `不适用`） |
| `domain` / `skill` | ②③④ | 实际锁定域与实际调用的库内 skill |
| `redline` / `rl_block` | ③ 域审查 | 是否命中红线、是否**真的**拦截 |
| `degrade` / `exit` | ④ 执行 | 降级与结束方式（`ok` / `deny` / `degrade` / `handoff` / `error`） |
| `leak` / `fab` / `iso` | ⑤ 输出 | 内部名泄漏 / 编造事实 / 隔离校验失败 —— **零容忍三项** |
| `lat_ms` / `turns` / `out_chars` | ⑤ 输出 | 时延 / 轮次 / 输出长度 |
| `corrected` | ⑤ 输出 | 用户是否纠正过 —— 真实质量的最强信号 |
| `u` | ① 需求明确 | 澄清门 U 值（**仅诊断用，不进前台**） |

**怎么判**：`python scripts/metrics.py report`（建议性）｜
`python scripts/metrics.py check --baseline <冻结基线>`（门禁）。
首次冻结：`python scripts/metrics.py baseline --out <路径>`；窗口内无数据时**拒绝冻结**
（防「空基线一律通过」）。`scripts/checkall.py` 只以**建议性**方式跑 `report`，
并把「无数据」这个事实打印出来 —— 真实体验证据的缺失不该静默。

**不得**：为凑数而补录、把设计稿写成实录、把下面 3 条演示直接当验收结果填进检查表。

## 演示 1 · 备考冲刺（跨 4 域）

**输入**
> 下周三高数期中，把笔记整成复习方案

**① 需求明确（`library/clarity.md`）**

| 槽位 | 值 | cᵢ | wᵢ |
|---|---|---|---|
| O 对象 | 高数，**科目有、章节无（范围可唯一收窄）** | 0.8 | 1.5 |
| T 任务 | 显式（备考） | 1.0 | 1.5 |
| D 产出 | 「复习方案」，计划/卡组未定 → 歧义 | 0.5 | 1.5 |
| W 时间 | 显式（下周三） | 1.0 | 0.8 |
| C 约束 | 缺失 | 0.0 | 0.6 |
| B 背景 | 缺失 | 0.0 | 0.2 |

`Σ wᵢcᵢ = 1.5×0.8 + 1.5×1.0 + 1.5×0.5 + 0.8×1.0 = 4.25` ｜ `Σ wᵢ = 6.1`
`U = 1 − 4.25/6.1 = 0.303 > 0.30` 且关键槽 **D 歧义（`c_D=0.5`）** → **追问**
按权重挑 2 问：① 考到第几章？② 要计划还是卡组？
回收后 O=1.0、D=1.0 → `Σ wᵢcᵢ = 1.5×1.0 + 1.5×1.0 + 1.5×1.0 + 0.8×1.0 = 5.3`，`U = 1 − 5.3/6.1 = 0.131 ≤ 0.30` → **放行**。

**② 锁定域（`domains/_registry.md`）**
命中 **S2**（笔记）、**S4**（备考）、**F1**（取考试日期）、**F2**（排专注块）→ 4 域串联

**③ 域审查（`library/domain-review.md`）**
- 「把笔记整成复习方案」不是「代做作业」→ 不触发 S3 红线 ✅
- 跨域顺序按依赖：S2 → F1 → S4 → F2

**④ 执行（库内 skill 优先）**

| 序 | 域 | 库内 skill | 动作 |
|---|---|---|---|
| 1 | S2 | `lecture-to-notes` | 讲义 → 结构化笔记 + 概念图 |
| 2 | F1 | `campus-desk` | 查校历/考试安排（公开站） |
| 3 | S4 | `exam-sprint` | 生成 6 天冲刺计划 + 卡组 |
| 4 | F2 | `focus-block` | 排每日 ≤2 个番茄钟 |

**⑤ 输出**

```
【结论】6 天可救，主攻第 3–5 章，每天 2 个番茄钟。
【依据】讲义第 3–5 章 · 考试日期取自校历
【结果】① D1–D2 第 3 章 12 题
       ② D3–D4 第 4 章 + 错因归类
       ③ D5 卡组过一轮
       ④ D6 限时模拟 + 只过错题
       → 产出：notes/数分-第3-5章.md · 高数卡组.apkg · 6 条日程
【建议】火力集中在第 3–5 章，第 1–2 章只做快速回顾
【下一步】现在做 D1 前 3 题，做完回我
```

**可选保存**：仅在用户明确要求保存时，按 `library/memory.md` 规则记录非敏感学习要点；默认不读写学习档案。

## 演示 2 · 校园事务（校情横切 + L1 私密站）

**输入**
> 校园卡丢了，顺便看看我这个月网费还剩多少

**① 需求明确**
O=校园卡+网费（明确）、T=事务（明确）、W=∅、C=∅、D=结果（明确）、B=∅
关键槽 `O/T/D` 齐全且无歧义（`cᵢ = 1.0`）→ 按 `clarity.md` §5 例外 2 **放行**（不追问，避免打扰）
（按例外 2 判定，与 §3 严格阈值口径一致）

**② 锁定域** → **F1 校园事务**（两个子任务同域）

**③ 域审查**
- 「补办卡」≠「代我操作」→ 只给路径 ✅
- 网费余额属 **L1** → 可读；**缴费金额属 L3** → 若用户问「我交了多少钱」则拒绝

**④ 执行**
| 动作 | 来源 |
|---|---|
| 挂失与补卡**入口** | `references/dlut-official-sites.md` §3 §5 + `dlut-site-profiles.md` §一 |
| 网费余额 | `scripts/dlut-read.sh 网费`（L1，方案 A + 独立 Profile） |

**⑤ 输出**

```
【结论】先线上挂失冻结，再走一卡通补卡栏目；网费余额见下。
【依据】一卡通服务指南 · 校园卡与网费官方入口（均已核验）
【网址】一卡通 https://ecard.dlut.edu.cn/ ｜ 网信中心 https://its.dlut.edu.cn/

【结果】① ecard「服务指南 / 常见问题」看挂失与补卡流程
       ② ecard「自助补卡」栏目办理；部分功能仅 i大工 APP
       → 产出：网费余额 ¥xx.xx · 剩余流量 xx G
【建议】补卡地点与工本费请致电官方部门电话总表确认；缴费金额明细不予读取
【下一步】现在先登 ecard 挂失
```

**可选保存**：仅在用户明确要求时保存办理结论；默认不写入档案，不记录卡号、金额或私密站页面内容。

## 演示 3 · 毕业论文（跨 2 域 + 红线）

**输入**
> 帮我写一篇关于大模型幻觉的综述，3000 字，下周交

**① 需求明确**
O=大模型幻觉（明确）、T=写作、W=下周、C=3000 字（明确）、D=综述、B=∅
关键槽 O/T/D 齐全 → **放行**（见 `clarity.md` §5 例外 2）

**② 锁定域** → **R1 文献检索** + **S5 学术表达**（域审查后追加 **R5 学术规范** 做引用/查重/AI 声明自查 → 共 3 域）

**③ 域审查（关键）**
- 用户说「帮我**写**」→ 触发 **S5 红线**：**只给结构大纲与自查，不代写正文** ✅
- 若用户说「帮我改到不查重」→ 触发 **R5 红线**：只给规范，不代改

**④ 执行**
| 序 | 域 | 库内 skill | 动作 |
|---|---|---|---|
| 1 | R1 | `lit-map` | 出检索式 + 纳排标准 + 文献矩阵 |
| 2 | S5 | `paper-outline` | 结构大纲 + 字数分配 + 模拟审稿 |
| 3 | R5 | `integrity-check` | 引用/查重/AI 声明自查 |

**⑤ 输出**

```
【结论】结构给到，正文请你自己写；已按 3000 字分配好。
【依据】写作规范：只给结构与自查，不代写正文
【结果】① 引言 400（问题与争议）
       ② 机制 700（个性化/自动化/评估）
       ③ 证据 900（3 项实证研究，检索式已给）
       ④ 批判 700（公平性/教师角色/数据隐私）
       ⑤ 展望 300
       → 产出：lit/matrix.md · paper/outline.md
【建议】先跑一遍检索式；另需按学校要求做 AI 使用声明
【下一步】先用检索式跑一遍，回我命中数量
```

**可选保存**：仅在用户明确要求时保存检索式或大纲要点；默认不写入档案，不记录正文片段。
