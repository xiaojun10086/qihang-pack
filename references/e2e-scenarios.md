## 演示 1 · 备考冲刺（跨 4 域）

**输入**
> 下周三高数期中，把笔记整成复习方案

**① 需求明确（`library/clarity.md`）**

| 槽位 | 值 | cᵢ |
|---|---|---|
| 槽位 | 值 | cᵢ | wᵢ |
|---|---|---|---|
| O 对象 | 高数，**章节未指定** → 歧义 | 0.5 | 1.5 |
| T 任务 | 显式（备考） | 1.0 | 1.5 |
| D 产出 | 「复习方案」，计划/卡组未定 → 歧义 | 0.5 | 1.5 |
| W 时间 | 显式（下周三） | 1.0 | 0.8 |
| C 约束 | 缺失 | 0.0 | 0.6 |
| B 背景 | 缺失 | 0.0 | 0.2 |

`Σ wᵢcᵢ = 1.5×0.5 + 1.5×1.0 + 1.5×0.5 + 0.8×1.0 = 3.8` ｜ `Σ wᵢ = 6.1`
`U = 1 − 3.8/6.1 = 0.377 > 0.30` 且关键槽 **O/D 缺失** → **追问**
按权重挑 2 问：① 考到第几章？② 要计划还是卡组？
回收后 O=1.0、D=1.0 → `Σ wᵢcᵢ = 1.5×1.0 + 1.5×1.0 + 1.5×1.0 + 0.8×1.0 = 5.3`，`U = 1 − 5.3/6.1 = 0.131 ≤ 0.30` → **放行**。

**② 锁定域（`domains/_registry.md`）**
命中 **S2**（笔记）、**S4**（备考）、**F1**（取考试日期）、**F2**（排专注块）→ 4 域串联

**③ 域审查（`library/domain-review.md`）**
- 「把笔记整成复习方案」不是「代做作业」→ 不触发 S3 红线 ✅
- 跨域顺序按依赖：S2 → F1 → S4 → F2

**④ 执行（库内 skill 优先）**

| 序 | 域 | 库内 skill | 动作 |
|---|---|---|---|
| 1 | S2 | `lecture-to-notes` | 讲义 → 结构化笔记 + 概念图 |
| 2 | F1 | `campus-desk` | 查校历/考试安排（公开站） |
| 3 | S4 | `exam-sprint` | 生成 6 天冲刺计划 + 卡组 |
| 4 | F2 | `focus-block` | 排每日 ≤2 个番茄钟 |

**⑤ 输出**

```
【结论】6 天可救，主攻第 3–5 章，每天 2 个番茄钟。
【依据】讲义第 3–5 章（S2）· 考试日期取自校历（F1）
【步骤】① D1–D2 第 3 章 12 题
       ② D3–D4 第 4 章 + 错因归类
       ③ D5 卡组过一轮
       ④ D6 限时模拟 + 只过错题
【产物】notes/数分-第3-5章.md · 高数卡组.apkg · 6 条日程
【下一步】现在做 D1 前 3 题，做完回我
```

**⑥ 归档（`library/memory.md`）** → `{ws}/.learnbuddy/memory/qihang/S4-exam-prep.md` 追加薄弱点与进度。

## 演示 2 · 校园事务（G 横切 + L1 私密站）

**输入**
> 校园卡丢了，顺便看看我这个月网费还剩多少

**① 需求明确**
O=校园卡+网费（明确）、T=事务（明确）、W=∅、C=∅、D=结果（明确）、B=∅
`U ≈ 0.30` → **边界值，直接放行**（不追问，避免打扰）

**② 锁定域** → **F1 校园事务**（两个子任务同域）

**③ 域审查**
- 「补办卡」≠「代我操作」→ 只给路径 ✅
- 网费余额属 **L1** → 可读；**缴费金额属 L3** → 若用户问「我交了多少钱」则拒绝

**④ 执行**
| 动作 | 来源 |
|---|---|
| 挂失路径 + 补卡地点 + 电话 | `references/dlut-official-sites.md` §3 §5 |
| 网费余额 | `scripts/dlut-read.sh 网费`（L1，方案 A + 独立 Profile） |

**⑤ 输出**

```
【结论】先线上挂失冻结，再补卡；网费余额见下。
【网址】一卡通 https://ecard.dlut.edu.cn/ ｜ 网信中心 https://its.dlut.edu.cn/
【状态】✅ 已核验（信息库 §3 / §5）
【步骤】① ecard 或「大连理工大学网信中心」公众号挂失
       ② 凌水大厅在网信中心一楼补卡（带学生证）
【产物】网费余额 ¥xx.xx · 剩余流量 xx G
【下一步】现在先去线上挂失
【备注】缴费金额属 L3，本包不读取，请自行到 pay.dlut.edu.cn 查看
```

**⑥ 归档** → 只记「已挂失补办」结论，**不记卡号/金额**。

## 演示 3 · 毕业论文（跨 2 域 + 红线）

**输入**
> 帮我写一篇关于大模型幻觉的综述，3000 字，下周交

**① 需求明确**
O=大模型幻觉（明确）、T=写作、W=下周、C=3000 字（明确）、D=综述、B=∅
关键槽 O/T/D 齐全 → **放行**（见 `clarity.md` §5 例外 2）

**② 锁定域** → **R1 文献检索** + **S5 学术表达**

**③ 域审查（关键）**
- 用户说「帮我**写**」→ 触发 **S5 红线**：**只给结构大纲与自查，不代写正文** ✅
- 若用户说「帮我改到不查重」→ 触发 **R5 红线**：只给规范，不代改

**④ 执行**
| 序 | 域 | 库内 skill | 动作 |
|---|---|---|---|
| 1 | R1 | `lit-map` | 出检索式 + 纳排标准 + 文献矩阵 |
| 2 | S5 | `paper-outline` | 结构大纲 + 字数分配 + 模拟审稿 |
| 3 | R5 | `integrity-check` | 引用/查重/AI 声明自查 |

**⑤ 输出**

```
【结论】结构给到，正文请你自己写；已按 3000 字分配好。
【依据】库内 skill paper-outline · lit-map
【步骤】① 引言 400（问题与争议）
       ② 机制 700（个性化/自动化/评估）
       ③ 证据 900（3 项实证研究，检索式已给）
       ④ 批判 700（公平性/教师角色/数据隐私）
       ⑤ 展望 300
【产物】lit/matrix.md · paper/outline.md
【下一步】先用检索式跑一遍，回我命中数量
【红线】只给结构与自查，不代写；需按学校要求做 AI 使用声明
```

**⑥ 归档** → 记「检索式 + 大纲」，不记正文片段。
