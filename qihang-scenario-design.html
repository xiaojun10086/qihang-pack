◈场景概述

新生入学后真正卡住他们的，不是"不会用 AI"，而是没人把散落的工具串成一条线——课表在教务、DDL 在群消息、笔记在备忘录、习题在纸面、情绪在心里。本方案把"学习"与"生活"两条线合并成一个可插拔的 Skill 包，由编排器统一调度。

真实需求与现存痛点

😵 痛点 1 · 需求说不清

"我高数要挂了怎么办"——不给章节、不给时间、不给目标。AI 只能给一篇正确的废话。

🧩 痛点 2 · 工具是散的

课表、日历、笔记、错题、文献各一个 App，新生第一学期要装 8 个工具，最后都弃用。

📉 痛点 3 · 学习与生活割裂

作息崩 → 上课困 → 笔记缺 → 期末崩。但没人把"作息"和"成绩"连起来看。

🧭 痛点 4 · 无长期记忆

今天问了，明天重来。没有人记得"你上次错在换元积分"。

支撑依据（可替换为本人经历/访谈摘录）：新生群高频问句集中在"课表怎么看""作业什么时候交""XX 老师给分吗""高数怎么学"；这四类恰好分布在生活事务与学业节奏两端，说明需求天然是跨域的。

1① 输入过程：提示词拆解 + 需求明确

入口只有一句话，但这句话必须被"拆成槽位、量化不确定度、追问到确定"。

1.1 提示词拆解（Slot Parsing）

把用户原话映射到 6 个槽位（空槽位显式留空，不猜）：

槽位含义示例（原话："高数快挂了")
对象 O具体课程 / 科目 / 章节 / 事件高数？哪一章？
任务 T答疑 / 备考 / 笔记 / 事务 / 规划备考？（推断）
时间 W截止时间 / 可投入时长 / 周期（空）
约束 C形式 / 字数 / 工具 / 禁忌（空）
产出 D期望交付物（提纲/卡组/计划/文档）（空）
背景 B年级 / 专业 / 既往薄弱点 / 情绪状态新生；情绪焦虑（推断）

1.2 需求明确：不确定性 > 5% 必须反复追问

澄清门（Clarification Gate）算法

1) 对每个槽位 i 自评置信度 c_i ∈ [0,1]
   （c_i 由"是否显式提及 / 是否可唯一推断 / 是否与上下文冲突"三项均值给出）
2) 计算整体不确定度：   U = 1 − ∏ c_i
3) 判定：  U ≤ 5%  → 直接执行
           U > 5%  → 触发澄清，最多 3 轮，每轮 ≤ 3 问
4) 提问优先级（高杠杆优先）：时间 W(3.0) > 对象 O(2.5) > 产出 D(2.0)
                            > 约束 C(1.5) > 背景 B(1.0) > 任务 T(0.5)
5) 3 轮后仍未达标 → 按最大后验假设执行，并在输出顶部显式声明
   「⚠️ 假设：…；如不符请纠正」

对照示例

用户："高数快挂了"

  • 拆解：O=高数（c=0.6）、T=备考（c=0.7）、W=∅（c=0.1）、C=∅（c=0.5）、D=∅（c=0.3）、B=新生（c=0.8）
  • U = 1 − (0.6×0.7×0.1×0.5×0.3×0.8) ≈ 99.5% > 5% → 必须澄清
  • 按权重生成 3 问：
    ① 距离考试/补考还有几天？（W）
    ② 卡在哪几章——极限、导数、积分、级数？（O）
    ③ 想要"一周冲刺计划"还是"错题卡组"？（D）
  • 收集答案 → 重算：O=0.95, W=0.95, D=0.9 … → U ≈ 3.2% ≤ 5% → 放行，进入选择过程
设计要点：不是"多问"，而是"算出来该问才问"。高置信度场景（如"帮我把这段录音转文字"）一次都不追问，避免打扰。

2② Skill 选择过程：路由 + 安装/调用

澄清完成后，编排器按「任务 T × 产出 D」查路由表，命中能力域后依次执行三步：探测 → 安装（若缺）→ 调用。

3③ 输出过程：要点式、尽量简略

统一模板，默认 ≤ 6 条要点，先结论后步骤；细节折叠进"展开可见"，不刷屏。

统一输出模板

【结论】  一句话给出可执行答案
【依据】  ≤2 条关键信息（来自哪个 Skill / 哪份材料）
【步骤】  ≤5 条编号动作，每条 ≤15 字
【产物】  文件/卡组/日程的落点（可点击）
【下一步】1 条——给出唯一推荐动作
【假设】  仅当触发"3 轮未澄清"时出现，一行说明

示例输出（承接上例：高数期中 7 天冲刺）

【结论】7 天可救，重点攻"换元积分 + 级数判敛"，每天 2 个番茄钟。

【步骤】

  1. D1–D2　补换元积分 12 道典型题
  2. D3–D4　级数判敛 8 道 + 错因归类
  3. D5　　错题卡组过一轮（Anki）
  4. D6　　限时模拟卷 1 套
  5. D7　　只过错题与公式速查

【产物】gws-tasks 已生成 7 条 DDL · 高数-换元积分.apkg 可导入

【下一步】现在做 D1 的前 3 道，做完回我。

简略原则：①能一句话不写一段；②能列表不写散文；③过程细节默认折叠；④每次只给一个下一步动作，避免选择瘫痪。
