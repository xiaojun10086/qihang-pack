# 输出规范（Level 1 · output-spec）

> 1 级 skill 库的职责之三。**所有 3 级 skill 的输出都必须走本模板，并过 `output-checklist.md` 校验。**

## 1. 统一模板（默认 ≤ 6 条要点）

```
【结论】  一句话可执行答案
【依据】  ≤ 2 条（来自哪个 skill / 哪份材料 / 信息库哪一节）
【步骤】  ≤ 5 条编号动作，每条 ≤ 15 字
【产物】  文件 / 卡组 / 日程 / 网址的落点
【下一步】只给 1 个动作
【假设】  仅当触发"3 轮未澄清"时出现
```

## 2. 变体

**校情查询（走 references/dlut-official-sites.md）**

```
【结论】+【网址】+【状态 ✅/⚠️】+【备注】
```

**跨域串联**

```
每个域给 1 条结论 → 末尾合成一张 ≤ 5 行的行动清单
```

**降级**

在输出**首行**加：`[已降级: 原 skill → 备用 skill]`

**追问（澄清门触发时）**

```
【还需确认】① … ② … ③ …（≤3 问，按 时间>对象>产出>约束>背景>任务 排序）
```

## 3. 简略四原则

1. 能一句话不写一段
2. 能列表不写散文
3. 过程细节默认折叠，不刷屏
4. 每次只给**一个**下一步动作（避免选择瘫痪）

## 4. 交付前校验（强制）

逐项过 `library/output-checklist.md` 的 **7 项硬校验**：
要点数 ≤6 · 结论前置 · 下一步唯一 · 来源标注 · URL 全部在库 · 降级已标注 · 敏感域无诊断。
**任一项不过 → 重新生成，不得交付。**

## 5. 输出后动作

把「薄弱点 / 错因 / 结论」写入学习档案（Learning Records），下次触发时自动带出。

**禁止写入档案的域**：
- **F3 身心与社交**（情绪细节、心理记录）—— 会话结束即丢弃
- **F5 健康与运动**（病史、检查结果）
- 任何来自私密站的原始页面内容

## 6. 反例（这些输出不合格）

| 不合格输出 | 违反项 |
|---|---|
| 列了 12 条要点 | 校验 1（要点数） |
| 先讲背景三段才给结论 | 校验 2（结论前置） |
| 建议「先做 A，也可以做 B，或者 C」 | 校验 3（下一步唯一） |
| 给出 `https://xyz.dlut.edu.cn/` 但信息库没有 | 校验 5（URL 合规） |
| 对 F3 用户说「你这是典型的焦虑症」 | 校验 7（敏感域） |
