# 学习档案与记忆对接（Level 1 · memory）

> 可选学习档案说明。默认不读取历史记录、不搜索会话、不写入记忆；仅在用户明确要求延续或保存学习记录时使用。

---

## 1. 写入什么（四类，别多写）

| 类型 | 内容 | 例子 |
|---|---|---|
| **薄弱点** | 具体到章节/题型的未掌握处 | 「数学分析：确界原理的证明」 |
| **错因** | 错误类型，不是题目 | 「换元后忘记还原变量」 |
| **进度** | 已完成到哪 | 「第 3 章 12/12 题，第 4 章 0/8」 |
| **上次结论** | 上次给的可执行答案 | 「6 天冲刺计划，主攻第 3–5 章」 |

**不写**：对话原文、情绪描述、私密站页面内容、未确认的猜测。

---

## 2. 写到哪（分层）

### 2.1 LearnBuddy / WorkBuddy 三层

| 层 | 路径 | 写什么 | 频次 |
|---|---|---|---|
| 用户级 | `~/.learnbuddy/MEMORY.md` | 跨项目长期约定（作息窗口、常修课程、偏好） | 仅在确认为长期时写 |
| 工作区日志 | `{ws}/.learnbuddy/memory/YYYY-MM-DD.md` | 用户明确要求保存的当日学习要点 | 仅按用户请求 |
| 工作区笔记 | `{ws}/.learnbuddy/memory/MEMORY.md` | 稳定事实（薄弱点、错因类型、复考计划） | 稳定后才写 |

### 2.2 本包自有的按域档案

```
{ws}/.learnbuddy/memory/qihang/
├── S1-course-qa.md
├── S4-exam-prep.md
├── R1-literature.md
└── ...
```

**每域一文件，格式固定**：

```markdown
# S4 备考与记忆 · 学习档案

## 薄弱点
- 数学分析 · 级数判敛：比较判别法的极限形式易混  [2026-10-01]

## 错因
- 换元后忘记还原变量  [2026-10-01]

## 进度
- 第 3 章 12/12 · 第 4 章 3/8

## 上次结论
- 6 天冲刺计划，主攻第 3–5 章，每天 2 个番茄钟  [2026-10-01]

## 待复考
- [ ] 比较判别法极限形式（2 天后）
```

## 3. 按用户请求读取或保存

| 时机 | 动作 |
|---|---|
| 用户要求延续旧计划 | 只读用户指定的档案或其主动提供的内容 |
| 用户要求保存本次结果 | 仅保存与请求直接相关的学习要点；写入前确认内容与位置 |
| 用户未提出保存/延续 | 本次正常作答，不读历史、不写档案 |

**带出话术**（示例）：`你上次在「比较判别法极限形式」上栽过，这次先做 2 道再往下。`

### 3.1 当前会话的连续性

- 当前对话中可沿用用户已提供且仍相关的目标、限制、进度和决定；不把推测补成用户事实。
- 这只表示利用当前会话上下文，不代表写入档案或能跨会话检索。
- 用户要求续接，但当前上下文里没有记录时，请其提供上一轮摘要或明确指定档案；不可假称记得。
- 用户明确要求保存后，先复述拟保存的最少必要要点及落点供确认；未确认前不落盘。
- 用户要求停止记忆、撤回保存或忘记某项时，不再读取/使用该项，并按其要求处理已有档案；不得另存撤回内容。

## 4. 红线（不得写入，任何一层都不行）

| 域 | 禁止写入 |
|---|---|
| **F3 身心与社交** | 情绪细节、心理记录、人际纠纷内容 —— **会话结束即丢弃** |
| **F5 健康与运动** | 病史、检查结果、用药信息 —— **整域**（锻炼/饮食/作息等亦不写） |
| **F4 财务与安全** | 金额明细、债务、账户流水（**排除后可写其余**） |
| **F6 军训与志愿** | 伤病记录（**排除后可写其余**） |
| **第三方隐私** | 他人健康 / 财务 / 心理信息，一律不写 |
| 私密站 | 任何从登录站点读到的原始页面内容 |
| 通用 | 身份证 / 银行卡 / 家庭信息 / 账号凭证 |

**跨域时的剥离规则**：一次会话涉及多域时，**逐段判定可写入性** ——
敏感域（F3 / F5 整域）的段落**整段丢弃**，其余域的段落**照常写入**；
**不得**因为「本次涉及 F3」就把可归档的学业内容（如 S4 复习计划）一并丢掉，
**也不得**把 F3 的情绪细节改写成「中性描述」后混入其他域档案。

---

## 5. 用户控制

- **一键清空**：`bash scripts/qihang.sh records --clear`（先备份再清）
- **查看**：`bash scripts/qihang.sh records`
- 只有用户明确要求时才读写；用户说「别记这个」→ 不写入，且不在档案中另作记录

---

## 6. 目标平台与回落落点

本包只面向 **LearnBuddy / WorkBuddy** 单一目标平台，三层记忆见 §2.1，无需为其他平台另设落点。

| 场景 | 落点 |
|---|---|
| 正常（LearnBuddy / WorkBuddy） | `{ws}/.learnbuddy/memory/qihang/<域ID>.md` |
| 平台目录不可写时回落 | `<包根>/records/<域ID>.md`（由 `scripts/qihang.sh records` 管理） |
