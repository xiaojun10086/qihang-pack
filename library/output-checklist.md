# 输出校验清单（Level 1 · 交付前必过）

> 所有 3 级 skill 的输出，交付前逐项自检。**任一项不过 → 重新生成，不得交付。**
> 域专属附加校验覆盖 **20 域**（避免只覆盖单域、护栏被绕过）。

## 一、7 项通用硬校验

| # | 校验项 | 通过标准 | 不过怎么办 |
|---|---|---|---|
| 1 | **要点数** | 除【结论】外 ≤ 6 条（口径见 `output-spec.md` §1.1） | 砍到 6 条以内 |
| 2 | **结论前置** | 第一行是【结论】且是一句可执行答案 | 重写结论，去掉铺垫 |
| 3 | **下一步唯一** | 末尾恰好 1 个【下一步】动作 | 多个候选 → 只留 1 个 |
| 4 | **来源标注** | 【依据】≤ 2 条，写明来自哪个 skill / 材料 / 信息库哪节 | 补来源；无来源则标注降级 |
| 5 | **URL 合规** | 出现的 dlut.edu.cn 网址**必须在信息库内**：标注 ✅ 可直接给；标注 ⚠️ 须同时提示「待核实」；无状态标注的结构性条目（校区 / 院系等）须注明出处小节 | 删除臆造 URL，改答未收录 |
| 6 | **降级标注** | 若发生降级（触发条件见 `output-spec.md` §2.1），首行有 `[已降级: 原 → 备]` | 补标注 |
| 7 | **红线拦截** | 若命中任一红线，输出走「红线拒绝」变体且**给出合规替代** | 改为拒绝 + 出路 |

| 域 | 附加校验（必须逐条确认） |

| **S4** | 未代考、未提供/买卖真题答案 |
| **S5** | 未代写正文；参考文献均可核验 |

| **F4** | 未推荐借贷/分期/投资；**未代操作缴费/代缴/转账**；**已受害场景已给止损路径**（挂失+96110+110） |
