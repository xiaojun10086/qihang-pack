# 输出校验清单（Level 1 · 交付前必过）

> 所有 3 级 skill 的输出，交付前逐项自检。**任一项不过 → 重新生成，不得交付。**

## 7 项硬校验

| # | 校验项 | 通过标准 | 不过怎么办 |
|---|---|---|---|
| 1 | **要点数** | ≤ 6 条（不含标题） | 砍到 6 条以内，细节折叠 |
| 2 | **结论前置** | 第一行是【结论】且是一句可执行答案 | 重写结论，去掉铺垫 |
| 3 | **单一下一步** | 末尾恰好 1 个【下一步】动作 | 多个候选 → 只留 1 个，其余移入档案 |
| 4 | **来源标注** | 【依据】≤ 2 条，且写明来自哪个 skill / 材料 / 信息库哪节 | 补来源；无来源则降级为通用建议并标注 |
| 5 | **URL 合规** | 出现的 dlut.edu.cn 网址**必须在信息库内**且有 ✅/⚠️ 标记 | 删除臆造 URL，改答「信息库未收录」 |
| 6 | **降级标注** | 若发生过降级，首行有 `[已降级: 原 → 备]` | 补标注 |
| 7 | **敏感域拦截** | 若为 F3，输出中**无诊断性结论**，且本次内容不写入档案 | 删除诊断表述，改为倾听 + 转介 |

## 域专属附加校验

| 域 | 附加校验 |
|---|---|
| S3 / S5 / F7 / R5 | 确认**未代写正文**，只给骨架/结构/自查 |
| F1 / F4 | 确认**未代操作系统**，只给入口 |
| F3 | 确认**未做诊断**；危机信号已转介 |
| F5 | 确认**未给用药建议**；严重症状已给就医路径 |
| 私密站相关 | 确认**只读、未落盘、未导出凭证**；会话已 `close --all` |
