# 输出校验清单（Level 1 · 交付前必过）

> 所有 3 级 skill 的输出，交付前逐项自检。**任一项不过 → 重新生成，不得交付。**
> 域专属附加校验覆盖 **20 域**（避免只覆盖单域、护栏被绕过）。
> 本清单与 `output-spec.md` 逐条对齐；改动任一方必须同步另一方。

## 一、7 项通用硬校验

| # | 校验项 | 通过标准 | 不过怎么办 |
|---|---|---|---|
| 1 | **结构不过度压缩** | ≤6 仅限制字段标签，不限制内容点（见 `output-spec.md` §1.3）；对详细教学/结构化请求，覆盖承诺范围内的关键定义、条件、推导、例子及限制 | 补回遗漏内容；按层级分节。若单轮容量不够，明确分轮范围，不可伪称已完整覆盖 |
| 2 | **结论前置** | 第一行是【结论】且是一句可执行答案；若交付文件，文件首行与回复【结论】表达一致 | 重写结论，去掉铺垫并同步文件首行 |
| 3 | **下一步唯一** | 末尾恰好 1 个【下一步】动作 | 多个候选 → 只留 1 个 |
| 4 | **只讲结果与建议（零内部名）** | ①【依据】≤ 2 条且**只写外部来源**（材料 / 官网 / 规范 / 已核验入口 / 合规边界）；② 输出块内**不出现** skill 名、域代号（`S1`–`R6`）、脚本名、库文件名、内部流程词、`红线`（完整词表见 `output-spec.md` §1.2）；③ 不写推理过程叙事（"我先…然后…"） | 删内部名 → 改写为能力级表述；过程叙述折叠；依据无外部来源则该行删掉 |
| 5 | **URL 合规** | 出现的 dlut.edu.cn 网址**必须在信息库内**：标注 ✅ 可直接给；标注 ⚠️ 须同时提示「待核实」；无状态标注的结构性条目（校区 / 院系等）须注明出处小节 | 删除臆造 URL，改答未收录 |
| 6 | **降级标注** | 若发生降级（触发条件见 `output-spec.md` §2.1），首行有 `[已降级] 由「原能力」改为「备能力」`，且**不含** skill 名 / 域代号 | 补标注并改能力级写法 |
| 7 | **红线拦截** | 若命中任一红线，输出走「红线拒绝」变体（【结论】拒绝 + 【依据】合规边界 + 【替代方案】 + 【下一步】） | 改为拒绝 + 出路 |

## 二、域专属附加校验（覆盖 20 域）

| 域 | 附加校验（必须逐条确认） |
|---|---|
| S1 | 未产出可直接提交的答案 |
| S2 | 产出用途为自用；若用于提交已改锁 S3 |
| **S3** | 未代写正文；**未编造数据**（编造须提示 R5） |
| **S4** | 未代考、未提供/买卖真题答案 |
| **S5** | 未代写正文；参考文献均可核验 |
| **F1** | 未代操作系统（选课/提交）；**缴费/代缴已改锁 F4**；L3 项未读取 |
| **F3** | 无诊断性结论；危机信号已转介；**本次内容未写入任何记忆层** |
| **F4** | 未推荐借贷/分期/投资；**未代操作缴费/代缴/转账**；**已受害场景已给止损路径**（挂失+96110+110） |
| **F5** | 未给用药建议；**急症已给 120**；**第三方健康隐私未分析/未外传**；**本次内容未写入任何记忆层** |
| **F6** | 未鼓励带病硬撑；**伤病已改锁 F5** |
| **F7/F8** | 未编造经历、学历、获奖、时间线；文书只给结构 |
| **R1** | **未生成/未补全任何未核验引文** |
| **R2** | 未补造/篡改数据；**已列出「不能下的结论」** |
| **R4/R5** | 未代投稿；未代改以规避查重；未隐藏 AI 使用痕迹 |
| **S6** | 作文只标错未重写；未代写课程作业 |
| **F2** | 未代做学业规划（应改锁 S4） |
| **R3** | 未代做课业代码；未代操作教务系统 |
| **R6** | **只输出公开信息**；未搜集非公开个人信息；未编造 URL/电话/姓名/职称；信息带核验状态 |

## 三、自检话术（内部执行，不输出给用户）

```
□ 结构适当；详细请求无关键内容遗漏    □ 结论前置（文件首行一致）    □ 下一步明确且唯一（适用时）
□ 零内部名（skill 名 / 域代号 / 脚本名 / 库文件名 / 流程词 / 「红线」）
□ 只讲结果与建议，无推理过程叙事
□ URL 全部在库    □ 降级已标注且为能力级    □ 红线已拦且有替代方案
□ 本域附加校验已逐条确认
```
