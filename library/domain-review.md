# 域审查（Level 1 · domain-review）

> 1 级 skill 库的职责之二。**负责锁定域、拦截越界、处理跨域与无域情况。**

## 1. 锁定流程

```
输入：已澄清的 6 槽位
  ↓
① 取 T(任务) + O(对象) 作为主键，去 domains/_registry.md 匹配触发词
  ↓
② 命中 1 个域      → 锁定，读 domains/<域>/_domain.md
   命中 N 个域      → 跨域串联，按依赖排序，逐个执行 3 级 skill
   命中 0 个域      → 进入 §3 兜底
  ↓
③ **校验「该域有没有覆盖本细分场景的库内 skill」**（**必经步骤**，不得跳过）
   有对口 skill → 直接用（库内唯一通道）
   无对口 skill → 按序降级，**两条分支都要在输出首行标 `[已降级: 原 → 备]`**：
     a) **同域另一个库内 skill 降级覆盖** → 备 = 该 skill 名
     b) **明确告知**「本包该细分场景暂无对口 skill」，给该域的**通用框架** → 备 = 域通用框架；
        并在档案记「缺口」（见 `library/memory.md`）
        > 成文规则见 `library/general-fallback.md` §3：以该域 `_domain.md` 的「域边界 + DUT 绑定点」为骨架，**不放弃域锁定**。
   ❌ **禁止**：因为「该域没有对口 skill」就放弃域锁定、或改锁到不相干的域
   ❌ **禁止**：跳过本条直接下发 ④ —— 「需求规模超出 skill 定位」也属无对口 skill，同样走降级
```

## 2. 越界拦截

锁定域后，**用该域的 `_domain.md`「不覆盖」条目复核一次**。若需求落在「不覆盖」里，必须改锁到 `→` 指向的域。

常见越界：

| 表面像 | 实际属于 | 判据 |
|---|---|---|
| 让我写作业 | S3 作业与考核 | 只给结构，不代写 |
| 讲一下这道题 | S1 课程答疑 | 分步讲解，不代做 |
| 帮我规划考研 | F7 升学深造 | 规划路径，不代写文书 |
| 我很焦虑 | F3 身心与社交 | 倾听+转介，**不做诊断** |
| 帮我查重 | R5 学术规范 | 给规范与自查，不代改 |

## 3. 无域兜底

命中 0 个域时，按顺序尝试：

1. **模糊匹配**：用同义词重试触发词表（如「挂科」→「复习/考试」）
2. **跨域组合**：拆成两个已知域分别处理
3. **降级为通用问答**：明确告知「本包暂无该方向的域」，**按 `library/general-fallback.md` §2 六步通用框架**给出结构完整、可执行、标注了不确定性的答复，并在学习档案记录该缺口
   > **不得**只回「本包暂无这个方向」一句了事 —— 零 skill 命中也要产出【结论】与【下一步】。
4. **绝不硬塞**：不得把需求塞进不相干的域
5. **同义重试的边界**：同义重试**只在「命中 0 个域」之后**使用，**不参与权重计算**；
   **红线词不允许用同义词规避** —— 「降重」「去重」「改写一遍让它不重复」等一律按 `R5` 红线处理。
6. **极模糊输入的兜底**：出现**身心两可**的极模糊输入（如「我不舒服」「我很难受」「我状态不好」），
   **必须先按安全兜底反问 1 问**（「是身体不适，还是心里不舒服？」），
   ❌ **不得直接判 F5 或 F3 后作答** —— 漏判 `F3` 会绕过危机转介红线。
7. **skill 步骤要求的信息库不可得时**：若 3 级 skill 的步骤要求某项 DUT 信息、
   而 `references/dlut-*.md` 无该条目 → 按 `SKILL.md` 硬规则 2 固定回复「**信息库未收录**」
   ＋ 给官网入口，**不得编造**；不得因为「skill 说要有」就默认存在。

## 4. 跨域串联模板

```
「下周三高数期中，把笔记整成复习方案」
  → S2 课堂与笔记（笔记归一）
  → F1 校园事务 / 校历（取考试日期）
  → S4 备考与记忆（生成卡组与排程）
  → F2 作息与专注（排专注块）
```

串联输出时，每条只给**该域**的结论，最后合成一张行动清单。
