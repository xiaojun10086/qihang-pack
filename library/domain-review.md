# 域审查（Level 1 · domain-review）

> 1 级 skill 库的职责之二。**负责锁定域、拦截越界、处理跨域与无域情况。**

> **按需加载**：学习与公开信息的普通单点请求走核心快路径；本文件用于复杂、跨域、边界不清或没有匹配 skill 的情况，不要求每次调用。

## 1. 锁定流程

```
输入：用户当前的任务与目标
  ↓
① 取对象 + 任务作初步路由；对复杂或模糊请求做**两级匹配**：
   a) 看 `domains/_registry.md` 定位候选核心域；
   b) 仅在边界不清或候选冲突时，查看相应 `_domain.md` 的覆盖范围与触发词。
  ↓
② 一个清晰目标 → 选一个最贴合的 skill；用户明确提出多个目标时才跨域拆分。
   没有直接匹配 → 说明能力边界，仍给可执行的一般方法或可信来源入口。
  ↓
③ 先复核安全、隐私与学术诚信边界；只有复杂任务才加载本文件的完整检查与跨域流程。
```

**不强制降级链**：普通请求不需要遍历所有同域 skill 或搜索外部 skill 平台。外部桥接仅在用户要求或确有特定工具需求时按需使用；无匹配时不硬塞不相关域。

## 2. 越界拦截

锁定域后，**双向复核该域的「覆盖」与「不覆盖」**：

1. **正向核对**：本次目标必须能落入 `_domain.md` 的「覆盖」范围。若域声明未提及，但域内某个 skill 的覆盖明确承接，应按 skill 定位执行，并将差异视为域声明缺项；不得因此绕过库内路由。
2. **反向核对**：用「不覆盖」条目复核一次。若需求落在「不覆盖」里，必须改锁到 `→` 指向的域。

常见越界：

| 表面像 | 实际属于 | 判据 |
|---|---|---|
| 让我写作业 | S3 作业与考核 | 只给结构，不代写 |
| 讲一下这道题 | S1 课程答疑 | 分步讲解，不代做 |
| 帮我规划考研 | F7 升学深造 | 规划路径，不代写文书 |
| 我很焦虑 | F3 身心与社交 | 倾听+转介，**不做诊断** |
| 帮我查重 | R5 学术规范 | 给规范与自查，不代改 |

### 2.1 越界词只是初筛（仲裁顺序）

`trigger.out_of_scope_markers` 命中的词**不具终判效力**。归属按固定**仲裁顺序**：

1. **需求主键 `T`(任务) + `O`(对象)** 落在 20 域之一 → **接管**（越界词只是用途或背景）；
2. 主键落不到任何域 → 再看是否命中越界词 → 命中则**不接管**；
3. 两者都不成立 → **不接管**（宁可不接管，也不硬塞域）。

> **顺序不可交换**：越界表 = **初筛**，主键 = **终判**；多义词归属**只由主键决定**。
> 唯一副本 = `config.yaml` 的 `trigger.arbitration`；不变式由 `scripts/aligncheck.py` U 组断言。

## 3. 无域兜底

命中 0 个域时：

1. 可用自然同义词理解用户表述，但不因关键词命中强行接管。
2. 只有用户确实提出多个目标时，才将其拆到多个已知域。
3. 直接说明本包没有专用方法，再按 `library/general-fallback.md` 给出简洁、可执行且标注不确定性的帮助；不要求外部搜索，也不自动写入档案。
4. **绝不硬塞**：不得把需求塞进不相干的域。
5. **同义重试的边界**：同义重试只在无直接匹配时使用，**不参与权重计算**；
   **红线词不允许用同义词规避** —— 「降重」「去重」「改写一遍让它不重复」等一律按 `R5` 红线处理。
6. **极模糊输入的兜底**：出现**身心两可**的极模糊输入（如「我不舒服」「我很难受」「我状态不好」），
   **必须先按安全兜底反问 1 问**（「是身体不适，还是心里不舒服？」），
   ❌ **不得直接判 F5 或 F3 后作答** —— 漏判 `F3` 会绕过危机转介红线。
7. **skill 步骤要求的信息库不可得时**：若 3 级 skill 的步骤要求某项 DUT 信息、
   而 `references/dlut-*.md` 无该条目 → 按 `SKILL.md` 硬规则 2 固定回复「**信息库未收录**」
   ＋ 给官网入口，**不得编造**；不得因为「skill 说要有」就默认存在。

## 4. 跨域串联模板

```
「下周三高数期中，把笔记整成复习方案」
  → S2 课堂与笔记（笔记归一）
  → F1 校园事务 / 校历（取考试日期）
  → S4 备考与记忆（生成卡组与排程）
  → F2 作息与专注（排专注块）
```

串联输出时，每条只给**该域**的结论，最后合成一张行动清单。
