启航

大连理工大学（大工 / DUT）学生的学习、信息搜集与校务助手

v4.1.0 25 个 skill 宿主无关 MIT

是什么

「启航」是一个扁平技能包：25 个 skill 覆盖「学习 → 巩固 → 产出 → 数据代码 → 检索 → 校务」六个阶段， 面向大工学生强绑定校内公开站与需登录平台。

用法是直接用自然语言说需求——不需要斜杠命令，也不需要先选分类。 入口会判断需求属于哪个阶段，再调用对应 skill。

有什么功能

学习

  • explain-stepwise 分步讲解
  • error-diagnose 错因归因
  • faster-cycle 系统学一门课
  • lecture-to-notes 讲义整理成笔记
  • reading-note 文献精读笔记
  • lang-drill 语言能力练习

巩固

  • exam-sprint 考前冲刺排程
  • recall-schedule 记忆与间隔重复

产出

  • assignment-plan 作业与小组任务拆解
  • lab-report 实验报告骨架
  • paper-outline 论文结构与答辩
  • cite-normalize 引用格式与文献管理

数据代码

  • data-lab 实验数据与统计
  • code-mentor 编程与科研代码

检索

  • campus-search 校园公开信息
  • advisor-finder 导师与教师资料
  • notice-track 通知与截止节点
  • lit-fetch 文献检索与获取
  • citation-verify 引文核验

校务

  • campus-desk 校园事务办理路径
  • course-select 选课与培养方案
  • campus-proof-guide 证明开具
  • dorm-life 宿舍、报修、离校
  • portal-operator 校内平台代操作

三条共享行为准则贯穿全部 skill：先给可用的答案 · 区分「解释」与「代做」 · 涉及事实必须给来源。 另有高于全部准则的安全兜底（心理危机、诈骗、急症直达对应通道）。
