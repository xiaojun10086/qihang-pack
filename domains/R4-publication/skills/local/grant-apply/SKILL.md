# 基金申报

- **归属域**：`R4` 学术产出与投稿（科研类）
- **来源**：自建
- **覆盖主体**：D 博士 · T 教师
- **定位**：面向基金申报书的结构骨架与评审维度自查（创新性 / 可行性 / 前期基础 / 预算合理性），只给框架与检查项。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：申报书结构骨架、评审维度自查、预算合理性检查、时间线
- 不覆盖：代写正文（见红线）；专利（→`patent-draft`）；伦理审查（→`R5` `ethics-review`）

## 执行步骤

1. 明确申报类别与指南要求
2. 给申报书结构骨架（立项依据 / 目标 / 内容 / 方案 / 基础 / 预算）
3. 按评审维度自查（创新性 / 可行性 / 前期基础 / 团队）
4. 检查预算科目与说明的合理性
5. 排申报时间线与材料齐备检查

## 方法库 · 判定细则

| 评审维度 | 自查问题 |
|---|---|
| 创新性 | 与已有工作差异点是什么 |
| 可行性 | 方法与条件是否支撑 |
| 前期基础 | 有无预研数据 |
| 预算 | 科目是否合规、有无说明 |

**判据**：立项依据写不出「现有研究的缺口」→ 创新性不成立，先补。

## ⚠️ 红线（不得绕过）

- **不代投稿、不代操作系统** —— 只给自检清单与材料清单
- 不伪造作者署名与利益冲突声明 —— 署名变更须经**全体作者确认并走期刊变更流程**；利益冲突只能据实声明（自查 → `R5`）
