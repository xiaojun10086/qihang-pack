# 专利交底书

- **归属域**：`R4` 学术产出与投稿（科研类）
- **来源**：自建
- **覆盖主体**：M 硕士 · D 博士
- **定位**：给专利交底书的结构骨架与「技术问题—方案—效果」三要素自查，梳理权利要求思路，不代写不代提交。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：专利交底书结构、技术三要素自查、权利要求思路梳理、检索与新颖性自查
- 不覆盖：代写 / 代提交（见红线）；论文投稿（→`submit-kit`）；学术规范（→`R5`）

## 执行步骤

1. 复述要保护的技术方案与要解决的问题
2. 用「技术问题—技术方案—技术效果」三要素自查
3. 给交底书结构（技术领域 / 背景 / 方案 / 实施例 / 附图）
4. 梳理独立 / 从属权利要求的层次思路
5. 提示先做检索与新颖性自查，提交由本人 / 代理完成

## 方法库 · 判定细则

**三要素自查**：

| 要素 | 合格标准 |
|---|---|
| 技术问题 | 现有技术存在什么缺陷 |
| 技术方案 | 用什么手段解决，可复现 |
| 技术效果 | 相比现有技术改善在哪 |

**判据**：三要素缺任一 → 交底书不完整，先补再谈权利要求。

## ⚠️ 红线（不得绕过）

- **不代投稿、不代操作系统** —— 只给自检清单与材料清单
- 不伪造作者署名与利益冲突声明 —— 署名变更须经**全体作者确认并走期刊变更流程**；利益冲突只能据实声明（自查 → `R5`）
