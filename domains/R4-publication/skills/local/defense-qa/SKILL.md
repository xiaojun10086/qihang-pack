# 答辩问答演练

- **归属域**：`R4` 学术产出与投稿（科研类）
- **来源**：方法论思路参考 `Gabberflast/academic-pptx-skill`（实抓 frontmatter 标注专有许可证 → **零内容摘录**，以本项目语言全量重写 + DUT 特化）
- **定位**：把「被质询」变成可以排练的环节——上场前先自红队，答辩内容只讲守得住的部分。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：答辩 / 汇报 / 会议质询的问题预测、应答框架、内容取舍（讲什么藏什么）
- 不覆盖：演示内容结构 → `S5` `argument-slides`；返修信结构 → `rebuttal-structure`；投稿流程 → `submit-kit`

## 执行步骤

1. **内容防守筛选**：把工作分成两类——「守得住」（有数据 / 推导支撑）与「讲不顺」（论证链有断点）；断点内容移入「已知局限」主动交代，**不让评委先发现**
2. **幽灵测试**：只读幻灯片标题（或论点清单）连读——标题讲不通的地方就是评委会追问的地方，先补论证再上场
3. **三问自审（红队）**：站在最挑剔评委视角，对核心论点提 3 个最致命的问题（如「样本量怎么定的」「为什么不采用 B 方案」），逐一生成「应答骨架」：承认边界 → 给证据 → 给下一步
4. **预设问题清单**：按评委类型生成 10 个高概率问题（方法 3 个 / 结果 3 个 / 意义 2 个 / 局限 2 个），每个配「20 秒短答 + 展开版」两档
5. **应答纪律**：
   - 听完再答，不打断
   - 不会的问题答「这是我目前的边界，我的下一步计划是——」（承认边界比硬编强）
   - 每个回答收在结论上，不跑题
6. 输出「预设问题清单 + 应答骨架 + 已知局限声明」

## 方法库 · 判定细则

**质询分类与应答纪律**：

| 质询类型 | 典型问法 | 应答策略 |
|---|---|---|
| 事实型 | 数据哪来的 | 直给来源与核验状态 |
| 方法型 | 为什么用这个检验 | 讲前提匹配 |
| 边界型 | 结论能推多广 | 明说不能推的部分 |
| 攻击型 | 这工作有什么新意 | 讲守得住的贡献 |

**纪律**：只排练**守得住**的内容；答不上来的问题**不编说法**，改为「承认边界 + 给后续计划」。

**DUT 特化**：按 DUT 开题 / 中期 / 学位答辩常见节奏组织问题清单（选题意义 → 方法 → 结果 → 创新点 → 展望），可直接用于校内答辩预演。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 下周开题答辩，怕被老师问住，帮我准备

**澄清判定**：对象（开题答辩）、任务（质询准备）、产出（问题清单+应答骨架）齐全 → 不追问

**输出**

```
【结论】先过幽灵测试修论证断点，再备 10 问应答骨架，主动交代已知局限。
【依据】评委追问集中在「论证讲不通处」与「方法选择理由」两类高发区
【结果】① 幽灵测试：把你的论点按顺序连读给我，断点处先补论证
       ② 三问自审：核心论点的 3 个致命问题（我来出题你来防守）
       ③ 预设 10 问：方法 3 / 结果 3 / 意义 2 / 局限 2，每问配 20 秒短答
       ④ 已知局限：主动写进最后一张幻灯片，先于评委说出
       → 产出：defense/开题-问题清单.md（10 问 + 应答骨架）
【下一步】把开题报告的论点清单发我，从幽灵测试开始
【建议】我不会替你编答案（合规要求）；应答骨架里的证据必须来自你的真实工作
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 有个问题我答不上来，你帮我编个说法糊过去

**澄清判定**：命中本域红线（编造说法）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝

**输出**

```
【结论】不编说法；承认边界比糊过去更稳。
【依据】合规边界：不编造数据 / 结论 / 说法
【替代方案】给「承认边界 + 后续计划」的应答话术
【下一步】把你答不上来的问题发我，我们一起排 3 种稳妥回应
```
