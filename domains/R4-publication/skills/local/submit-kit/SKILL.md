# 投稿返修工具包

- **归属域**：`R4` 学术产出与投稿（科研类）
- **来源**：自建
- **定位**：先跑投稿前自检（结构/引用/数据），再给期刊匹配与审稿意见逐条回复表。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 5%）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：论文投稿、专利与会议、基金申报、返修回复
- 不覆盖：不做出稿前的结构打磨（→S5）

## 执行步骤

1. 投稿前自检：结构完整性、引用规范、数据可复现
2. 按主题与方法匹配 3 个候选期刊/会议（含分区与周期）
3. 列投稿材料清单（Cover Letter、声明、伦理审查）
4. 返修：逐条拆解审稿意见 → 分类（接受/反驳/补充实验）
5. 为每条意见写回复草稿 + 修改位置
6. 输出返修对照表

## 输出

按 `library/output-spec.md` 模板输出，默认 ≤ 6 条要点。

## DUT 绑定点

- 科学技术研究院 https://scidep.dlut.edu.cn/
- 研究生院 https://gs.dlut.edu.cn/

需登录：
- 科研管理系统（项目/成果登记）

## 失败与降级

库内执行不满足 → 读同目录 `../external.md` 走库外安装；仍失败 → 纯提示词模式并标注 `[已降级]`。
