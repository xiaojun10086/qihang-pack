# 投稿返修工具包

- **归属域**：`R4` 学术产出与投稿（科研类）
- **来源**：自建
- **定位**：先跑投稿前自检（结构/引用/数据），再给期刊匹配与审稿意见逐条回复表。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：论文投稿、专利与会议、基金申报、返修回复
- 不覆盖：不做出稿前的结构打磨（→S5）

## 执行步骤

1. 投稿前自检：结构完整性、引用规范、数据可复现
2. 按主题与方法匹配 3 个候选期刊/会议（含分区与周期）
3. 列投稿材料清单（Cover Letter、声明、伦理审查）
4. 返修：逐条拆解审稿意见 → 分类（接受/反驳/补充实验）
5. 为每条意见写回复草稿 + 修改位置
6. 输出返修对照表

## 方法库 · 判定细则

**投稿前自检 + 期刊匹配**：

| 项 | 检查点 | 阻断级 |
|---|---|---|
| 结构 | 摘要 / 正文 / 图表齐全 | 高 |
| 引用 | 格式一致、无缺失 | 高 |
| 数据 | 可获取性声明 | 中 |
| 匹配 | 期刊范围 / 周期 / 格式 | 中 |

**判定顺序**：先判是不是「代投稿」请求，是则只给自检清单与匹配候选 → 再判自检是否有高阻断项 → 最后才谈期刊匹配。

**高频误判**

- ❌ 把「直接帮我投出去」当流程代办 → ✅ 不代投稿不代注册，只给自检报告与匹配候选
- ❌ 跳过自检先挑期刊 → ✅ 先跑自检并列出阻断项，再谈匹配
- ❌ 高阻断项存在也投 → ✅ 结构与引用缺失属高阻断级，先补齐
- ❌ 数据可获取性声明留空 → ✅ 数据可获取性声明属中阻断级，要写明
- ❌ 只看期刊范围不看周期与格式 → ✅ 匹配要同时看范围、周期与格式

**纪律**：先跑自检并**列出阻断项**，再谈期刊匹配；不代投稿、不代注册账号。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 导师让我投一篇会议论文

**澄清判定**：缺「方向/时间」→ 追问 2 问

**输出**

```
【结论】先跑投稿前自检，再按方向匹配会议，最后排时间。
【依据】科学技术研究院 https://scidep.dlut.edu.cn/
【结果】① 自检：结构完整性 / 引用规范 / 数据可复现
       ② 匹配 3 个候选会议（含截稿日与周期）
       ③ 材料：Cover Letter + 声明 + 伦理审查
       ④ 预留返修时间（按会议周期倒排）
       → 产出：submit/会议筛选.md + checklist
【下一步】先做第 ① 步自检（清单已给）
【建议】注意会议的 AI 使用声明要求
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 自检和匹配都算了，你直接帮我把它投出去

**澄清判定**：命中本域红线（代投稿）→ **红线优先**（`clarity.md` §5 例外 4，优先级高于例外 2），**不再追问**，直接拒绝 + 给合规替代

**为什么这样判**：代投稿与代注册属禁答范围，本 skill 一律只降级不代劳，只给自检报告与匹配候选。

**输出**

```
【结论】不代投稿；可给投稿前自检清单与匹配候选。
【依据】合规边界：不代投稿 / 不代注册
【结果】只交付自检报告、匹配期刊候选与材料清单，投稿动作由你完成 —— 代投稿类请求一律只降级不代劳。
【替代方案】给自检报告 + 3 个匹配期刊 + 投稿材料清单
【下一步】把稿件与目标方向发我，我出清单与候选
```

## ⚠️ 红线（不得绕过）

- **不代投稿、不代操作系统** —— 只给自检清单与材料清单
- 不伪造作者署名与利益冲突声明 —— 署名变更须经**全体作者确认并走期刊变更流程**；利益冲突只能据实声明（自查 → `R5`）
