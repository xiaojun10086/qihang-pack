# FASTER 学习循环

- **归属域**：`S4` 备考与记忆（学习类）
- **来源**：改造自 `hluaguo/learn-faster-kit`（MIT）· 骨架提取重写 + DUT 特化
- **定位**：把「学一门课 / 一个技术」拆成六步循环来经营，核心是「教学回讲」——用自己的话讲出来才算学会。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：一门课 / 一个技能的完整学习循环设计；学习模式选择；教学回讲练习
- 不覆盖：考前一两周的应急排程 → `exam-sprint`；间隔重复卡组生成 → `recall-schedule`；专注环境 → `F2`

## 执行步骤

1. **选模式**（按目标四选一）：
   - 均衡：理论 + 练习 + 应用各三分之一（默认推荐）
   - 应试：以真题回忆和模考为主
   - 理论：吃透概念与心智模型
   - 实践：以项目 / 实验任务驱动
2. **F 忘（归零）**：列出「你以为什么」的既有认知，逐条标记「确认 / 存疑 / 错误」——先清掉错误预设再学新内容
3. **A 练（动手）**：每学一个知识点立刻配 1 道最小练习；只读不动手的时间不得超过学习总时长的 1/3
4. **S 态（状态）**：固定学习时段与地点（DUT 场景：图书馆 / 自习室），单次 ≥ 50 分钟，前 5 分钟只做「回顾上次笔记」这一件事进入状态
5. **T 教（回讲）**：每完成一个主题，用自己的话（不看笔记）讲给假想的新生听；讲不顺的段落就是要重学的段落
6. **E 恒（节律）**：把循环嵌入课表空档（`jxgl` 课表），每周固定循环次数，而不是「有空就学」
7. **R 复（间隔）**：把回讲暴露的薄弱点记入复习清单，按 1 天 / 3 天 / 7 天 / 21 天间隔回炉（细节排程走 `recall-schedule`）
8. 输出本轮循环的「薄弱点清单 + 下轮计划」

## 方法库 · 判定细则

**FASTER 六步**：Forget → Act → State → Teach → Enter → Review。

| 步 | 关键动作 |
|---|---|
| Teach | 用自己的话讲，讲不顺=没懂 |
| Review | 间隔回访，非连续重读 |

**验收**：能不看资料把该知识点讲给他人听 → 才算过。

**DUT 特化**：循环排期嵌入 DUT 学期周历——教学周、期中周、期末周分档，把「教学回讲」安排在教学周内、把回讲检验安排在期中前后，与课程进度同步推进。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 程序设计基础学得稀碎，想系统地把它学明白

**澄清判定**：对象（程序设计基础）、任务（系统学习）、产出（学习循环）齐全 → 不追问

**输出**

```
【结论】按「应试→理论」混合模式跑 FASTER 循环，先归零再动手，每章必回讲。
【依据】教学回讲（主动回忆）比被动重读留存率高 2–3 倍；课程在本学期课程表内
【结果】① 归零：写下你对指针/循环的既有理解，我来标记「确认/存疑/错误」
       ② 动手：每章 1 道最小练习（如：用循环打印九九乘法表）
       ③ 状态：每周二/四晚图书馆 2 小时（含 5 分钟回顾启动）
       ④ 回讲：每章学完合上书讲给我听，讲不顺的段落重学
       ⑤ 间隔：薄弱点按 1/3/7/21 天回炉
       → 产出：study/faster-cycle-plan.md（循环表 + 薄弱点清单）
【下一步】现在开始第①步：用 3 句话说说你理解的「变量」
【建议】练习代码可以自己写；可直接提交的作业答案不代写
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我做个 3 天考前突击计划

**澄清判定**：任务明确但属短期冲刺 → 依 `clarity.md` §5 例外 2 放行后改锁 `exam-sprint`

**输出**

```
[已降级] 由「学习循环」改为「考前冲刺排程」
【结论】这属于「考前冲刺排程」类需求，已改按该方式处理。
【下一步】提交科目与剩余天数
```
