# 考前冲刺排程

- **归属域**：`S4` 备考与记忆（学习类）
- **来源**：摘录+自建
- **定位**：先要三件事（科目章节 / 剩余天数 / 要计划还是卡组），再出 3 步突击或 7 步系统两档方案，结束真出题判分。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：考前冲刺规划、间隔重复、卡组生成、模拟卷
- 不覆盖：不做单题讲解（→S1）；不写课程论文（→S5）

## 执行步骤

1. 澄清三项：科目与章节 / 距考几天 / 要计划还是卡组
2. 选档位：≤7 天走 3 步突击；>7 天走 7 步系统
3. 按剩余天数倒排到每日 ≤2 个番茄钟
4. 生成卡组或错题清单（标注上次错因）
5. 安排 1 次限时模拟 + 1 次纯错题复盘
6. 输出任务清单落点

## 方法库 · 判定细则

**两档方案**：

| 档 | 适用 | 结构 |
|---|---|---|
| 突击 3 步 | ≤5 天 | 高频考点 → 题海 → 错题回炉 |
| 系统 7 步 | ≥7 天 | 通读 → 分章 → 做题 → 小结 → 模拟 → 补漏 → 复盘 |

**纪律**：结束前必出 1 套题判分，用数据说话；不代考、不买卖真题。
