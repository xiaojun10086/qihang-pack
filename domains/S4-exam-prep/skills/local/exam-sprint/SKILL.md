# 考前冲刺排程

- **归属域**：`S4` 备考与记忆（学习类）
- **来源**：摘录+自建
- **定位**：优先给一个立刻可执行的复习动作，再根据时间、考点范围和用户反馈逐步细化。

## 前置（复杂任务按需使用）

简单、清晰的备考请求直接处理。只有关键信息会改变安排时才按 `library/clarity.md` 澄清；复杂或跨域计划再参照 `library/domain-review.md`。

## 边界

- 覆盖：考前冲刺规划、间隔重复、卡组生成、模拟卷
- 不覆盖：不做单题讲解（→S1）；不写课程论文（→S5）

## 执行步骤

1. 复用用户已给的信息；不知道考试范围时，不编造考点。
2. 若考试临近，先给今天可执行的复习块；需要整段计划时再依据剩余时间倒排。
3. 每个复习块结合主动回忆、针对性练习和错题回顾；安排应适配用户可用时段。
4. 仅当范围或时间会明显改变建议时，提出一个最关键的追问。
5. 可附 1–3 道短练习或请用户发一道错题，以反馈调整后续安排。

## 方法库 · 判定细则

**两档方案**：

| 档 | 适用 | 结构 |
|---|---|---|
| 突击 3 步 | ≤5 天 | 高频考点 → 题海 → 错题回炉 |
| 系统 7 步 | ≥7 天 | 通读 → 分章 → 做题 → 小结 → 模拟 → 补漏 → 复盘 |

**纪律**：只有在模拟练习对当前目标有帮助时才出题；不代考、不买卖答案。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 数学分析下周三期中，我才看到第 3 章

**澄清判定**：缺「章节范围」与「产出形式」→ 追问 2 问后 U ≤ 0.30

**输出**

```
【结论】6 天可救，主攻第 3–5 章，每天 2 个番茄钟。
【依据】；突击节奏按 3 步档
【结果】① D1–D2 第 3 章 12 道典型题
       ② D3–D4 第 4 章 + 错因归类
       ③ D5 错题卡组过一轮
       ④ D6 限时模拟 1 套 + 只过错题
       → 产出：高数卡组.apkg · 每日任务已生成
【下一步】现在做 D1 前 3 题，做完回我
【还需确认】① 考到第几章 ② 要计划还是卡组
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我讲一下这道模拟题怎么做

**澄清判定**：任务明确但属单题讲解 → 依 `clarity.md` §5 例外 2 放行后改锁 `S1` `explain-stepwise`

**输出**

```
[已降级] 由「考前冲刺排程」改为「分步讲解」
【结论】这属于「分步讲解」类需求，已改按该方式处理。
【下一步】提交题目原文，走分步讲解
```

## ⚠️ 红线（不得绕过）

- **不代考、不买卖答案/真题** —— 属学术不端，须提示 `R5`
- 不做单题讲解（→`S1`）

## 输出

短请求先给今天可做的复习动作；较完整的计划可参考 `library/output-spec.md`，不强制补齐所有字段。
