# 考前冲刺排程

- **归属域**：`S4` 备考与记忆（学习类）
- **来源**：摘录+自建
- **定位**：先要三件事（科目章节 / 剩余天数 / 要计划还是卡组），再出 3 步突击或 7 步系统两档方案，结束真出题判分。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 5%）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：考前冲刺规划、间隔重复、卡组生成、模拟卷
- 不覆盖：不做单题讲解（→S1）；不写课程论文（→S5）

## 执行步骤

1. 澄清三项：科目与章节 / 距考几天 / 要计划还是卡组
2. 选档位：≤7 天走 3 步突击；>7 天走 7 步系统
3. 按剩余天数倒排到每日 ≤2 个番茄钟
4. 生成卡组或错题清单（标注上次错因）
5. 安排 1 次限时模拟 + 1 次纯错题复盘
6. 输出任务清单落点

## 可执行示例

**输入**

> 数学分析下周三期中，我才看到第 3 章

**澄清判定**：缺「章节范围」与「产出形式」→ 追问 2 问后 U ≤ 5%

**输出**

```
【结论】6 天可救，主攻第 3–5 章，每天 2 个番茄钟。
【依据】库内 skill exam-sprint（3 步突击档）；校历与考试安排
【步骤】① D1–D2 第 3 章 12 道典型题
       ② D3–D4 第 4 章 + 错因归类
       ③ D5 错题卡组过一轮
       ④ D6 限时模拟 1 套 + 只过错题
【产物】高数卡组.apkg · 每日任务已生成
【下一步】现在做 D1 前 3 题，做完回我
【追问问了】① 考到第几章 ② 要计划还是卡组
```
