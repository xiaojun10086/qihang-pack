# 模拟卷与错题回炉

- **归属域**：`S4` 备考与记忆（学习类）
- **来源**：自建
- **覆盖主体**：U 在读本科（考前查漏）
- **定位**：用真题结构自组限时模拟卷，并把错题按类型回炉：归因、变式再练、覆盖率检查，面向考前需要查漏的本科生。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：模拟卷组卷、错题归因与变式再练、知识点覆盖率检查
- 不覆盖：单题讲解（→`S1`）；整门课冲刺排程（→`exam-sprint`）；长期记忆排程（→`recall-schedule`）

## 执行步骤

1. 明确考试范围与题型分布（问老师或看往年卷）
2. 按题型比例组一份限时模拟卷（只用历年真题结构）
3. 限时做完后逐题归因（知识 / 方法 / 粗心 / 时间）
4. 对高错因类型出 2–3 道变式题
5. 计算知识点覆盖率，列出未覆盖章节

## 方法库 · 判定细则

**错因四分类与回炉顺序**：

| 错因 | 回炉动作 | 优先级 |
|---|---|---|
| 知识（不会） | 回补概念 → 变式题 | 高 |
| 方法（想不到） | 归纳题型套路 | 高 |
| 粗心（算错） | 建立检查清单 | 中 |
| 时间（做不完） | 调整做题顺序 | 中 |

**组卷纪律**：只用历年真题 / 老师给的样题，不用来源不明的「押题卷」。
