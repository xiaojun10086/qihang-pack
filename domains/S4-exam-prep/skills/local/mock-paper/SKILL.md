# 模拟卷与错题回炉

- **归属域**：`S4` 备考与记忆（学习类）
- **来源**：自建
- **覆盖主体**：U 在读本科（考前查漏）
- **定位**：用真题结构自组限时模拟卷，并把错题按类型回炉：归因、变式再练、覆盖率检查，面向考前需要查漏的本科生。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：模拟卷组卷、错题归因与变式再练、知识点覆盖率检查
- 不覆盖：单题讲解（→`S1`）；整门课冲刺排程（→`exam-sprint`）；长期记忆排程（→`recall-schedule`）

## 执行步骤

1. 明确考试范围与题型分布（问老师或看往年卷）
2. 按题型比例组一份限时模拟卷（只用历年真题结构）
3. 限时做完后逐题归因（知识 / 方法 / 粗心 / 时间）
4. 对高错因类型出 2–3 道变式题
5. 计算知识点覆盖率，列出未覆盖章节

## 方法库 · 判定细则

**错因四分类与回炉顺序**：

| 错因 | 回炉动作 | 优先级 |
|---|---|---|
| 知识（不会） | 回补概念 → 变式题 | 高 |
| 方法（想不到） | 归纳题型套路 | 高 |
| 粗心（算错） | 建立检查清单 | 中 |
| 时间（做不完） | 调整做题顺序 | 中 |

**判定顺序**：先判用户要的是「组卷 + 错因回炉」还是「单题讲解」，后者改走分步讲解 → 再判错因属知识 / 方法 / 粗心 / 时间哪一类 → 最后才排回炉优先级。

**高频误判**

- ❌ 把「讲讲这道题」当组卷需求 → ✅ 单题讲解改走分步讲解，模拟卷不做逐题答疑
- ❌ 错因一律归为「不会」→ ✅ 先分知识、方法、粗心、时间四类，回炉动作各不相同
- ❌ 用来源不明的押题卷 → ✅ 只用历年真题或老师给的样题
- ❌ 卷子做完就结束 → ✅ 做完要跑错因回炉，否则分数不会动
- ❌ 粗心当能力问题 → ✅ 粗心靠检查清单压，不是回去重学知识

**组卷纪律**：只用历年真题 / 老师给的样题，不用来源不明的「押题卷」。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 高数期末还有 10 天，我想做套模拟卷看看漏洞在哪

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】先按题型分布组一份 2h 限时卷，错题按四类归因再回炉。
【依据】模拟卷与错题回炉流程：组卷 → 归因 → 变式
【结果】① 组限时卷 ② 掐时间做 ③ 逐题标错因 ④ 出变式题
       → 产出：错因分布表 + 未覆盖章节清单
【下一步】做完把错因分布发我，我帮你排回炉顺序
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我讲一下这道模拟卷上的大题

**澄清判定**：任务明确但属单题讲解 → 依 `clarity.md` §5 例外 2 放行后改锁 `S1` `explain-stepwise`

**为什么这样判**：模拟卷流程面向整卷组题与错因回炉，单题讲解走不到回炉那一步；讲解类需求改由分步讲解承接（是换路径，不是拒答）。

**输出**

```
[已降级] 由「模拟卷」改为「分步讲解」
【结论】这属于「分步讲解」类需求，已改按该方式处理。
【结果】只改派到「分步讲解」路径，整卷命制与批改由任课教师完成 —— 越界请求一律只降级不代劳。
【下一步】提交题目原文，走分步讲解
```
