# 开卷索引页

- **归属域**：`S4` 备考与记忆（学习类）
- **来源**：自建
- **覆盖主体**：U 在读本科（开卷考核）
- **定位**：为开卷考试制作一页式检索索引：按考点归类的公式、定理与解法定位表，面向允许带资料进入的考核。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：开卷索引页设计（考点归类、公式定位、页码速查、检索训练）
- 不覆盖：闭卷突击备考（→`exam-sprint`）；单题讲解（→`S1`）；记忆卡组（→`recall-schedule`）

## 执行步骤

1. 确认考试是否开卷、可带资料范围（问清规则）
2. 按章节 / 考点归成 8–12 个检索块
3. 每块只放「触发词 → 公式 / 定理编号 → 页码」
4. 加一页「常用结论 + 易错条件」速查
5. 用一份真题演练检索速度，删掉查不到的项

## 方法库 · 判定细则

**索引粒度判据**：一个检索块 =「一类问法」。太粗会翻不到，太细会查不完。

| 块内字段 | 作用 |
|---|---|
| 触发词 | 题干里可能的措辞 |
| 公式 / 定理编号 | 直指结论 |
| 页码 | 一处定位，不写两处 |

**验收**：随机抽 5 道真题，全部能在 30 秒内定位 → 索引合格。
