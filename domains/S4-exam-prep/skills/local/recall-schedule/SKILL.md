# 间隔复习排程

- **归属域**：`S4` 备考与记忆（学习类）
- **来源**：自建
- **定位**：生成卡组与间隔重复排程（1/3/7/14 天），控制每日复习量上限，不代考。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：卡组生成、间隔重复排程、每日复习量控制
- 不覆盖：不代考、不买卖真题答案（→红线）；不做单题讲解（→S1）

## 执行步骤

1. 确认科目、章节范围与截止日
2. 把已提供或已核验材料中的知识点切成原子卡（一问一答，一卡一概念）；每张卡脱离上下文也能识别对象
3. 按 1 / 3 / 7 / 14 天四轮排程，反推每轮起始日
4. 检查卡片事实能回溯到来源；答案简洁、只覆盖一个要点，避免重复卡、模糊问法和材料无依据的卡片
5. 叠加用户确认的每日复习上限；未说明时先给可调建议，不把示例数当成用户偏好
6. 输出日历视图 + 每日张数；若需文件，优先交付可读的 Markdown/纯文本卡组，不承诺未配置导出器的 `.apkg`

## 方法库 · 判定细则

**间隔重复节奏**：1 → 3 → 7 → 14 天。

| 参数 | 建议 |
|---|---|
| 每日新卡与复习量 | 按用户可投入时间和卡片难度调整；未确认时不固定张数 |
| 逾期卡优先 | 先清积压 |

**纪律**：排程是给记忆服务的，不制造焦虑 —— 超载就减量。
每日上限根据用户可用时间调整，不把默认样例数冒充用户设置。

**卡片质检**：一张卡只测一个明确知识点；题干不依赖「它/其优势」等上下文；答案与来源一致。按概念、条件、步骤或易混点分组，难度标注只用于安排，不当作掌握度证据。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 高数第 3–5 章，两周后考，帮我排一下背的节奏

**澄清判定**：对象（第 3–5 章）、时间（两周）、产出（排程）明确 → 放行

**输出**

```
【结论】两周内可按 1/3/7/14 天安排回顾，具体每日卡量按你的可用时间确定。
【依据】间隔重复排程
【结果】① 按第 3–5 章拆分概念卡，每卡一个定义或条件
　　　　② 以 1/3/7/14 天为建议回顾点；每日量暂不预设
　　　　③ 逾期与错卡优先，已熟卡降低频率
　　　　→ 产出：可编辑卡组文本 + 排程草案
【下一步】告诉我每天可投入多少分钟，再细化每日数量
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我把这门课的整体复习规划一下

**澄清判定**：任务明确但属冲刺排程 → 依 `clarity.md` §5 例外 2 放行后改锁 `exam-sprint`

**输出**

```
[已降级] 由「间隔复习排程」改为「考前冲刺排程」
【结论】这属于「考前冲刺排程」类需求，已改按该方式处理。
```
