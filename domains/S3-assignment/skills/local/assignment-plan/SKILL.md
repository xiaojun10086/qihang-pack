# 作业拆解

- **归属域**：`S3` 作业与考核（学习类）
- **来源**：自建
- **定位**：把大作业/课程设计拆成里程碑与工作量，排期并标风险项，不代写正文。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：作业拆解、里程碑排期、风险标注
- 不覆盖：不代写正文；不代提交（→红线）

## 执行步骤

1. 读清评分标准与截止日，抽出交付物清单
2. 把交付物拆成 ≤8 个里程碑，每个标预计工时
3. 倒排到日，留出 20% 缓冲
4. 标出 3 类风险：依赖外部（他人/设备/数据）、易返工、易低估
5. 给出「今天能启动的最小一步」

## 方法库 · 判定细则

**里程碑拆分**：需求确认 → 初稿 → 合稿 → 自查 → 提交，五点必排。

| 风险信号 | 应对 |
|---|---|
| 数据未采 | 前移采集里程碑 |
| 依赖他人 | 标外部依赖块 |

**纪律**：只拆解与排期；不代写正文、不编造数据。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 课程设计要求第 16 周交，还有 5 周，我还没开始

**澄清判定**：对象（课程设计）、时间（5 周）、产出（排期）明确 → 放行

**输出**

```
【结论】5 周够，但要先定选题，否则第 3 周就会卡住。
【依据】作业拆解流程
【结果】① 本周定选题 + 查 3 篇参考文献
　　　　② 第 2 周出需求与总体设计
　　　　③ 第 3–4 周实现 + 测试
　　　　④ 第 5 周写报告与答辩 PPT 骨架
　　　　→ 产出：plan/课程设计里程碑.md
【下一步】今天只做一件事：用两句话写下你的选题，回我
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 我实验数据还没做，先帮我把报告正文写了吧

**澄清判定**：命中红线（代写 + 数据缺失）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并提示改锁

**输出**

```
【结论】不代写正文；缺数据时先补数据再写。
【依据】合规边界：不代写正文、不编造实验数据
【替代方案】给报告骨架 + 数据处理清单
【下一步】先确认数据来源，规范自检
```

## ⚠️ 红线（不得绕过）

- **不代写正文**（只给 IMRAD 骨架与自查）
- **不编造实验数据** —— 属学术不端，须改锁并提示 `R5`
- **不代操作教学平台**（不代提交作业/报告）
