# 实验报告脚手架

- **归属域**：`S3` 作业与考核（学习类）
- **来源**：自建
- **定位**：按 IMRAD 给实验报告骨架，分配各节字数，并给出自查清单；正文由学生自己写。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：作业规划、实验报告结构、课程设计拆解、格式规范
- 不覆盖：不代写（只给结构与自查）；不投期刊（→R4）

## 执行步骤

1. 确认实验名称、目的、数据是否齐备
2. 按 IMRAD 出骨架：引言 / 方法 / 结果 / 讨论 / 结论
3. 分配各节字数（如 300/400/500/500/200）
4. 标记必须由本人完成的部分（数据处理、结论）
5. 给出格式自查清单（单位、有效数字、图表编号、引用）
6. 输出 Markdown / docx 落点

## 方法库 · 判定细则

**IMRAD 字数分配**：引言 15% · 方法 25% · 结果 35% · 讨论 25%。

| 节 | 只写什么 |
|---|---|
| 结果 | 数据与图表，不解释 |
| 讨论 | 与文献比对、局限 |

**纪律**：只给骨架与自查；数据缺失时标「待补数据」，绝不编造。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 下周要交大学物理实验报告，测重力加速度，帮我看看怎么写

**澄清判定**：对象/产出明确；只缺字数（非关键槽位）→ 不追问

**输出**

```
【结论】按 IMRAD 走，重点在误差分析，全篇约 2000 字。
【依据】；数据来源为你自己的实验记录
【结果】① 引言 300 字（原理 + 目的）
       ② 方法 400 字（装置、步骤、公式）
       ③ 结果 500 字（数据表 + 图 + 拟合）
       ④ 讨论 500 字（误差来源：计时、摆长、空气阻力）
       ⑤ 结论 200 字
       → 产出：report/物理实验-重力加速度.md 骨架
【下一步】先把第 ③ 节的数据表填上（这部分必须你本人做）
【建议】全程只给骨架与自查，正文不代写
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我把这份实验报告的正文写了

**澄清判定**：命中红线（代写正文）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不代写正文；可给 IMRAD 骨架与自查清单。
【依据】合规边界：不代写正文
【替代方案】四节骨架 + 字数分配
【下一步】把实验数据发我，我帮你对骨架
```

## ⚠️ 红线（不得绕过）

- **不代写正文**（只给 IMRAD 骨架与自查）
- **不编造实验数据** —— 属学术不端，须改锁并提示 `R5`
- **不代操作教学平台**（不代提交作业/报告）
