# 编程作业自查

- **归属域**：`S3` 作业与考核（学习类）
- **来源**：自建
- **覆盖主体**：U 在读本科（工科编程课）
- **定位**：面向编程作业的自查清单：编译、边界、复杂度、可读性与引用声明逐项自检，只给检查项与定位提示，不代写代码。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：编程作业自查（正确性 / 边界 / 复杂度 / 风格 / 引用他人代码声明）
- 不覆盖：代写代码（见红线）；算法思路讲解（→`S1` `explain-stepwise`）；环境报错排查（→`R3` `tool-setup`）

## 执行步骤

1. 复述作业要求与评分点，确认输入输出规格
2. 过自查表：能编译 / 正常样例 / 边界样例 / 复杂度
3. 检查命名、注释、函数长度等可读性项
4. 检查是否引用了他人代码并标注出处
5. 输出「问题清单 + 每项定位提示」，不直接给修正后的代码

## 方法库 · 判定细则

**编程作业自查表（7 项）**：

| # | 检查项 | 不合格信号 |
|---|---|---|
| 1 | 能编译 / 无警告 | 有未使用变量、隐式转换 |
| 2 | 正常样例通过 | 只测了样例 1 |
| 3 | 边界样例 | 空输入 / 极值 / 单元素未测 |
| 4 | 复杂度 | 嵌套循环超题给数据量 |
| 5 | 命名与注释 | 变量名 a1/a2、无函数注释 |
| 6 | 引用声明 | 抄了模板 / 网上代码未标注 |
| 7 | 输出格式 | 多空格、缺换行导致判题失败 |

**不做**：给出修正后的完整代码 —— 只给「哪一行、什么问题、往哪个方向改」。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我的快排作业提交前帮我看看有啥问题

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】先补 3 类边界用例，再查递归深度，代码本体不改。
【依据】编程作业自查表第 3 / 4 / 6 项
【结果】① 加空数组 / 单元素 / 全相等用例 ② 检查最坏复杂度 ③ 标注参考来源
       → 产出：问题清单（3 项）+ 定位提示
【下一步】补完边界用例把运行结果发我，再核一次
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 这道编程题怎么写，直接给我完整代码

**澄清判定**：命中红线（求可直接提交的代码）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不代写可直接提交的代码；可给思路与自查清单。
【依据】合规边界：不代写正文
【替代方案】提供算法思路拆解 + 自查表
【下一步】把你自己写到一半的版本发我，我指出卡点
```
