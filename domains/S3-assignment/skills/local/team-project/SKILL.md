# 小组作业协作

- **归属域**：`S3` 作业与考核（学习类）
- **来源**：自建
- **覆盖主体**：U 在读本科（小组作业）
- **定位**：把小组作业拆成可认领的任务块与里程碑，生成分工表、进度看板与协作纪要模板，面向需要多人协作的本科生。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：小组作业任务拆解、分工表、进度与里程碑、协作纪要模板
- 不覆盖：个人作业拆解（→`assignment-plan`）；报告正文撰写（→`lab-report`）；组内人际冲突（→`F3`）

## 执行步骤

1. 复述作业目标、交付物与截止时间
2. 拆成 4–8 个可独立认领的任务块
3. 给每块标工作量、前置依赖与负责人（留空待认领）
4. 排出里程碑（初稿 / 合稿 / 提交）与检查点
5. 生成周会纪要模板与进度看板列

## 方法库 · 判定细则

**任务块拆分口径**：每块满足「一个人一周内可独立完成 + 有明确交付物」。

| 看板列 | 含义 |
|---|---|
| 待认领 | 拆好但无人负责 |
| 进行中 | 已认领 |
| 待合稿 | 单块完成，等并稿 |
| 已交付 | 通过检查点 |

**判据**：任一任务块的前置依赖为空且无负责人 → 标记为风险项，先解决。

**输出**

```

【结果】① 认领任务块 ② 定 3 个检查点 ③ 建进度看板
       → 产出：分工表 + 周会纪要模板
```
