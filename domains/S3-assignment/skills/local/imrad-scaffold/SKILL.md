# IMRAD 论文骨架

- **归属域**：`S3` 作业与考核（学习类）
- **来源**：改造自 `kgraph57/paper-writer-skill`（MIT）· 骨架提取重写 + DUT 特化
- **定位**：结构工厂，不是文章代笔——产出四节骨架文件、进度清单和自查表；正文一个字不代写。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：课程论文 / 毕业设计的结构骨架、进度管理、写作前自查、投稿前格式清单
- 不覆盖：实验报告的数据图表规范 → `lab-report`；作业的时间规划 → `assignment-plan`；期刊投稿返修 → `R4`

## 执行步骤

1. **人类主权双闸（先于一切）**：
   - 💡 **想法闸**：研究问题 / 论点必须由用户提出或从其草稿中提取——AI 可以帮打磨措辞、指出模糊，但**永不替用户发明论点**
   - 📊 **数据闸**：所有数据必须来自用户的实验 / 调研 / 计算——AI 永不生成任何数据点、被试或结果
2. **建项目目录**（骨架的物理形态）：
   ```
   paper-<课程或题目slug>/
   ├── 00-任务书.md      # 要求、截止日期、评分口径（抄任课教师原文）
   ├── 10-引言.md  20-方法.md  30-结果.md  40-讨论.md   # 四节骨架
   ├── refs.md           # 参考文献（每条必须有可回源锚点）
   └── checklist.md      # 写作前 / 提交前两套自查
   ```
3. **四节各给「填空式骨架」**（每节 3–5 个小节标题 + 每个小节的引导问题，不给正文）：
   - 引言：研究背景 → 已有工作 → 缺口 → 本文贡献（一句话）
   - 方法：设计 → 变量与测量 → 流程 → 分析方法（写作时最 solid 的一节，先写它）
   - 结果：图表先行 → 描述性统计 → 推断结果（只陈述，不解释）
   - 讨论：主要发现 → 与已有工作对照 → 局限 → 结论
4. **顺序建议**：方法 → 结果 → 引言 → 讨论（先写最确定的，最后写最需要全局观的）
5. **对抗性自审**（提交前红队）：站在「最挑剔的评阅人」角度对核心论点提 3 个问题写进 checklist，让用户逐一防守
6. 输出「项目目录 + 四节骨架 + 自查表」

## 方法库 · 判定细则

**四节骨架文件**：每节给「要回答的问题 + 建议字数 + 自查项」。

| 节 | 要回答 |
|---|---|
| Intro | 为什么做 |
| Methods | 怎么做 |
| Results | 得到什么 |
| Discussion | 意味着什么 |

**纪律**：正文一个字不代写；骨架交付后由本人填充。

**DUT 特化**：骨架对接 DUT 学位论文与课程设计格式要求（章节编号、图表题注、公式编号、参考文献 GB/T 7714），并提供 DUT 毕业设计系统提交前的自查项。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 软件工程课要求写一篇课程论文，我有调研数据，完全不知道怎么下手

**澄清判定**：对象（课程论文）、任务（搭结构）、产出（骨架）齐全，数据归用户所有 → 不追问

**输出**

```
【结论】先建 IMRAD 项目目录，你填方法和数据两节，我守住结构与自查。
【依据】方法与结果两节由你的调研事实支撑，最先固化；引言讨论最后写
【结果】① 双闸确认：论点你自己定（我帮你收窄），数据只用你的调研结果
       ② 建目录：paper-软件工程/（00-任务书…40-讨论.md，骨架见）
       ③ 你先填 20-方法.md（我给引导问题：设计？变量？流程？）
       ④ 30-结果.md 只放你的图表与数字，我帮排结构不改数值
       ⑤ 提交前跑对抗性自审：3 个评阅人问题先防守再交
       → 产出：paper-软件工程/ 目录（骨架 + 双闸声明 + checklist）
【下一步】把任务书原文发我，先落 00-任务书.md
【建议】正文必须自己写（学术诚信要求）；我给结构与自查，不给可提交的成文段落
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 骨架我有了，正文你帮我补上吧

**澄清判定**：命中红线（代写正文）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不代写正文；骨架已交付，正文由本人写。
【依据】合规边界：不代写正文
【替代方案】逐节自查清单
【下一步】写完一节发我，我按自查表核一节
```

## ⚠️ 红线（不得绕过）

- **不代写正文**（只给 IMRAD 骨架与自查）
- **不编造实验数据** —— 属学术不端，须改锁并提示 `R5`
- **不代操作教学平台**（不代提交作业/报告）
