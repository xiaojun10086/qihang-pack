# 就医路径

- **归属域**：`F5` 健康与运动（生活类）
- **来源**：自建
- **定位**：把「该不该去医院 / 去哪一层 / 怎么报销」讲清楚：紧急度分层 → 就诊层级 → 医保材料，不诊断不给药。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：就医时机分层、就诊层级选择、医保报销流程
- 不覆盖：不诊断、不给用药建议（→红线）；急症直接 120

## 执行步骤

1. 按「能自理 / 需尽快就诊 / 急症」三层做紧急度分层，不给诊断结论
2. 急症（意识模糊 / 高热 / 剧痛 / 外伤严重）→ 立即 120，不再给居家建议
3. 需尽快就诊 → 给校医院门诊时段、挂号方式、需带证件
4. 需要转诊 → 给附属医院对口科室与预约路径
5. 给医保报销三步：留票据 → 校医院/医保办 → 报销时限

## 方法库 · 判定细则

**紧急度分层**：急症（意识模糊 / 高热 / 剧痛）→ 120；一般 → 校医院 → 附属医院。

| 层级 | 场景 |
|---|---|
| 120 | 危及生命 |
| 校医院 | 常见病、轻症 |
| 附属医院 | 需专科检查 |

**纪律**：不诊断、不给药；只给路径与材料。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 这两天一直胃疼，要去医院吗？

**澄清判定**：对象（胃疼）、任务（要不要去）明确 → 放行；不追问症状细节（避免越界诊断）

**输出**

```
【结论】持续两天建议今天去校医院，别再观察；有剧痛/呕血立刻 120。
【依据】就医路径分层
【结果】① 带学生证 + 校园卡到校医院
　　　　② 挂号内科，说明持续时长与诱因
　　　　③ 需转诊则开转诊单去附属医院
　　　　→ 产出：health/就医与报销清单.md
【下一步】现在查校医院今日门诊时间，能挂上就今天去
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 我这个症状该吃什么药

**澄清判定**：命中红线（诊断 / 用药）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不做诊断、不给用药建议；按就医路径就诊。
【依据】合规边界：不做诊断、不给用药建议
【替代方案】紧急度分层 + 就诊层级
【下一步】按分层选 120 / 校医院 / 附属医院
```

## ⚠️ 红线（不得绕过）

- **不做诊断、不给用药建议、不替代医生**
- 急症（意识模糊 / 高热 / 剧痛 / 外伤严重）→ **直接拨打 120**，不再给居家建议
- **第三方健康隐私**（他人病史、体检报告）**不分析、不外传、不写入任何文件**
- 涉持续/加重症状 → 直接给就医路径
