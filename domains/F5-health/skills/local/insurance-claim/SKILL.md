# 医保报销

- **归属域**：`F5` 健康与运动（生活类）
- **来源**：自建
- **覆盖主体**：U 在读本科
- **定位**：梳理大学生医保的门诊 / 住院 / 异地就医报销流程、材料与办理入口，只给路径与材料清单，不做医疗判断。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：大学生医保报销流程、门诊 / 住院 / 异地材料清单、办理入口梳理
- 不覆盖：诊断与用药建议（见红线）；就医路径（→`clinic-path`）；第三方健康隐私（见红线）

## 执行步骤

1. 判定场景：普通门诊 / 住院 / 异地 / 转诊
2. 列出该场景需要的票据与证明材料
3. 给办理窗口 / 系统入口与时限
4. 说明比例口径以医保部门规定为准（不背书具体数字）
5. 输出材料清单与办理顺序

## 方法库 · 判定细则

| 场景 | 关键材料 | 时限提示 |
|---|---|---|
| 门诊 | 发票 + 病历 + 学生证 | 当月 / 学期内 |
| 住院 | 出院小结 + 费用清单 | 出院后尽快 |
| 异地 | 备案 + 转诊单 | 事先备案 |

**纪律**：具体报销比例一律不写死 —— 以医保部门当年规定为准。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我最近住院了，医保怎么报销

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】先备出院小结与费用清单，再到医保窗口办理。
【依据】医保报销：住院场景材料表
【结果】① 收齐票据 ② 查本院报销窗口 ③ 按顺序提交
       → 产出：住院报销材料清单
【下一步】先确认出院小结是否已拿到，把材料发我核对
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 我这症状是不是该吃点什么药

**澄清判定**：命中红线（诊断 / 用药建议）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不做诊断、不推荐用药；需按就医路径就诊。
【依据】合规边界：不做诊断、不给用药建议
【替代方案】给校医院与就医路径
【下一步】预约就诊
```

## ⚠️ 红线（不得绕过）

- **不做诊断、不给用药建议、不替代医生**
- 急症（意识模糊 / 高热 / 剧痛 / 外伤严重）→ **直接拨打 120**，不再给居家建议
- **第三方健康隐私**（他人病史、体检报告）**不分析、不外传、不写入任何文件**
- 涉持续/加重症状 → 直接给就医路径
