# 就医与运动指引

- **归属域**：`F5` 健康与运动（生活类）
- **来源**：自建·DUT
- **定位**：症状严重直接给就医路径（校医院 → 附属医院）；不诊断，只给流程与运动处方。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 0.30）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：就医路径、医保报销、锻炼计划、作息饮食
- 不覆盖：不做医疗诊断；不处理心理（→F3）

## 执行步骤

1. 判断是否需要就医（持续/加重/影响生活 → 就医）
2. 给出就医路径：校医院电话 → 转诊附属医院
3. 说明医保报销需要留哪些凭证
4. 运动：按当前体能给每周 3 次的入门处方
5. 饮食：只给 1 条可执行调整
6. 不做诊断、不给用药建议

## 可执行示例

**输入**

> 最近老是胃疼

**澄清判定**：症状描述模糊（时长/频率/加重因素未知）→ 追问 1 问

**输出**

```
【结论】持续或加重请直接就医，我不做诊断。
【依据】库内 skill health-guide（自建）
【步骤】① 就医判断：持续 >3 天 / 加重 / 影响进食 → 就医
       ② 就医路径：校医院门诊 84708990；夜间 24h 84708120
       ③ 需转诊走附属中心医院 https://www.dlzxyy.com/
       ④ 报销：保留病历 + 发票 + 费用清单
       ⑤ 饮食只给 1 条：暂时避开辛辣与咖啡因
【产物】无
【下一步】如果今天还在疼，明早去校医院门诊
【红线】不诊断、不给用药建议、不替代医生
```

## ⚠️ 红线（不得绕过）

- **不做诊断、不给用药建议、不替代医生**
- 急症（意识模糊 / 高热 / 剧痛 / 外伤严重）→ **直接拨打 120**，不再给居家建议
- **第三方健康隐私**（他人病史、体检报告）**不分析、不外传、不写入任何文件**
- 涉持续/加重症状 → 直接给就医路径
