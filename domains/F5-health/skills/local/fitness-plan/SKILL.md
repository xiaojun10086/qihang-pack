# 锻炼与体测

- **归属域**：`F5` 健康与运动（生活类）
- **来源**：自建
- **覆盖主体**：U 在读本科
- **定位**：结合体测项目与校园场馆，给可执行的锻炼计划与体测达标训练方案，不做运动损伤诊断。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：体测项目训练计划、校园场馆结合、周训练安排
- 不覆盖：运动损伤诊断 / 用药（见红线）；就医路径（→`clinic-path`）；饮食营养处方（→`health-guide`）

## 执行步骤

1. 明确目标（体测达标 / 增肌 / 减脂）与体测项目
2. 评估可用场馆与每周可用时段
3. 排周训练计划（有氧 / 力量 / 柔韧分配）
4. 给体测专项的达标训练要点
5. 标注「受伤 / 剧痛 → 就医或拨 120」

## 方法库 · 判定细则

**周计划分配口径**：有氧 2–3 次、力量 2 次、柔韧穿插，中间隔开同肌群。

| 体测项目 | 训练要点 |
|---|---|
| 1000m / 800m | 间歇跑 + 配速 |
| 立定跳远 | 下肢爆发 + 落地技术 |
| 引体 / 仰卧起坐 | 分组力竭 + 递增 |

**判据**：训练中出现关节刺痛 → 停训并走就医路径，不带伤硬练。

**输入**

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```

       → 产出：4 周训练表
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 我跑步膝盖疼还能继续练吗

**澄清判定**：涉持续 / 加重症状 → 依 `clarity.md` §5 例外 2 放行后改锁就医路径（`clinic-path`）

**输出**

```
[已降级] 由「锻炼与体测」改为「就医路径」
【结论】出现持续性膝痛，先停训并走就医路径，不给居家运动建议。
【下一步】预约校医院或骨科
```

## ⚠️ 红线（不得绕过）

- **不做诊断、不给用药建议、不替代医生**
- 急症（意识模糊 / 高热 / 剧痛 / 外伤严重）→ **直接拨打 120**，不再给居家建议
- **第三方健康隐私**（他人病史、体检报告）**不分析、不外传、不写入任何文件**
- 涉持续/加重症状 → 直接给就医路径
