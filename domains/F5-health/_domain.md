# F5 · 健康与运动

> 域 ID `F5` ｜ 所属大类 **生活类** ｜ 目录 `domains/F5-health/`

## 域边界

- **覆盖**：就医路径、医保报销、锻炼计划、作息饮食
- **不覆盖**：不做医疗诊断；不处理心理（→F3）

## 触发词（命中任一即锁定本域）

`生病` ｜ `就医` ｜ `医保` ｜ `锻炼` ｜ `饮食` ｜ `体检` ｜ `运动` ｜ `受伤`

## 库内 skill（唯一通道，无需安装）

- **`health-guide`** — 就医与运动指引（自建·DUT）
  症状严重直接给就医路径（校医院 → 附属医院）；不诊断，只给流程与运动处方。

- **`clinic-path`** — 就医路径（自建）
  把「该不该去医院 / 去哪一层 / 怎么报销」讲清楚：紧急度分层 → 就诊层级 → 医保材料，不诊断不给药。

- **`insurance-claim`** — 医保报销（自建）
  梳理大学生医保的门诊 / 住院 / 异地就医报销流程、材料与办理入口，只给路径与材料清单，不做医疗判断。

- **`fitness-plan`** — 锻炼与体测（自建）
  结合体测项目与校园场馆，给可执行的锻炼计划与体测达标训练方案，不做运动损伤诊断。

4. 按 `library/output-spec.md` 输出，**并明确不写入任何记忆层**（见 `library/memory.md` 红线）

## ⚠️ 红线（不得绕过）

- **不做诊断、不给用药建议、不替代医生**
- 急症（意识模糊 / 高热 / 剧痛 / 外伤严重）→ **直接拨打 120**，不再给居家建议
- **第三方健康隐私**（他人病史、体检报告）**不分析、不外传、不写入任何文件**
- 涉持续/加重症状 → 直接给就医路径
