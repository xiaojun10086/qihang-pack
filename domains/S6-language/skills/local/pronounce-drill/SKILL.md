# 口语跟读

- **归属域**：`S6` 语言能力（学习类）
- **来源**：自建
- **定位**：做跟读与发音纠错训练，给中式发音偏误对照表与每日 10 分钟脚本。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 0.30）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：发音纠错、跟读训练、口语流利度
- 不覆盖：不代写课程作业（→S3）；作文只标错不重写

## 执行步骤

1. 先做 1 分钟朗读采样，定位 3 个高频偏误
2. 对照中式发音偏误表（/θ/ /ð/ /v/ /w/、连读、词重音）给纠正口型要点
3. 给 3 组最小对立对（minimal pairs）练听辨
4. 排每日 10 分钟脚本：跟读 → 复述 → 录音自评
5. 给一次「录音自评表」，不代替评测

## 可执行示例

**输入**

> 我口语很差，一开口就怕说错，怎么练？

**澄清判定**：对象（口语）、任务（怎么练）明确 → 放行；背景缺失不追问（clarity §5 例外 2）

**输出**

```
【结论】先练 3 组最小对立对，每天 10 分钟，两周见效。
【依据】发音偏误对照（库内 skill pronounce-drill）
【步骤】① 采样 1 分钟，定位 /θ/ /v/ 两个偏误
　　　　② 练 thank/think、very/wary 两组对立对
　　　　③ 跟读 → 复述 → 录音自评，各 3 分钟
【产物】oral/每日10分钟脚本.md · 自评表.md
【下一步】今天先录 1 分钟，把最卡的 3 个词发我
```
