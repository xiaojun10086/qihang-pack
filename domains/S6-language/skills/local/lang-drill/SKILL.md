# 语言训练

- **归属域**：`S6` 语言能力（学习类）
- **来源**：自建
- **定位**：先测水平（CEFR 或四六级分数），再出可执行的每日训练计划，写作只标错不重写。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 5%）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：英语/第二外语的词汇、语法、写作批改、口语、翻译
- 不覆盖：不做学术论文写作（→S5）

## 执行步骤

1. 测水平（CEFR / 四六级 / 雅思分数）
2. 明确弱项（听 / 说 / 读 / 写 四选一为主攻）
3. 出每日 ≤30 分钟的最小可行动作
4. 写作批改规则：标出错误类型 + 给 1 条修改建议，不整篇重写
5. 设置 1 周后的复测点
6. 输出训练表落点

## 输出

按 `library/output-spec.md` 模板输出，默认 ≤ 6 条要点。

## DUT 绑定点

- 外国语学院 https://fld.dlut.edu.cn/

需登录：
- 图书馆电子资源（外文数据库）

## 失败与降级

库内执行不满足 → 读同目录 `../external.md` 走库外安装；仍失败 → 纯提示词模式并标注 `[已降级]`。
