# 学术英语

- **归属域**：`S6` 语言能力（学习类）
- **来源**：自建
- **覆盖主体**：M 硕士（论文英文写作）
- **定位**：面向论文写作的学术英语：句式库、时态与语态选择、常见中式表达改写方向，只标错与给替换选项，不整段重写。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：学术句式与连接词、时态语态选择、中式英语改写方向、投稿信常用表达
- 不覆盖：整篇作文重写（见红线）；日常语言训练（→`lang-drill`）；口语发音（→`pronounce-drill`）

## 执行步骤

1. 定位文本类型（摘要 / 引言 / 方法 / 讨论 / 投稿信）
2. 逐句标出问题：时态 / 语态 / 搭配 / 中式表达
3. 对每处给 1–2 个学术惯用替换，不整段重写
4. 汇总高频问题类型，给针对性句式库
5. 给一次自检清单

## 方法库 · 判定细则

**分节时态对照表**：

| 章节 | 常用时态 | 说明 |
|---|---|---|
| 摘要 | 一般过去 / 现在 | 结果用过去，结论用现在 |
| 引言 | 现在完成 / 一般现在 | 综述用完成时 |
| 方法 | 一般过去 | 被动常见 |
| 结果 | 一般过去 | 只陈述不解释 |
| 讨论 | 一般现在 | 解释与推论 |

**中式表达高频三类**：① 冗余名词化（make an improvement → improve）；② 无主语长句；③ 连接词缺失。

**判定顺序**：先判是「整篇重写」还是「逐句标错」，前者一律只标错 → 再判是时态、中式表达还是连接词问题 → 最后才给逐句替换选项。

**高频误判**

- ❌ 把「改成地道版本」当整篇润色 → ✅ 只逐句标错并给替换选项，不整段重写
- ❌ 把「中式表达」一律归为语法错 → ✅ 先分冗余名词化、无主语长句与连接词缺失，各自改法不同
- ❌ 讨论段沿用一般过去 → ✅ 结果段用过去陈述，讨论段用现在解释
- ❌ 把「帮我看看语法」当通篇校对 → ✅ 先定位是时态、搭配还是句式问题，再逐句给
- ❌ 中式表达只标不改 → ✅ 标错的同时给可直接替换的写法，否则用户无从下手

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我论文方法部分的英文读起来很中式，帮我看看

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】主要是冗余名词化与被动语态混用，逐句给替换项。
【依据】学术英语：分节时态 + 中式表达三类
【结果】① 标问题句 ② 给 1–2 个学术替代表达 ③ 汇总句式库
       → 产出：逐句问题标注 + 替换选项
【下一步】改完方法段发我，复核时态一致性
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我把这段英文整段改成地道的版本

**澄清判定**：命中红线（整篇重写）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**为什么这样判**：整篇重写会把作者的语言选择一并替换掉，本 skill 只标错并给替换选项（只降级不代劳，不是空手退回）。

**输出**

```
【结论】不整段重写；只标错并给替换选项。
【依据】合规边界：作文只标错、不整篇重写
【结果】只交付逐句标注与句式库，整段重写由你本人完成 —— 整篇代写一律只降级不代劳。
【替代方案】逐句标注 + 句式库
【下一步】提交原段，我逐句标问题
```
