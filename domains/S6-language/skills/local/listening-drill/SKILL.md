# 精听训练

- **归属域**：`S6` 语言能力（学习类）
- **来源**：自建
- **覆盖主体**：U 在读本科
- **定位**：用「盲听—听写—对照—跟读」四步做精听训练，配材料难度分级与听写错因统计，面向想提升听力的本科生。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：精听训练流程、材料分级、听写错因统计、影子跟读
- 不覆盖：口语发音纠正（→`pronounce-drill`）；应试技巧（→`ielts-coach`）；单词记忆（→`S4`）

## 执行步骤

1. 选一段 1–2 分钟、难度略高于当前水平的音频
2. 盲听 2 遍写下能听懂的信息骨架
3. 逐句听写，标出听错处（连读 / 生词 / 语速）
4. 对照原文统计错因分布
5. 影子跟读 3 遍并复述大意

## 方法库 · 判定细则

**材料难度分级**：以「生词率」定级 —— 生词 < 3% 偏易，3%–8% 合适，> 8% 偏难。

| 听错类型 | 训练动作 |
|---|---|
| 连读弱读 | 慢速逐句模仿 |
| 生词 | 先过词表再听 |
| 语速 | 0.8× 起逐步提速 |

**判据**：同一段材料连听 3 遍仍听不懂 > 30% → 降级材料，不必硬啃。
