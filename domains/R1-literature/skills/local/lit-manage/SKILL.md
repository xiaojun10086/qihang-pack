# 文献库管理

- **归属域**：`R1` 文献检索与管理（科研类）
- **来源**：自建
- **覆盖主体**：M 硕士
- **定位**：给 Zotero 文献库的分类、标签、命名与去重规范，把散乱文献整理成可检索、可回溯的结构。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：Zotero 分类 / 标签 / 命名 / 去重规范、附件与笔记关联、导出与备份
- 不覆盖：检索式设计（→`lit-map`）；引文核验（→`citation-verify`）；系统综述流程（→`review-method`）

## 执行步骤

1. 审计现有文献库（数量、重复、无附件项）
2. 定一套分类体系（主题 / 项目 / 状态）
3. 定标签与文件命名规范
4. 批量去重与补全元数据
5. 设定期备份与导出格式

## 方法库 · 判定细则

| 维度 | 规范示例 |
|---|---|
| 分类 | 主题 / 项目 / 状态 三层 |
| 标签 | 方法、对象、年份 |
| 命名 | 年份-作者-关键词 |
| 去重 | 按 DOI 去重，缺 DOI 按标题 |

**判据**：任意一篇文献，能在 10 秒内被「分类 + 标签」定位 → 结构合格。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我 Zotero 里几百篇文献乱成一团，怎么整理

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】按「分类 + 标签 + 命名」三层重整，先按 DOI 去重。
【依据】文献库管理：分类 / 标签规范
【步骤】① 审计重复项 ② 定分类体系 ③ 定命名规范 ④ 批量去重
【产物】文献库整理规范 + 去重清单
【下一步】先导出当前库的条目数，我帮你估去重工作量
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我下载这篇论文的全文

**澄清判定**：任务明确但属合法获取 → 依 `clarity.md` §5 例外 2 放行后改锁 `lit-fetch`

**输出**

```
[已降级: lit-manage → lit-fetch]
【结论】属文献获取，改由 lit-fetch 承接。
【下一步】提交文献题录，走合法获取流程
```

## ⚠️ 红线（不得绕过）

- **不生成、不补全任何未核验的引文**（标题 / 作者 / 卷期页 / DOI）
- 每条引文必须可回源；无法定位的条目一律删除，不放「凑数文献」
