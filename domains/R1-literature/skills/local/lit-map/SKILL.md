# 文献地图

- **归属域**：`R1` 文献检索与管理（科研类）
- **来源**：自建
- **定位**：先出检索式与纳排标准，再按「主题—方法—结论」矩阵整理；每条引文给可核验锚点。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：文献检索式设计、筛选、引文核验、文献管理
- 不覆盖：不写论文正文（→S5/R4）

## 执行步骤

1. 把研究问题拆成 2–4 个检索概念
2. 为每个概念出同义词与检索式（中英各一版）
3. 定纳入/排除标准
4. 建矩阵：主题 | 方法 | 样本 | 结论 | 局限
5. 每条引文标注来源与可核验锚点（DOI/页码）
6. 输出文献矩阵表

## 方法库 · 判定细则

**纳排标准与整理矩阵**：

| 维度 | 必填 | 常见坑 |
|---|---|---|
| 检索式 | 库名 + 检索式 + 日期 | 只给关键词、不可复现 |
| 纳排 | 纳入 / 排除各列判据 | 只写「相关」无判据 |
| 主题—方法—结论 | 每条一行 | 结论抄摘要而非读全文 |

**纪律**：先定检索式与纳排，**再开始读**；每条引文给可核验锚点（DOI / 页码），无锚点的行标「待核验」。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 要写一篇关于「大模型幻觉」的综述，怎么找文献

**澄清判定**：对象/产出明确 → 不追问

**输出**

```
【结论】先定检索式与纳排标准，再做矩阵，别一上来就读全文。
【依据】图书馆 https://lib.dlut.edu.cn/ （含校外访问）
【结果】① 拆概念：LLM / hallucination / detection|mitigation
       ② 检索式中英各一版（已给）
       ③ 纳排标准：2022 年后、有实验、同行评议
       ④ 建矩阵：方法 | 数据集 | 指标 | 局限
       → 产出：lit/matrix.md
【下一步】先用检索式跑一遍，回我命中数量再筛
【建议】每条引文留 DOI，方便回源核验
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 别搞什么检索式了，直接把这 20 篇综述的全文打包给我

**澄清判定**：任务明确但属全文获取 → 依 `clarity.md` §5 例外 2 放行后改锁 `lit-fetch`

**输出**

```
[已降级] 由「文献地图」改为「合法文献获取」
【结论】这属于「合法文献获取」类需求，已改按该方式处理。
【下一步】把 20 篇的题名 + DOI 列表发我，按合法渠道逐条取
```

## ⚠️ 红线（不得绕过）

- **不生成、不补全任何未核验的引文**（标题 / 作者 / 卷期页 / DOI）
- 每条引文必须可回源；无法定位的条目一律删除，不放「凑数文献」
