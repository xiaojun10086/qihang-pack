# 引文核验

- **归属域**：`R1` 文献检索与管理（科研类）
- **来源**：自建
- **定位**：逐条核验引文（题名/作者/年/卷期页/DOI）并标回源状态，不生成、不补全。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：引文核验、回源、字段一致性检查
- 不覆盖：不生成、不补全任何未核验引文（→红线）

## 执行步骤

1. 列出待核验引文的现有字段
2. 逐条标回源状态：已回源 / 部分回源 / 无法定位
3. 对「部分回源」标出缺失字段与可能来源
4. 对「无法定位」的条目一律建议删除，不放凑数文献
5. 输出核验表：条目 / 状态 / 缺字段 / 处置

## 方法库 · 判定细则

**核验字段与回源状态**：

| 字段 | 判据 | 回源状态标 |
|---|---|---|
| 题名 / 作者 | 与源页面逐字一致 | 一致 / 有出入 |
| 年份 / 卷期页 | 源页面明示 | 已核验 / 待核验 |
| DOI | 可解析到同一文献 | 可解析 / 不可解析 / 未给 |
| 会议 / 期刊全称 | 用规范全称 | 规范 / 缩写待展开 |

**纪律**：只核验**已存在**的引文，缺字段就标「未给」，**不得据常识补全**；一条引文只给一个最终状态，冲突时以 DOI 解析结果为准。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我参考文献里有些是之前复制来的，帮我核一下真实性

**澄清判定**：对象（参考文献）、任务（核验）明确 → 放行；核验≠补全，不触红线

**输出**

```
【结论】12 条里 9 条可回源、2 条字段不全、1 条无法定位（建议删）。
【依据】引文核验流程
【结果】① 已回源 9 条：字段自洽
　　　　② #4 #9 缺卷期页 → 你去数据库补齐
　　　　③ #12 无法定位 → 删除，不要凑数
　　　　→ 产出：cite/核验表.md
【下一步】先删掉 #12，再把 #4 的卷期页补上回我
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 这条引文我漏了 DOI 和页码，你帮我按惯例补全一下

**澄清判定**：命中本域红线（补全 / 生成引文）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝

**输出**

```
【结论】不代补引文；漏字段一律标「未给」，请回源复制。
【依据】合规边界：不生成、不补全引文
【替代方案】教你按 DOI / 期刊页定位原始条目自行核对
【下一步】把本条引文的 DOI 或期刊页链接发我，逐字段核验
```

## ⚠️ 红线（不得绕过）

- **不生成、不补全任何未核验的引文**（标题 / 作者 / 卷期页 / DOI）
- 每条引文必须可回源；无法定位的条目一律删除，不放「凑数文献」
