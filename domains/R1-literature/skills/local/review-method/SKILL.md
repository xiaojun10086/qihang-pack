# 系统综述

- **归属域**：`R1` 文献检索与管理（科研类）
- **来源**：自建
- **覆盖主体**：M 硕士 · D 博士
- **定位**：按 PRISMA 流程给系统综述 / 范围综述的操作框架：检索式、去重、筛选标准、流程图与偏倚评估，不代写正文。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：系统 / 范围综述方法框架、PRISMA 流程与流程图、检索式与筛选标准、偏倚风险评估
- 不覆盖：普通文献检索与管理（→`lit-map`）；引文核验（→`citation-verify`）；正文写作（→`S5`，见红线）

## 执行步骤

1. 明确综述问题（用 PICOS / SPIDER 结构）
2. 设计检索式并在 2–3 个数据库检索、记录命中数
3. 定纳入 / 排除标准，做标题 / 摘要 / 全文三级筛选
4. 画 PRISMA 流程图并记录各阶段数量
5. 给偏倚风险评估工具与数据提取表模板

## 方法库 · 判定细则

**PRISMA 各阶段必录数量**：检索命中 → 去重后 → 标题筛选 → 全文筛选 → 纳入。

| 结构 | 适用 |
|---|---|
| PICOS | 量化 / 干预类问题 |
| SPIDER | 质性 / 经验类问题 |

**判据**：流程图任一阶段缺数量 → 该综述不可复现，退回补录。
