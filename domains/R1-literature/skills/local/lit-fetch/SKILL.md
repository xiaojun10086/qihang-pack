# 合法文献获取

- **归属域**：`R1` 文献检索与管理（科研类）
- **来源**：改造自 `Lucaswangzcx/literature-downloader-skill`（MIT）· 骨架提取重写 + DUT 特化
- **定位**：把「找文献、筛文献、合法拿全文、留记录」做成可复现流程；拿不到的如实说拿不到，并给下一步合法路线。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：文献检索计划、批量获取的合法路线、获取状态记录与中文报告
- 不覆盖：检索式设计与文献矩阵 → `lit-map`；引文真伪核验 → `citation-verify`；笔记整理 → `S2`

## 执行步骤

1. **明确需求**：主题、年份范围、目标篇数、语言、是否必须全文
2. **拆检索式**：把题目拆成 2–4 个概念块 + 同义词 / 缩写 / 中英双语（细节走 `lit-map`）
3. **分层检索**：
   - 广泛发现：Google Scholar / Semantic Scholar / OpenAlex / Crossref
   - 中文库：知网 / 万方（经 DUT 图书馆入口访问）
   - 全文入口：DOI 页 / 出版社页 / 开放获取版本 / 预印本 / 作者主页
4. **合法获取全文（按序尝试）**：
   ① 开放获取（OA 期刊 / PubMed Central / Unpaywall 查合法版本）
   ② **DUT 图书馆电子资源**（校内 IP 或校外访问入口——最常用的合法通道）
   ③ 预印本 / 机构仓储 / 作者主页版本
   ④ 馆际互借 / 文献传递（图书馆服务）
   ⑤ 邮件联系作者
   **遇到登录墙 / 403 / 付费墙 → 如实记「暂不可得」，绝不算成功，更不绕过**
5. **状态用中文人话记录**：已下载 PDF ｜ 已存网页版 ｜ 需经学校图书馆 ｜ 建议馆际互借 ｜ 建议联系作者 ｜ 未找到合法全文
6. **去重整理**：按 DOI / 题名去重；每条记录「题名、年份、来源、DOI、全文状态、下一步」
7. 输出「文献清单 + 全文状态表 + 下一步路线」

## 方法库 · 判定细则

**合法获取渠道分级**（按优先级）：

| 顺序 | 渠道 | 适用 | 备注 |
|---|---|---|---|
| 1 | 图书馆订阅库 | 已在馆藏 | 走 `lib.dlut.edu.cn` |
| 2 | 开放获取（OA） | 有 OA 版本 | 认准出版社 / 机构库链接 |
| 3 | 馆际互借 / 文献传递 | 馆藏缺失 | 走图书馆服务台 |
| 4 | 作者索取 | 通讯作者有公开邮箱 | 附礼貌信模板 |

**纪律**：只走上述合法渠道；**不提供盗版站点（如 Sci-Hub）线路、不给破解下载法**；拿不到就如实说「拿不到」并给下一步合法路线。

**DUT 特化**：合法获取优先走 DUT 图书馆订阅库与文献传递服务；校外访问用 WebVPN 登录图书馆电子资源入口；开发区 / 盘锦校区学生对应分馆服务，馆际互借走本校图书馆服务台。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 帮我找 10 篇大模型幻觉检测的近三年文献，能下全文的优先

**澄清判定**：对象（LLM 幻觉检测文献）、任务（找+合法获取）、数量（10 篇）齐全 → 不追问

**输出**

```
【结论】先出检索式跑 OA 与图书馆通道，目标 10 篇中至少 6 篇拿到合法全文。
【依据】OA 命中率高的领域（AI 预印本文化浓）；DUT 图书馆订阅了主流数据库
【结果】① 检索式：hallucination AND detection AND (LLM|large language model)，2023–2026
       ② 分层：arXiv/Semantic Scholar 发现 → DOI 核对 → OA 版本优先
       ③ 校内通道：图书馆电子资源（校外访问入口可用）
       ④ 状态表：每篇标「已下/需图书馆/建议联系作者」
       → 产出：lit/候选10篇.csv（题名·年份·DOI·全文状态·下一步）+ 已下全文目录
【下一步】先回我 3–5 篇你最想要的，我从它们开跑
【建议】付费墙文献走馆际互借或联系作者，不绕过（合规要求）；引文信息以数据库为准
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 图书馆没有这篇，给我个能直接下载的免费站点链接吧

**澄清判定**：命中本域红线（提供盗版获取渠道）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝

**输出**

```
【结论】不提供盗版站点；可走馆际互借或作者索取。
【依据】合规边界：不提供非法获取渠道
【替代方案】① 图书馆文献传递 ② 通讯作者索取（附信模板）
【下一步】把文献题名 + DOI 发我，我给出对应合法路线
```

## ⚠️ 红线（不得绕过）

- **不生成、不补全任何未核验的引文**（标题 / 作者 / 卷期页 / DOI）
- 每条引文必须可回源；无法定位的条目一律删除，不放「凑数文献」
