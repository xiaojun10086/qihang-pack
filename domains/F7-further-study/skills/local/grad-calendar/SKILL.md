# 升学时间线

- **归属域**：`F7` 升学深造（生活类）
- **来源**：自建
- **定位**：把保研/考研/留学三条线拆成月份级时间轴与材料倒排，文书只给结构。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 0.30）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：路径时间轴、材料倒排、节点提醒
- 不覆盖：不代写文书、不编造经历（→红线）

## 执行步骤

1. 先定路径（可多选，分别排）
2. 抽出各路径的关键节点（报名 / 材料 / 考试 / 面试 / 出结果）
3. 按月排轴，标出每个节点的硬性材料与前置依赖
4. 给「现在就该做的 1 件事」
5. 文书类只给结构大纲与自查清单

## 可执行示例

**输入**

> 想保研又怕保不上，考不考也拿不准，现在大二下

**澄清判定**：对象（保研/考研）、背景（大二下）明确 → 放行；产出默认时间轴，不追问

**输出**

```
【结论】两条线并行到明年 6 月不冲突，先做的是"绩点 + 一段科研"。
【依据】升学时间线（库内 skill grad-calendar）
【步骤】① 本学期：绩点保底 + 进一个课题组
　　　　② 明年 3–5 月：关注夏令营通知
　　　　③ 6–9 月：投夏令营 / 同步复习考研数学
【产物】plan/升学时间轴.md
【下一步】这周去找一位任课老师问本科生进组的门路
```

## ⚠️ 红线（不得绕过）

- **不代写文书**（个人陈述 / 推荐信 / 研究计划）—— 只给结构与自查
- 不虚构经历、奖项、录取动机

> 本红线**继承自 `../../_domain.md`**，不得在本 skill 内单独放宽；如与域文件冲突，以域文件为准。
