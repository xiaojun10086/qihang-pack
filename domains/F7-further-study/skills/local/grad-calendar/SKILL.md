# 升学时间线

- **归属域**：`F7` 升学深造（生活类）
- **来源**：自建
- **定位**：把保研/考研/留学三条线拆成月份级时间轴与材料倒排，文书只给结构。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：路径时间轴、材料倒排、节点提醒
- 不覆盖：不代写文书、不编造经历（→红线）

## 执行步骤

1. 先定路径（可多选，分别排）
2. 抽出各路径的关键节点（报名 / 材料 / 考试 / 面试 / 出结果）
3. 按月排轴，标出每个节点的硬性材料与前置依赖
4. 给「现在就该做的 1 件事」
5. 文书类只给结构大纲与自查清单

## 方法库 · 判定细则

**三条线倒排**：保研 / 考研 / 留学各按「考试 / 材料 / 截止」倒推。

| 线 | 关键节点 |
|---|---|
| 保研 | 夏令营 → 预推免 → 系统填报 |
| 考研 | 报名 → 初试 → 复试 |
| 留学 | 语言 → 套磁 → 网申 |

**纪律**：文书只给结构；时间以官方公告为准。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 想保研又怕保不上，考不考也拿不准，现在大二下

**澄清判定**：对象（保研/考研）、背景（大二下）明确 → 放行；产出默认时间轴，不追问

**输出**

```
【结论】两条线并行到明年 6 月不冲突，先做的是"绩点 + 一段科研"。
【依据】升学时间线
【结果】① 本学期：绩点保底 + 进一个课题组
　　　　② 明年 3–5 月：关注夏令营通知
　　　　③ 6–9 月：投夏令营 / 同步复习考研数学
　　　　→ 产出：plan/升学时间轴.md
【下一步】这周去找一位任课老师问本科生进组的门路
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我选几所目标学校

**澄清判定**：任务明确但属选校策略 → 依 `clarity.md` §5 例外 2 放行后改锁 `school-pick`

**输出**

```
[已降级] 由「升学时间线」改为「选校与夏令营」
【结论】这属于「选校与夏令营」类需求，已改按该方式处理。
【下一步】提交自身定位，建冲 / 稳 / 保梯度
```

## ⚠️ 红线（不得绕过）

- **不代写文书**（个人陈述 / 推荐信 / 研究计划）—— 只给结构与自查；**真实材料的措辞优化属合规**（不得虚构内容）
- 不虚构经历、奖项、录取动机
