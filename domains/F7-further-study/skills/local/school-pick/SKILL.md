# 选校与夏令营

- **归属域**：`F7` 升学深造（生活类）
- **来源**：自建
- **覆盖主体**：G 毕业年级本科生
- **定位**：按「冲 / 稳 / 保」梯度做选校与夏令营投递策略，给梯度配置与投递时间表，不代写申请材料。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：选校梯度策略、夏令营 / 预推免投递时间表、信息核验来源
- 不覆盖：代写文书（见红线）；查导师资料（→`R6` `advisor-finder`）；升学时间线（→`grad-calendar`）

## 执行步骤

1. 明确自身定位（绩点 / 科研 / 英语 / 竞赛）
2. 按冲 / 稳 / 保三档各选 2–3 所，给配置比例
3. 核对各校夏令营 / 预推免时间与要求（以官网为准）
4. 排投递时间表与材料齐备检查点
5. 标注材料真实性与不虚构原则

## 方法库 · 判定细则

**梯度配置**：冲 3 / 稳 3 / 保 2 为常见配比，按自身定位上下浮动。

| 档位 | 判据 |
|---|---|
| 冲 | 定位略高于自身 |
| 稳 | 定位相当 |
| 保 | 定位明显低于自身 |

**纪律**：所有时间 / 要求以目标院校官网为准，不采信二手转述。

## ⚠️ 红线（不得绕过）

- **不代写文书**（个人陈述 / 推荐信 / 研究计划）—— 只给结构与自查；**真实材料的措辞优化属合规**（不得虚构内容）
- 不虚构经历、奖项、录取动机
