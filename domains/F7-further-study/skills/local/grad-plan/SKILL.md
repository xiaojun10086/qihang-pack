# 升学路径规划

- **归属域**：`F7` 升学深造（生活类）
- **来源**：自建
- **定位**：先定路径（保研/考研/留学），再倒排时间线，标出每个节点的硬性材料。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：保研/考研/留学的路径规划、时间线、材料与选校选导师
- 不覆盖：不写文书代笔（只给结构与自查）；不求职（→F8）

## 执行步骤

1. 锁定路径：保研（推免）/ 考研 / 留学 / 直博
2. 查 DUT 对应入口（研究生院 / 国际交流处 / 学院推免章程）
3. 倒排时间线（大三下 → 大四上，按月）
4. 列硬性材料清单（成绩单、推荐信、文书、语言成绩）
5. 文书只给结构与自查，不代写
6. 输出时间线表

## 方法库 · 判定细则

**先定路径再倒排**：路径 → 节点 → 硬性材料。

| 路径 | 硬性材料 |
|---|---|
| 保研 | 成绩排名 + 科研经历 |
| 考研 | 初试科目 + 复试准备 |
| 留学 | 语言成绩 + 推荐信 |

**纪律**：文书只给结构、不代写；不虚构经历。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我大一，想保研，现在该做什么

**澄清判定**：年级已知、路径明确 → 不追问

**输出**

```
【结论】保研是三年工程，大一重点是绩点与科研入口。
【依据】研究生院 https://gs.dlut.edu.cn/ （推免章程逐年发布）
【结果】① 大一：把绩点打进专业前 20%（**以所在学院当年推免章程为准；本包未收录具体分数线 / 排名要求**）
       ② 大二：进实验室/竞赛，攒 1 段科研经历
       ③ 大三上：关注学院推免章程与夏令营通知
       ④ 大三下：夏令营 → 预推免 → 材料准备
【网址】研究生招生 https://gs.dlut.edu.cn/yjszs.htm
【状态】✅ 已核验
【下一步】先查你所在学院的推免章程（我给了路径）
```

## ⚠️ 红线（不得绕过）

- **不代写文书**（个人陈述 / 推荐信 / 研究计划）—— 只给结构与自查；**真实材料的措辞优化属合规**（不得虚构内容）
- 不虚构经历、奖项、录取动机
