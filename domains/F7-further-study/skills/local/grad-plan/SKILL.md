# 升学路径规划

- **归属域**：`F7` 升学深造（生活类）
- **来源**：自建
- **定位**：先定路径（保研/考研/留学），再倒排时间线，标出每个节点的硬性材料。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 5%）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：保研/考研/留学的路径规划、时间线、材料与选校选导师
- 不覆盖：不写文书代笔（只给结构与自查）；不求职（→F8）

## 执行步骤

1. 锁定路径：保研（推免）/ 考研 / 留学 / 直博
2. 查 DUT 对应入口（研究生院 / 国际交流处 / 学院推免章程）
3. 倒排时间线（大三下 → 大四上，按月）
4. 列硬性材料清单（成绩单、推荐信、文书、语言成绩）
5. 文书只给结构与自查，不代写
6. 输出时间线表

## 输出

按 `library/output-spec.md` 模板输出，默认 ≤ 6 条要点。

## 失败与降级

库内执行不满足 → 读同目录 `../external.md` 走库外安装；仍失败 → 纯提示词模式并标注 `[已降级]`。
