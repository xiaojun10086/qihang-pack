# F7 · 升学深造

> 域 ID `F7` ｜ 所属大类 **生活类** ｜ 目录 `domains/F7-further-study/`

## 域边界

- **覆盖**：保研/考研/留学的路径规划、时间线、材料与选校选导师
- **不覆盖**：不写文书代笔（只给结构与自查）；不求职（→F8）；升学类**材料与时间线** → 本域（考研复试属本域，非 `F8`）
- **本域无对口 skill 的场景**（升学面试的**模拟问答 / 追问演练**）：按 `library/general-fallback.md` §3
  用**本域通用框架**承接（面试流程 · 评分维度 · 材料核验），**明确标注降级**，不假装覆盖；
  **不**改锁到求职面试域（语境错配）。

## 库内 skill（唯一通道，无需安装）

- **`grad-plan`** — 升学路径规划（自建）
  先定路径（保研/考研/留学），再倒排时间线，标出每个节点的硬性材料。

- **`grad-calendar`** — 升学时间线（自建）
  把保研/考研/留学三条线拆成月份级时间轴与材料倒排，文书只给结构。

- **`school-pick`** — 选校与夏令营（自建）
  按「冲 / 稳 / 保」梯度做选校与夏令营投递策略，给梯度配置与投递时间表，不代写申请材料。

- **`material-kit`** — 升学材料结构（自建）
  给个人陈述 / 研究计划 / 推荐信材料的「结构骨架与自查清单」，只搭框架与检查真实完整性，不代写正文。
