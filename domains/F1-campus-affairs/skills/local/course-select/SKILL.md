# 选课与培养方案核对

- **归属域**：`F1` 校园事务（生活类）
- **来源**：自建
- **覆盖主体**：N 新生 · U 在读本科
- **定位**：把培养方案与已修学分做成对照表，核对必修 / 选修 / 学分缺口与选课时间节点，只给核对方法与入口，不代抢课。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：培养方案与学分核对、选课 / 退补选时间节点、重修规则梳理
- 不覆盖：代选课 / 抢课（见红线，不代操作系统）；缴费金额（→`F4`）；开具证明（→`campus-proof-guide`）

## 执行步骤

1. 取本专业培养方案与自己的已修成绩单
2. 按必修 / 限选 / 任选三类逐项打勾，算学分进度
3. 列出待修缺口与开课学期
4. 确认选课 / 退补选时间节点（以教务通知为准）
5. 输出核对表与时间节点，代操作一律引导到教务系统自行完成

## 方法库 · 判定细则

**学分核对口径**：

| 类别 | 判据 | 常见坑 |
|---|---|---|
| 必修 | 方案标「必修」 | 同名不同课的学分不互认 |
| 限选 | 需在方向模块内选满 | 选够门数但不在模块内 |
| 任选 | 总量达标即可 | 重复算同一门 |

**时间节点**：选课、退补选、重修报名三者窗口不重叠，逐个记。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我大二，想核对下我的学分还差多少、下学期该选什么

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】先按三类课程核学分缺口，再对开课学期选课。
【依据】选课与培养方案核对：学分核对表
【结果】① 三类打勾 ② 算缺口 ③ 对开课学期 ④ 记选课节点
       → 产出：学分核对表 + 待选清单
【下一步】把成绩单与培养方案发我，逐项核对
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我登录教务系统把课选上

**澄清判定**：命中红线（代操作系统）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不代操作系统；可给选课入口与核对待办清单。
【依据】合规边界：不代操作系统（选课）
【替代方案】提供入口与选课顺序建议
【下一步】按待选清单自行登录教务系统选课
```

## ⚠️ 红线（不得绕过）

- **不代操作系统**（选课 / 提交 / 报名）—— 只给入口与路径；**缴费 / 代缴属 `F4`**
- L3 禁读：缴费金额 / 银行卡 / 身份证 / 家庭信息
