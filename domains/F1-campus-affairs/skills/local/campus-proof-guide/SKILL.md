# 证明开具指引

- **归属域**：`F1` 校园事务（生活类）
- **来源**：自建
- **定位**：把「要开什么证明」映射到对口部门、材料清单与办理周期，只给路径不代操作。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：在学证明、成绩证明、党团关系、户籍等开具路径
- 不覆盖：不代操作系统（→红线）；不读成绩明细（→L3）

## 执行步骤

1. 先判定证明类型（在学 / 成绩 / 党团 / 户籍 / 出国）与用途国别
2. 查 DUT 信息库锁定对口部门与办公地点
3. 列出材料清单（学生证 / 一寸照 / 申请表 / 用途说明）
4. 给出办理周期与是否可线上办
5. 信息库未收录时固定回复「未收录，建议访问 www.dlut.edu.cn 核实」

## 方法库 · 判定细则

**证明 → 部门映射**：

| 证明 | 对口 |
|---|---|
| 在学证明 | 学院 / 教务处 |
| 成绩单 | 教务处 |
| 党团证明 | 学院党委 / 团委 |

**周期**：多数 1–3 个工作日，以部门答复为准。

**判定顺序**：先判是不是「代办理 / 代盖章 / 代提交」请求（是则只给部门、材料与周期）→ 再判证明类型与用途国别（决定要中文版还是英文版）→ 最后才给材料清单与周期。

**高频误判**

- ❌ 把「帮我去盖个章交过来」当加急代办 → ✅ 只给部门、材料与周期，代办一律拒绝
- ❌ 不问用途国别就报份数 → ✅ 出国用途常需英文版，份数与语种由用途决定
- ❌ 把成绩证明当成绩查询 → ✅ 成绩明细属禁读范围，只给办理路径
- ❌ 周期给一个确定天数 → ✅ 周期以部门答复为准，只给大致区间
- ❌ 信息库没收录就编一个部门 → ✅ 未收录时按固定口径引导去官网核实

## 可执行示例

**示例 1（正常命中）**

**输入**

> 出国交流要开在学证明和成绩证明，去哪儿办？

**澄清判定**：对象（在学 + 成绩证明）、任务（去哪办）明确 → 放行；命中校情横切不追问

**输出**

```
【结论】在学证明找教务处，成绩证明找教务处（含英文版），均需带学生证。
【依据】已核验的官方部门入口
【网址】教务处 https://teach.dlut.edu.cn/
【状态】✅ 已核验
【建议】成绩证明含明细，本工具不代读；请本人到系统或窗口申请
【下一步】先确认用途国别是否要英文版，再决定办几份
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我去学院把证明盖好章交过来

**澄清判定**：命中红线（代操作）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**为什么这样判**：办理与盖章需要本人到场，本 skill 只负责把部门、材料与周期说清楚（只降级不代劳，不是空手退回）。

**输出**

```
【结论】不代办理盖章；可给部门、材料与周期。
【依据】合规边界：不代操作系统
【结果】只交付部门映射、材料清单与办理周期，办理与盖章由你本人完成 —— 代办一律只降级不代劳。
【替代方案】证明—部门映射表 + 材料清单
【下一步】按清单本人办理，缺材料再问我
```

## ⚠️ 红线（不得绕过）

- **不代操作系统**（选课 / 提交 / 报名）—— 只给入口与路径；**缴费 / 代缴属 `F4`**
- L3 禁读：缴费金额 / 银行卡 / 身份证 / 家庭信息
