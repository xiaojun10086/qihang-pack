# 分步讲解

- **归属域**：`S1` 课程答疑（学习类）
- **来源**：自建
- **定位**：先让学习者自己写一步，再按「定位卡点 → 给提示 → 给解法 → 出同类题」四步走，不直接抛答案。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 5%）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：单点题目/概念的分步讲解、错因诊断、举一反三
- 不覆盖：不代写作业（→S3）；不做整门课备考规划（→S4）

## 执行步骤

1. 复述题目并确认理解（防理解偏差）
2. 要求学习者先写出自己想到的第一步
3. 定位卡点：概念不清 / 方法不会 / 计算失误（三者处理方式不同）
4. 给一句关键提示（不是答案）
5. 给完整解法，标出每一步依据
6. 出 1 道同类题并留白，不代做

## 输出

按 `library/output-spec.md` 模板输出，默认 ≤ 6 条要点。
