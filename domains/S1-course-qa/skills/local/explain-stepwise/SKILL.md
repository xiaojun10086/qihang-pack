# 分步讲解

- **归属域**：`S1` 课程答疑（学习类）
- **来源**：自建
- **定位**：先让学习者自己写一步，再按「定位卡点 → 给提示 → 给解法 → 出同类题」四步走，不直接抛答案。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：单点题目/概念的分步讲解、错因诊断、举一反三
- 不覆盖：不代写作业（→S3）；不做整门课备考规划（→S4）

## 执行步骤

1. 复述题目并确认理解（防理解偏差）
2. 要求学习者先写出自己想到的第一步
3. 定位卡点：概念不清 / 方法不会 / 计算失误（三者处理方式不同）
4. 给一句关键提示（不是答案）
5. 给完整解法，标出每一步依据
6. 出 1 道同类题并留白，不代做

## 方法库 · 判定细则

| 卡点类型 | 判别信号 | 处理方式 |
|---|---|---|
| 概念不清 | 说不出符号 / 术语含义 | 补定义，再回原题 |
| 方法不会 | 知道要什么但想不到手段 | 给同类题的方法模板 |
| 计算失误 | 思路对、结果错 | 只查运算步骤，不重讲概念 |
| 审题偏差 | 答非所问 | 先复述题意，确认口径 |

**顺序纪律**：一次只处理一类卡点；混在一起讲会让学生误以为「全都不会」。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 老师，这道极限题 x→0 时 (sin x − x)/x³，为什么先做等价无穷小代换是错的？

**澄清判定**：对象明确、任务明确 → 关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 **放行**（U = 0.311 > 0.30，缺口仅在 `W/C/B`，不影响执行）

**输出**

```
【结论】等价无穷小只能替换"乘积因子"，这里是相减，必须泰勒展开到 x³。
【依据】sin x = x − x³/6 + o(x³)；卡点定位 → 提示 → 解法 → 同类题四步流程
【结果】① 展开 sin x 到 x³ 项
       ② 相减，x 消去，得 −x³/6
       ③ 除以 x³ → −1/6
       ④ 回讲为什么代换失败：减法产生同阶抵消
【下一步】用同法算 (tan x − x)/x³，做完发我
【建议】第 4 步的同类题留白
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 这三道题我都做错了，帮我看看为什么错

**澄清判定**：任务明确但属错因归因而非讲解 → 依 `clarity.md` §5 例外 2 放行后改锁 `error-diagnose`

**输出**

```
[已降级] 由「分步讲解」改为「错因归因」
【结论】这属于「错因归因」类需求，已改按该方式处理。
【下一步】提交三道错题与你的解法，走错因四分类
```
