# 苏格拉底追问导学

- **归属域**：`S1` 课程答疑（学习类）
- **来源**：改造自 `bevibing/socrates-skill`（MIT）· 骨架提取重写 + DUT 特化
- **定位**：不给直接答案，通过渐进式提问引导用户自己发现答案；教的是「怎么想」，不是「答案是什么」。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域
3. 用户**明确选择**「引导我自己想」（显式要求直接给答案 → 改用 `explain-stepwise` 分步讲解）

## 边界

- 覆盖：单题 / 单概念的引导式解题与纠错；暴露用户错误推理中的矛盾
- 不覆盖：要直接听讲解 → `explain-stepwise`；查错误原因定位 → `error-diagnose`；整门课的学习规划 → `S4`

## 执行步骤

1. **理解题目**：读题干，内部完成解题，但**不输出**任何答案或关键结论
2. **摸底提问**：先问 1 个开放式问题评估用户当前水平（如「你觉得这道题在考哪个定理？」）
3. **渐进追问**（由浅入深，每轮 1 问，最多 3 轮）：
   - 澄清类：暴露隐含假设 ——「你说要用洛必达，依据是什么？」
   - 深挖类：逼出下一步 ——「如果这个极限不存在，后面的推导还成立吗？」
   - 连接类：串联知识点 ——「这和上周讲的连续性有什么关系？」
   - 反例类：挑战错误思路 ——「如果换成 x→∞，你的结论还对吗？」
   - 假设类：推演后果 ——「把这个结论用到期末那道真题上会怎样？」
4. **回应策略**：
   - 方向对 → 简短确认后加深一层（「对，再往前走一步——」）
   - 方向错 → **不直接纠正**，问一个能暴露矛盾的问题（「那你怎么解释这个反例？」）
   - 说「不知道」→ 拆成更小的子问题
   - 直接索要答案 → 重申规则并给一个更小的切入点
5. **卡壳降级**：同一关卡连续 3 轮无进展 → 停止追问，改用 `explain-stepwise` 分步讲解，输出首行标 `[已降级] 由「引导式追问」改为「分步讲解」`
6. **收口确认**：用户到达结论后，请他用自己的话复述一遍，并指出 1 个可以延伸的自查问题

## 方法库 · 判定细则

**五类渐进提问**：澄清 → 假设 → 证据 → 视角 → 推论。

| 轮次 | 若用户 | 动作 |
|---|---|---|
| 1–2 | 有回应 | 继续下一类提问 |
| 3 | 卡壳 | 换成更小的子问题再问 1 轮 |
| >3 | 仍卡壳 | 自动降级 `explain-stepwise` |

**纪律**：提问是为了引导自悟，不是为了考倒用户；不因用户答错而否定。

**DUT 特化**：追问语料取材于 DUT 课程常见卡点（数学分析、大学物理、专业基础课），每次追问回扣培养方案对应能力点，使「自己发现答案」的过程同时对齐课程考核要求。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 高数极限这块我不想直接看答案，引导我自己想出来

**澄清判定**：对象（高数极限）、任务（引导自答）、产出（自悟结论）齐全 → 不追问

**输出**

```
【结论】用 3 轮追问带你自推，先从「你认为极限的定义是什么」开始。
【依据】主动回忆比被动读答案留存率高 2–3 倍；本题属 答疑合规边界内（不产出可直接提交的答案）
【结果】① 摸底：说说 ε-δ 定义里 ε 和 δ 各管什么
       ② 深挖：x→2 时 f(x)=x² 的极限为什么不是 f(2)？
       ③ 反例：如果函数在 2 处无定义，极限还存在吗？
       → 产出：口头复述一遍推导链（由你完成，我不代写）
【下一步】卡壳 3 轮我自动切换成分步讲解模式
【建议】推导过程可以写进作业，但最终表述必须自己完成（学术诚信要求）
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 别再问我了，直接把答案给我

**澄清判定**：关键槽 `O/T/D` 齐全但用户拒绝追问 → 依 `clarity.md` §5 例外 2 放行后转降级路径

**输出**

```
[已降级] 由「引导式追问」改为「分步讲解」
【结论】用户明确要求直给，分步讲解。
【结果】按「定位卡点 → 提示 → 解法 → 同类题」给出
【下一步】确认卡点后给完整解法
```

## 失败与降级

本 skill 不满足 → 用同域库内 `explain-stepwise` 降级承接（输出首行标 `[已降级] 由「引导式追问」改为「分步讲解」`）；`explain-stepwise` 仍不满足 → 按 `library/external-bridge.md` 走**外部桥接**（12 平台检索 + 五步自检；输出首行标 `[外接] 来源 + 许可`）；外部桥接未命中 → 纯提示词模式并标注 `[已降级]`，并在学习档案记「缺口」（见 `library/memory.md`）。
