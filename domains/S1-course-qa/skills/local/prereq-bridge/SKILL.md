# 先修补桥

- **归属域**：`S1` 课程答疑（学习类）
- **来源**：自建
- **覆盖主体**：N 新生 · U 在读本科（前置断层者）
- **定位**：当卡点不在本题而在前置知识断层时，先回溯定位断点、只补一节最小前置，再回到原题继续。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：前置知识断点定位与最小补齐、知识链条回溯
- 不覆盖：单题分步讲解（→`explain-stepwise`）；错因归类（→`error-diagnose`）；整门课补课规划（→`S4`）

## 执行步骤

1. 让学习者写出当前卡在哪一步
2. 沿该步回溯 2–3 层找最早讲不清的概念
3. 判定断点类型（定义 / 定理条件 / 运算规则）
4. 只补解决当前卡点所需的最小前置单元，但须把该单元讲到可理解、可应用；不以「最小」为由只抛公式或结论
5. 用原题的下一步验证补齐是否生效
6. 给出断点清单与建议复习章节

## 方法库 · 判定细则

| 断点类型 | 特征 | 处理方式 |
|---|---|---|
| 定义没记牢 | 说不出符号含义 | 补定义 + 1 个最小例子 |
| 定理条件不清 | 忽略前提直接用 | 补条件对照表 + 反例 |
| 运算规则用错 | 步骤对、结果错 | 补规则 + 易错反例 |

**判定顺序**：先判卡点**是不是前置断层**——若当前步骤所需概念用户讲得清，说明是单题问题，转 `explain-stepwise`；再沿步骤回溯定位最早讲不清的一层；最后判断点类型（定义 / 定理条件 / 运算规则）。

**高频误判**

- ❌ 把「这题太难」当断层 → ✅ 须让学习者写出卡在哪一步，凭回溯定位，不凭难度感觉
- ❌ 一路追到中学内容 → ✅ 相邻层级讲得清即停，过度回溯会脱离原题
- ❌ 只抛公式或结论当补齐 → ✅ 最小补齐指**范围**最小，不是**深度**最小，须讲到可理解、可应用
- ❌ 断点判成「不会算」就只练运算 → ✅ 运算对而概念错时，真断点在定义或定理条件
- ❌ 补完不回原题验证 → ✅ 补齐是否生效，要用原题的下一步检验

回溯停止条件：连续两层都能讲清楚，即停 —— 不要一路追到高中内容。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我求 f(x)=x²ln x 的极值，做到求导就不会了

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】卡点在乘法求导法则，不是极值判定。
【依据】断点回溯：极值步骤依赖求导，求导断在乘法法则
【结果】① 补 (uv)′=u′v+uv′ ② 用 f=x²·ln x 演练 ③ 回原题求导
       → 产出：断点清单（乘法求导法则）
【下一步】对 f 求导后发我，继续判定极值
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我讲一下拉格朗日中值定理的证明

**澄清判定**：任务明确，但不属本 skill——用户要的是这个定理本身的讲解，未暴露前置断层 → 依 `clarity.md` §5 例外 2 放行后改锁 `explain-stepwise`

**为什么这样判**：本 skill 只补前置断层，用户要的是该定理本身的讲解、未暴露断层；单点讲解改锁 `explain-stepwise`（是换路径，不是拒答）。

**输出**

```
[已降级] 由「先修补桥」改为「分步讲解」
【结论】你要的是这个定理本身的证明，不是某处前置断层，已改按分步讲解处理。
【结果】若你写证明时卡在某一步，把该步发我，再判断是否需要补前置。
【下一步】提交该题原文，走分步讲解
```
