# 易混辨析

- **归属域**：`S1` 课程答疑（学习类）
- **来源**：自建
- **覆盖主体**：U 在读本科（考前辨析）
- **定位**：把一组常被混淆的概念、公式或定理放进同一张多维度对照表，逐项给出差异与适用条件，用于考前快速区分。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：易混概念 / 公式 / 定理的多维对照辨析、适用条件区分
- 不覆盖：单个概念的分步讲解（→`explain-stepwise`）；错题归因（→`error-diagnose`）；备考排程（→`S4`）

## 执行步骤

1. 列出被混淆的 2–4 个对象，确认同属一个上位概念
2. 选 3–4 个辨析维度（定义域 / 条件 / 结论 / 反例）
3. 逐维度填对照表，标出「唯一差异点」
4. 对每个关键差异给出能说明边界的例子或反例；若用户要求完整辨析，不能只给口诀或只列结论
5. 总结判别方法，并说明它适用的条件与容易误用之处

## 方法库 · 判定细则

**维度选择四问**（每次都从这四问里挑，避免维度漂移）：
1. 适用范围一样吗？→ 定义域 / 前提条件维度
2. 结论强弱一样吗？→ 充分必要维度
3. 反过来成立吗？→ 逆命题维度
4. 有没有只属于一个的反例？→ 反例维度

**判据**：若四个维度下表完全一致 → 这两个对象其实是同一个，停止辨析并告知用户。

**判定顺序**：先判对象是否**同属一个上位概念且真会被混**——若只是「想了解某个概念」，转 `explain-stepwise`；再选辨析维度；最后找唯一差异点。

**高频误判**

- ❌ 把「讲一下 X」当辨析 → ✅ 只有一个对象时无从对照，属讲解
- ❌ 维度漂移 → ✅ 每次都从既定维度里挑，不临时另起，否则各列不可比
- ❌ 对照表填成定义复述 → ✅ 每格须落在**差异**上，相同项不必逐格重复
- ❌ 只给口诀不给反例 → ✅ 边界靠反例确立，口诀不能替代适用条件
- ❌ 对象其实等价却硬找差异 → ✅ 各维度全一致即说明同源，停止辨析

## 可执行示例

**示例 1（正常命中）**

**输入**

> 极限、连续、可导、可微到底啥区别，考试老混

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】四者是逐级加强，可微⇒可导⇒连续⇒极限存在，箭头不可逆。
【依据】易混辨析：选取「蕴含关系 / 反例 / 维数」三个维度对照
【结果】① 排陈述蕴含链 ② 标每处反例（|x| 在 0 处）③ 给口诀
       → 产出：一张四行三列对照表
【下一步】用 |x| 自测：连续可否导？答完发我
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我写一下导数的定义式

**澄清判定**：任务明确，但只有一个对象、无对照需求 → 依 `clarity.md` §5 例外 2 放行后改锁 `explain-stepwise`

**为什么这样判**：对照辨析靠多个对象之间的差异定位，单个定义式没有可对照的对象；单点讲解改锁 `explain-stepwise`（是换路径，不是拒答）。

**输出**

```
[已降级] 由「易混辨析」改为「分步讲解」
【结论】只问一个定义式，没有可对照的对象，已改按分步讲解处理。
【结果】若你把它和相邻概念混了，把那组概念发我，再走对照辨析。
【下一步】提交该题原文，走分步讲解
```
