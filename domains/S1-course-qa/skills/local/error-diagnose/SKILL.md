# 错因归因

- **归属域**：`S1` 课程答疑（学习类）
- **来源**：自建
- **定位**：把做错的题按「概念 / 方法 / 计算 / 审题」四类归因，输出错因清单与再练顺序，不代做。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：错题归因、薄弱点定位、再练顺序
- 不覆盖：不代做（→红线）；不整门课备考规划（→S4）

## 执行步骤

1. 收 3–5 道错题（标明是作业题还是自练题）
2. 逐题判断错因四类：概念不清 / 方法不会 / 计算失误 / 审题偏差
3. 统计各类占比，找出占比最高的那一类
4. 针对最高类给 1 条纠正动作
5. 按「先修概念、再练同类」排出再练顺序，留白不给答案

## 方法库 · 判定细则

| 错因 | 判据 | 再练顺序 |
|---|---|---|
| 概念 | 同类题全错 | 先补概念 |
| 方法 | 概念懂但换形就不会 | 归纳题型模板 |
| 计算 | 思路对、步骤错 | 专练运算 |
| 审题 | 题意理解偏 | 练读题标注 |

**纪律**：只对**已发生的错**归因，不预测、不代做；同一错题只归一类主因。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 这几道题我都做错了，怎么回事？
1) 求 lim(sin x − x)/x³  2) 求 ∫x·ln x dx  3) 解 2x²−5x+3=0

**澄清判定**：对象明确（3 道具体题）、任务明确（归因）→ 关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 **放行**（U = 0.311 > 0.30）

**输出**

```
【结论】3 道题里 2 道是"方法不会"、1 道是"计算失误"，先补方法再练计算。
【依据】错因归因流程
【结果】① 第 1 题：等价无穷小误用 → 方法类（改泰勒展开）
　　　　② 第 2 题：分部积分公式记反 → 方法类
　　　　③ 第 3 题：因式分解算错符号 → 计算类
【下一步】先把"分部积分公式"抄写 3 遍默写一遍，回我
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 这道题我不会，帮我讲一下怎么做

**澄清判定**：任务明确但属单题讲解 → 依 `clarity.md` §5 例外 2 放行后改锁 `explain-stepwise`

**输出**

```
[已降级] 由「错因归因」改为「分步讲解」
【结论】这属于「分步讲解」类需求，已改按该方式处理。
【下一步】提交题目原文，走四步讲解
```
