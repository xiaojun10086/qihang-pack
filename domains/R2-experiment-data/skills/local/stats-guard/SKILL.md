# 统计自查

- **归属域**：`R2` 实验与数据（科研类）
- **来源**：自建
- **定位**：选检验方法、看检验力、列「不能下的结论」，不补造不篡改数据。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：检验方法选择、检验力评估、结论边界声明
- 不覆盖：不补造/不篡改/不选择性报告数据（→红线）

## 执行步骤

1. 确认数据结构（分组数、样本量、配对与否、分布假设）
2. 选检验方法并说明所需假设
3. 做检验力/效应量评估，判断"不显著"是没效应还是样本不够
4. 列出「不能下的结论」：不推因果 / 不外推总体 / 不称证明
5. 给下一步：需要多少样本或哪种设计

## 方法库 · 判定细则

**检验方法速查 + 前提检查**：

| 前提 | 检查方式 | 不满足时 |
|---|---|---|
| 正态性 | 直方图 / QQ 图 / 正态检验 | 换非参 |
| 方差齐性 | Levene 检验 | 用校正 t / Welch |
| 独立性 | 抽样设计核验 | 换配对 / 混合模型 |
| 样本量 | 检验力估算 | 报备检验力不足 |

**纪律**：只报**能下的结论**，明确列「不能下的结论」；不补造缺失值、不删不利数据点。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 跑了 3 次 p 都在 0.08 左右，是不是样本太小？

**澄清判定**：对象（p 值/样本）、任务（判断）明确 → 放行；不请求补造数据

**输出**

```
【结论】p≈0.08 是"证据不足"，不是"没效应"；先算检验力再决定补样本。
【依据】统计自查流程
【结果】① 当前 n 下的检验力约 0.45，偏低
　　　　② 要 0.8 的检验力，n 需补到约 2.2 倍
　　　　③ 不能下的结论：不推因果、不外推到他校样本
　　　　→ 产出：data/统计自检.md
【下一步】先按现有 n 报效应量与置信区间，再决定是否补做
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 缺的几个数据点你按均值给我补上吧

**澄清判定**：命中本域红线（补造数据）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝

**输出**

```
【结论】不补造数据；缺失数据应如实标注并说明处理方式。
【依据】合规边界：不补造、不篡改数据
【替代方案】给缺失机制判定 + 合规的缺失处理选项（标注 / 敏感性分析）
【下一步】把缺失位置与量表口径发我，我给出处理建议
```

## ⚠️ 红线（不得绕过）

- **不补造、不篡改、不选择性报告数据**；不得为达成 p<0.05 而调整样本
- 结论后**必须列出「不能下的结论」**（不推因果 / 不外推总体 / 不称「证明」）
