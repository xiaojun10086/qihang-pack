# 数据实验台

- **归属域**：`R2` 实验与数据（科研类）
- **来源**：自建
- **定位**：先确认数据与假设，再选检验方法，跑完给出「图 + 一句话结论 + 不能下的结论」。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 0.30）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：实验设计、数据处理、统计检验、图表规范
- 不覆盖：不写报告结构（→S3）

## 执行步骤

1. 确认数据类型（连续/分类）与样本量
2. 明确要检验的假设
3. 选检验方法并说明前提（正态性、独立性）
4. 跑分析，出出版级图表（标注单位与误差棒）
5. 给一句话结论 + 明确列出不能下的结论
6. 输出脚本与图表

## 可执行示例

**输入**

> 我有两组数据，想比较有没有显著差异

**澄清判定**：缺「数据类型/样本量/配对与否」→ 追问 2 问

**输出**

```
【结论】先看是否配对、是否正态，再决定用 t 检验还是秩和检验。
【依据】库内 skill data-lab（自建）
【步骤】① 确认：配对？样本量？连续还是分类？
       ② 正态性检验：Shapiro-Wilk
       ③ 选检验：配对+正态→配对 t；否则→Wilcoxon
       ④ 出图：箱线图 + 误差棒 + p 值标注
【产物】analysis/两组比较.ipynb + 图
【下一步】先回我"是否配对 + 各多少例"
【声明】只给统计结论，**明确列出不能下的结论**（如不能推因果）
```

## ⚠️ 红线（不得绕过）

- **不补造、不篡改、不选择性报告数据**；不得为达成 p<0.05 而调整样本
- 结论后**必须列出「不能下的结论」**（不推因果 / 不外推总体 / 不称「证明」）
