# 数据实验台

- **归属域**：`R2` 实验与数据（科研类）
- **来源**：自建
- **定位**：先确认数据与假设，再选检验方法，跑完给出「图 + 一句话结论 + 不能下的结论」。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 5%）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：实验设计、数据处理、统计检验、图表规范
- 不覆盖：不写报告结构（→S3）

## 执行步骤

1. 确认数据类型（连续/分类）与样本量
2. 明确要检验的假设
3. 选检验方法并说明前提（正态性、独立性）
4. 跑分析，出出版级图表（标注单位与误差棒）
5. 给一句话结论 + 明确列出不能下的结论
6. 输出脚本与图表

## 输出

按 `library/output-spec.md` 模板输出，默认 ≤ 6 条要点。
