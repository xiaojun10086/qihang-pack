# 图表规范

- **归属域**：`R2` 实验与数据（科研类）
- **来源**：自建
- **覆盖主体**：U 在读本科 · M 硕士
- **定位**：按期刊 / 学位论文的图表规范给图型选择、坐标轴 / 误差棒 / 显著性标注与分辨率要求清单，不代画数据。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：图型选择、坐标轴与误差棒规范、显著性标注、分辨率与格式要求
- 不覆盖：数据造假 / 美化（见红线）；统计分析（→`stats-workflow`）；实验设计（→`exp-design`）

## 执行步骤

1. 明确图要表达的关系（比较 / 分布 / 相关 / 构成）
2. 按关系选图型并给出「不建议」的图型
3. 检查坐标轴单位、量程、误差棒与样本量标注
4. 落显著性标注与图注要素
5. 给分辨率 / 矢量图 / 配色可达性要求

## 方法库 · 判定细则

| 关系 | 推荐图型 | 不建议 |
|---|---|---|
| 比较 | 条形 / 箱线 | 3D 饼图 |
| 分布 | 直方 / 密度 | 折线代替分布 |
| 相关 | 散点 + 拟合 | 双 Y 轴硬凑 |
| 构成 | 堆叠条 | 多饼图 |

**分辨率**：位图 ≥ 300 dpi，线图优先矢量（PDF / EPS）。

**判定顺序**：先判是不是「改图让结果更显著」请求，是则只给真实数据的规范要素 → 再判要表达的关系（比较 / 分布 / 相关 / 构成）→ 最后才选图型与分辨率。

**高频误判**

- ❌ 把「改成看起来更显著」当美化 → ✅ 不篡改误差棒，也不选择性呈现
- ❌ 用 3D 饼图做比较 → ✅ 比较用条形或箱线，3D 饼图会误读
- ❌ 用折线表示分布 → ✅ 分布用直方或密度，折线代替分布会掩盖形态
- ❌ 双 Y 轴硬凑相关性 → ✅ 相关用散点加拟合，双 Y 轴会造出假相关
- ❌ 图导出分辨率不足 → ✅ 位图不低于 300 dpi，线图优先矢量格式

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我论文里这张图导师说看不出结论，怎么改

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】先确认要表达的关系，再换图型并补误差棒与单位。
【依据】图表规范：图型 × 关系对照
【结果】① 定关系 ② 换图型 ③ 补误差棒 / 单位 ④ 落显著性标注
       → 产出：图表要素检查清单
【下一步】把这张图的原始数据发我，判断该换哪种图型
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我把误差棒改成看起来更显著

**澄清判定**：命中红线（篡改 / 选择性呈现）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**为什么这样判**：篡改误差棒与选择性呈现属禁答范围，本 skill 一律只降级不代劳，只做真实数据的规范出图。

**输出**

```
【结论】不篡改误差棒或选择性呈现；可规范标注真实结果。
【依据】合规边界：不补造 / 不篡改 / 不选择性报告数据
【结果】只交付真实数据的规范图表要素清单，图型与标注按实际结果定 —— 改图类请求一律只降级不代劳。
【替代方案】真实数据的规范图表要素清单
【下一步】把真实数据发我，给出合规的图型与标注方案
```

## ⚠️ 红线（不得绕过）

- **不补造、不篡改、不选择性报告数据**；不得为达成 p<0.05 而调整样本
- 结论后**必须列出「不能下的结论」**（不推因果 / 不外推总体 / 不称「证明」）
