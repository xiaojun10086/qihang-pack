# 统计分析流程

- **归属域**：`R2` 实验与数据（科研类）
- **来源**：改造自 `K-Dense-AI/scientific-agent-skills`（MIT，statistical-analysis）· 骨架提取重写 + DUT 特化
- **定位**：管「怎么分析」的纪律——问题 → 数据 → 检验 → 前提 → 结果 → 报告六步强制顺序，防「先选好检验再找数据凑」。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：实验 / 调研数据的检验选择、前提检查、效应量计算、结果写作模板（APA 风格）
- 不覆盖：数据造假核查 → `data-lab`；实验设计本身 → `R2` 域通用框架（`library/general-fallback.md` §3）；环境搭建 → `R3`

## 执行步骤

1. **先框问题再碰数据**：写下 ① 假设 ② 因变量与自变量 ③ 设计类型（独立 / 配对 / 重复测量）——选检验由设计决定，不是反过来
2. **看原始数据**：每组的 n、均值、标准差、缺失值；先画直方图 / 箱线图再谈检验——异常值、天花板 / 地板效应要向用户点名，不得静默处理
3. **选检验速查**：
   - 两组独立均值 → 预设 Welch t 检验（不假定方差齐性）
   - 配对均值 → 配对 t 检验（对配对差值做）
   - 多组 → Welch ANOVA；秩比较 → Mann-Whitney / Kruskal-Wallis
   - 关联 → Pearson（线性）/ Spearman（单调）；按科学问题选，不用正态性预检来选
4. **查前提并报告**：正态性（Q-Q 图 + 检验）、方差齐性、独立性——**前提检查结果必须写进报告**（评阅人会看）
5. **效应量必算**：p 值只说「与零模型不相容到什么程度」；效应量（Cohen's d / η² / r）+ 置信区间才支撑「实际重要性」的判断
6. **结果写作模板**：`描述统计（M±SD）+ 检验统计量 + 精确 p 值 + 效应量[95%CI] + 前提核查声明`
7. 输出「分析决策表 + 结果段落草稿（数据留空由用户填）」

## 方法库 · 判定细则

**六步强制顺序**（不得跳步、不得回退凑）：

| 步 | 内容 | 卡点 |
|---|---|---|
| 1 | 问题 | 研究问题未定不选检验 |
| 2 | 数据 | 结构 / 缺失 / 类型未清不动手 |
| 3 | 检验 | 依数据定检验 |
| 4 | 前提 | 前提不过换非参 |
| 5 | 结果 | 报效应量与区间 |
| 6 | 报告 | 附「不能下的结论」 |

**纪律**：顺序即纪律——**防「先选好检验再找数据凑」**；任何一步缺失就停下追问，不跳过。

**DUT 特化**：报告口径对齐 DUT 学位论文与课程报告格式要求（题注、单位、显著性标记），便于直接在答辩 / 提交场景落地。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 大物实验两组测量数据，一组 5 次一组 6 次，要比较有没有系统差异

**澄清判定**：对象（两组测量）、任务（比较差异）、设计（独立/配对待确认）——设计维度缺 → 追问 1 问

**追问**

【还需确认】两组是「同一批仪器同一样本重复测量」（配对）还是「两种方法各测各的」（独立）？

（用户答「两种方法」后放行）

**输出**

```
【结论】独立两均值比较走 Welch t 检验，先过前提再出效应量。
【依据】设计=独立两组（5 vs 6）；不假定方差齐性时 Welch 是预设选择
【步骤】① 框问题：H0=两方法均值相等；因变量=测量值；设计=独立
       ② 看数据：两组各 n、M、SD、离群点；箱线图先行
       ③ 前提：正态性 Q-Q 图 + Shapiro；结果写进报告
       ④ 检验：Welch t + Cohen's d[95%CI]
       ⑤ 报告模板：t(df)=…, p=…, d=…[CI]，附前提声明
【产物】analysis/决策表.md + 结果段落模板（数值留空你填）
【下一步】把两组原始数据发我（或自己按②–④跑）
【提醒】不改动任何实验读数（数据红线）；分析代码可代写、数据不代造
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 你先告诉我该用哪个检验就行，数据我还没整理完

**澄清判定**：顺序纪律下第 2 步（数据）未过 → 依 `clarity.md` §5 例外 2 放行后**追问**

**输出**

```
【结论】数据未整理，暂不能定检验——顺序第 2 步未过。
【依据】六步强制顺序：问题 → 数据 → 检验
【追问】数据是几组、什么类型、有无缺失？（三问即可定检验）
【下一步】回我这三项，我再给检验方案
```

## ⚠️ 红线（不得绕过）

- **不补造、不篡改、不选择性报告数据**；不得为达成 p<0.05 而调整样本
- 结论后**必须列出「不能下的结论」**（不推因果 / 不外推总体 / 不称「证明」）
