## 库内 skill（唯一通道，无需安装）

- **`data-lab`** — 数据实验台（自建）
  先确认数据与假设，再选检验方法，跑完给出「图 + 一句话结论 + 不能下的结论」。

- **`stats-guard`** — 统计自查（自建）
  选检验方法、看检验力、列「不能下的结论」，不补造不篡改数据。

- **`stats-workflow`** — （改造自外部 MIT 最优解 + DUT 特化）
  先框问题再碰数据、前提必查必报、效应量与 p 值并重的六步统计纪律

- **`exp-design`** — 实验设计（自建）
  给实验设计的要素检查：研究问题、变量与操作化、对照与随机化、样本量与重复，强调先设计再收数据。

- **`viz-spec`** — 图表规范（自建）
  按期刊 / 学位论文的图表规范给图型选择、坐标轴 / 误差棒 / 显著性标注与分辨率要求清单，不代画数据。

0. **先判红线**（见下文 `## ⚠️ 红线` 节）—— 命中则**拒绝并给合规替代**，**不追问**

2. 1 级库完成**域审查**，确认命中 `R2`（`library/domain-review.md`）
3. 用**库内 skill**（库内 5 个：`data-lab` · `stats-guard` · `stats-workflow` · `exp-design` · `viz-spec`；按需求择一）执行
4. **输出与保存**：按 `library/output-spec.md` 输出 ≤6 条要点；默认不读写学习档案，仅用户明确要求保存时按 `library/memory.md` 处理。
5. 按 `library/skill-evolution.md` 记录本域习惯，并**只在可改段内**做非结构性自迭代（不改红线 / 输出契约 / 任何事实；不满足触发条件则不迭代）
6. **外部桥接（按需）**：库内 skill 与同域降级都接不住，且外部能力确有帮助时，读 `library/external-bridge.md` → 只查本域指定平台 → 过五步自检 → 输出首行标 `[外接] 来源 + 许可`；**未命中则回落「纯提示词模式」**（原有流程）。

## ⚠️ 红线（不得绕过）

- **不补造、不篡改、不选择性报告数据**；不得为达成 p<0.05 而调整样本
- 结论后**必须列出「不能下的结论」**（不推因果 / 不外推总体 / 不称「证明」）
