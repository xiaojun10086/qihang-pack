# 深度工作日程

- **归属域**：`F2` 作息与专注（生活类）
- **来源**：改造自 `alirezarezvani/claude-skills`（MIT，deep-work）· 骨架提取重写 + DUT 特化
- **定位**：把「今天要干什么」变成一张注意力预算表——深度任务吃掉最好的时段，浅任务按预算封顶，超了就砍。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：单日任务清单的深浅分类、时间块排程、浅工作预算、收尾清单
- 不覆盖：单段专注块的技术与抗干扰 → `focus-block`；把大任务拆小 → `task-decompose`；情绪性拖延 → `F3`

## 执行步骤

1. **收任务清单**：让用户列出今天所有任务 + 预估分钟数（含上课 / 实验等硬性安排）
2. **分深浅**：
   - 深度 = 需要连续思考的产出型任务（写报告、推导、编码、复习难点）
   - 浅层 = 事务型（回消息、整理笔记格式、取快递、填表）
   - 浅层占比超 **50%** → 先逼问每个浅任务：「训练一个聪明新生来做，要几分钟？」能外包 / 合并 / 砍掉的先处理
3. **排时间块**（以 DUT 课表为硬边界）：
   - 深度块**最早**安排（人的精力上午最好），每块 ≥ 90 分钟，**全天深度总量 ≤ 4 小时**——超了就明确砍或顺延，不假装能做 6 小时
   - 浅任务最多 **2 个批次**（如 12:00–12:30、17:00–17:30），不零散撒
   - 每块之间留 10 分钟缓冲（注意力残留），午餐固定
   - 日程排不进 → 报「超预算」并列出砍单建议，**不静默延长到深夜**（违背 F2 健康作息红线）
4. **记录与连续性**：每完成一个深度块记 1 笔（时长 + 内容），每周对目标（建议 15 小时起步，按课表密度调整）；连续天数只是激励，不追求打卡焦虑
5. **收尾仪式**（每天最后 10 分钟）：① 把未完事项写进明天的清单 ② 扫一眼明天课表 ③ 说一句「今天到此为止」——未闭合的回路会偷走明天的第一个深度块
6. 输出「今日时间块表 + 浅工作预算」

## 方法库 · 判定细则

**注意力预算**：深度任务吃最好的时段，浅任务封顶。

| 任务 | 时段 | 上限 |
|---|---|---|
| 深度 | 上午 2 段 | 各 90 分钟 |
| 浅 | 午后 | 合计 ≤ 2 小时 |

**判据**：超预算的浅任务一律砍掉或改期，不挤占深度块。

**DUT 特化**：专注窗口直接对接 DUT 作息——按教学周节次（早八 / 上午 / 下午大节）切块，深度块避开排在早八与连堂课；自习落点优先图书馆伯川馆 / 令希馆开放时段，体育与场馆预约须走 i大工 APP（无网页版）。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 明天上午满课，下午没课，晚上有实验，但我得赶大物实验报告，还想刷会儿高数题

**澄清判定**：对象（明日日程）、任务（排深度计划）、约束（课表 + 实验报告 deadline）齐全 → 不追问

**输出**

```
【结论】实验报告是深度任务，下午最早开工连排 2 块；高数刷题降级为浅批次或顺延。
【依据】深度块应占精力最好的时段且日上限 4 小时；明日硬边界：上午满课 + 晚间实验
【步骤】① 深浅分类：实验报告=深(120min)；高数刷题=深(90min)；回消息/整理笔记=浅
       ② 排块：13:30–15:30 实验报告深块①；15:40–15:50 缓冲；
          16:00–17:30 高数深块②（今日深时 3.5h ≤ 4h 上限）
       ③ 浅批：12:00–12:30 午间批；实验结束后 21:00–21:20 收尾批
       ④ 收尾：21:30 前 10 分钟清空未完事项 → 明日清单
【产物】day/deep-work-{明日日期}.md（时间块表 + 浅预算 27%）
【下一步】实验结束后回报实际完成块数，累计本周深时
【提醒】不排 23:30 以后的深块（作息红线：睡眠窗口 23:30–07:00）
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 我大作业不知道从哪下手，帮我拆一下

**澄清判定**：任务明确但属任务拆解 → 依 `clarity.md` §5 例外 2 放行后改锁 `task-decompose`

**输出**

```
[已降级: deep-work → task-decompose]
【结论】属任务拆解，改由 task-decompose 承接。
【下一步】提交大作业要求与截止时间
```
