# 拖延干预

- **归属域**：`F2` 作息与专注（生活类）
- **来源**：自建
- **覆盖主体**：U 在读本科
- **定位**：先判定拖延类型（任务厌恶 / 完美主义 / 即时诱惑 / 目标模糊），再给对应的最小启动动作与承诺机制。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：拖延类型判定、最小启动动作设计、环境改造与承诺机制
- 不覆盖：心理诊断（见红线）；任务拆解（→`task-decompose`）；时间块排布（→`focus-block`）

## 执行步骤

1. 让用户描述最近一次拖延的具体情境与当时的念头
2. 判定类型：任务厌恶 / 完美主义 / 即时诱惑 / 目标模糊
3. 给该类型对应的最小启动动作（如「只做 2 分钟」）
4. 设计环境改造与承诺机制（去图书馆 / 公开承诺）
5. 约定下一次复盘时间点

## 方法库 · 判定细则

| 类型 | 特征 | 最小启动动作 |
|---|---|---|
| 任务厌恶 | 「一想到就烦」 | 只做 2 分钟，允许随时停 |
| 完美主义 | 「做不好不如不做」 | 先交一版「故意粗糙」草稿 |
| 即时诱惑 | 「拿起手机就停不下」 | 物理隔离 + 番茄钟 |
| 目标模糊 | 「不知道从哪开始」 | 先写一句「下一步是什么」 |

**判据**：类型判错的干预无效 —— 先描述情境，再下类型。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 一到写论文就刷手机，拖了一周了

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】属「即时诱惑」型，用物理隔离 + 2 分钟启动。
【依据】拖延干预：四类判定与对策
【结果】① 手机放另一房间 ② 设 25 分钟番茄钟 ③ 只写 2 分钟开头
       → 产出：一次可执行的启动动作
【下一步】今晚试一次，把「能不能坐下 25 分钟」的结果发我
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 我什么都不想干，觉得活着没意思

**澄清判定**：出现危机信号 → 依 `clarity.md` §5 例外 2 放行后按安全兜底改锁 `F3`（危机红线优先）

**输出**

```
[已降级] 由「拖延干预」改为「状态自查」
【结论】出现情绪危机信号，改由「心理与状态支持」承接并走危机转介。
【下一步】立即危机流程给 24h 可用通道
```
