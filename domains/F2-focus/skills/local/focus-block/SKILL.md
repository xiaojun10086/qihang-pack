# 专注块排布

- **归属域**：`F2` 作息与专注（生活类）
- **来源**：自建
- **定位**：先修作息再谈效率；每天只给 1 个最小可行动作（≤15 分钟）与固定专注窗口。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：作息调整、专注块排布、拖延干预、时间管理
- 不覆盖：不做学业规划内容（只在其中嵌入时间安排）

## 执行步骤

1. 读取 config.yaml 的 sleep_window
2. 判断是作息问题还是注意力问题（处理策略不同）
3. 设定本周唯一目标（只 1 个）
4. 排每日 1–2 个固定专注块，绑定trigger（如「图书馆坐下后」）
5. 累计连续天数，断了只记录不评判
6. 与 `S4` 备考排程联动

## 方法库 · 判定细则

**先修作息再谈专注**：每天给 1 个最小动作（≤15 分钟）+ 固定专注窗口。

| 变量 | 建议 |
|---|---|
| 专注窗口 | 固定同一时段 |
| 单块时长 | 25 或 45 分钟 |
| 干扰物 | 物理隔离 |

**判据**：作息未稳（入睡 > 1:00）先走 `sleep-reset`，不硬排专注块。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 每天都熬到两点，白天上课睡

**澄清判定**：对象=作息、任务=调整 → 不追问

**输出**

```
【结论】先修入睡时间，不谈效率，本周只做一件事。
【依据】作息设定：睡眠窗口 23:30–07:00
【结果】① 本周唯一目标：23:30 关灯（不求早睡，只求按时上床）
       ② 最小动作：22:50 手机放到床外充电
       ③ 每天 1 个固定专注块：14:00–15:30 图书馆
       ④ 连续天数只记录，断了不评判
       → 产出：habit/作息打卡.md
【下一步】今晚 22:50 执行第 ② 步，明早回我结果
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 我天天 3 点睡，作息全乱了

**澄清判定**：任务明确但属作息回调 → 依 `clarity.md` §5 例外 2 放行后改锁 `sleep-reset`

**输出**

```
[已降级] 由「专注块排布」改为「作息重置」
【结论】这属于「作息重置」类需求，已改按该方式处理。
【下一步】提交当前与目标作息，排回调表
```
