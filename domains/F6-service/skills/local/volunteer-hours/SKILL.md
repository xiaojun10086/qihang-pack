# 志愿时长规划

- **归属域**：`F6` 军训与志愿（生活类）
- **来源**：自建
- **定位**：把志愿时长/第二课堂要求拆到月，给选项目原则与记录模板，不鼓励带病硬撑。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 0.30）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：志愿时长规划、项目选择、时长归档
- 不覆盖：不鼓励带病硬撑；伤病改锁 F5（→红线）

## 执行步骤

1. 确认学校要求（时长下限、截止学期、认定口径）
2. 倒推每月需完成的小时数
3. 按「就近 + 与专业相关 + 可连续」三条原则筛项目
4. 给记录模板：日期 / 项目 / 时长 / 证明人 / 收获一句话
5. 留出 1 个月缓冲防认定不通过

## 可执行示例

**输入**

> 志愿时长还差 20 小时，这学期要交，怎么办？

**澄清判定**：对象（志愿时长）、时间（本学期）、产出（怎么办）明确 → 放行

**输出**

```
【结论】剩 10 周，每周 2 小时就够，优先选校内可连续的项目。
【依据】志愿时长规划（库内 skill volunteer-hours）
【步骤】① 本周查认定口径（哪些项目算）
　　　　② 每周固定 2 小时，选校内图书馆引导岗
　　　　③ 每次记一行：日期/项目/时长/证明人
【产物】service/志愿记录.md
【下一步】今天先到校团委网站确认可认定项目清单
```

## ⚠️ 红线（不得绕过）

- 军训期身体不适**不鼓励硬撑**，一律先报告教官
- **伤病 → 改锁 `F5`**；严重（中暑晕倒 / 骨折 / 意识不清）→ 直接 120
- 志愿时长与第二课堂以学校系统为准，本包只做归档建议

> 本红线**继承自 `../../_domain.md`**，不得在本 skill 内单独放宽；如与域文件冲突，以域文件为准。
