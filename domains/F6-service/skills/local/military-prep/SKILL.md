# 军训准备

- **归属域**：`F6` 军训与志愿（生活类）
- **来源**：自建
- **覆盖主体**：N 本科新生
- **定位**：军训前的身心与物资准备清单：体能预热、防晒防暑、物品清单与身体不适的处置原则（身体不适先报告教官）。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：军训体能预热、物品清单、防晒防暑、不适处置原则
- 不覆盖：伤病处置（→`F5`）；志愿时长（→`volunteer-hours`）；军训请假流程（→`F1`）

## 执行步骤

1. 评估距军训的天数与训练强度
2. 给 1 周体能预热计划（耐力 + 站姿）
3. 出物品清单（水、防晒、鞋垫、常用药）
4. 讲防晒防暑与补水节奏
5. 强调身体不适先报告教官，不硬撑

## 方法库 · 判定细则

| 类别 | 清单要点 |
|---|---|
| 补水 | 大容量水杯 + 淡盐水 |
| 防晒 | 高倍防晒 + 补涂节奏 |
| 足部 | 吸汗鞋垫 + 创可贴 |
| 防暑 | 藿香正气类（遵医嘱） + 避开正午暴晒 |

**判据**：任何身体不适 → 先报告教官；严重（中暑晕倒 / 骨折 / 意识不清）→ 先拨 120。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 下周就要军训了，我现在要做什么准备

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】一周体能预热 + 备齐补水防晒与足部用品。
【依据】军训准备：物品清单与防暑要点
【结果】① 每天慢跑 20 分钟 ② 练站姿 ③ 备水杯 / 防晒 / 鞋垫 / 创可贴
       → 产出：一周预热计划 + 物品清单
【下一步】先把物品清单备齐，体能计划从今晚开始
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 军训时中暑晕倒了该怎么办

**澄清判定**：涉严重伤病 → 依 `clarity.md` §5 例外 2 放行域锁定后按红线处置（120 优先）

**输出**

```
【结论】严重中暑属急症，先拨 120，其后再报告教官。
【依据】合规边界：严重伤病先拨 120（120 优先，不加延时动作）
【结果】① 立即拨 120 ② 移至阴凉处 ③ 等待时报告教官
【下一步】现在就记住 120 与校医院电话
```

## ⚠️ 红线（不得绕过）

- 军训期身体不适**不鼓励硬撑**，一律先报告教官
- **伤病 → 改锁 `F5`**；严重（中暑晕倒 / 骨折 / 意识不清）→ **先拨 120，其后再报告教官**（120 优先，不加延时动作）
- 志愿时长与第二课堂以学校系统为准，本包只做归档建议
