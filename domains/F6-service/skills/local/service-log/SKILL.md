# 军训与志愿记录

- **归属域**：`F6` 军训与志愿（生活类）
- **来源**：自建
- **定位**：军训期给体能/物资/防晒准备清单；志愿侧帮选项目并归档时长与收获。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：军训准备与适应、志愿服务与社会实践的项目选择与记录
- 不覆盖：不涉及学业（→S 类）；不涉及求职（→F8）

## 执行步骤

1. 军训：给物资清单、体能预热、防晒与中暑预防
2. 军训期作息按 sleep_window 提前 1 周调
3. 志愿：按兴趣与时长筛选项目类型
4. 记录服务时长与可迁移收获（写成 3 条经历条目）
5. 按记录模板归档为**本地记录表**（**不代登记**，志愿时长/第二课堂以学校系统为准）
6. 输出记录表

## 方法库 · 判定细则

**军训准备三件**：体能预热 + 物资清单 + 防暑节奏。

| 类别 | 要点 |
|---|---|
| 物资 | 水、防晒、鞋垫、创可贴 |
| 纪律 | 不适先报告教官 |

**志愿侧**：帮选项目并归档时长与收获，时长以学校系统为准。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 下周开始军训，要准备什么

**澄清判定**：对象/时间明确 → 不追问

**输出**

```
【结论】按「物资 + 体能 + 作息」三件事准备，重点防晒与补水。
【结果】① 物资：防晒霜(SPF50+)、大水壶、藿香正气、创可贴、厚袜
       ② 体能：军训前 3 天每天快走 30 分钟预热
       ③ 作息：按 sleep_window 提前 1 周调到 23:30 睡
       ④ 中暑信号：头晕/恶心/不出汗 → 立即报告教官并到阴凉处
       → 产出：checklist/军训准备.md
【下一步】今天先把物资清单买齐
【建议】身体不适**不硬撑**，及时报告
```

**澄清判定**：任务明确但属军训专项准备 → 依 `clarity.md` §5 例外 2 放行后改锁 `military-prep`

**输出**

```
[已降级] 由「军训与志愿记录」改为「军训准备」

【下一步】提交距军训天数，出一周预热与清单
```

## ⚠️ 红线（不得绕过）

- 军训期身体不适**不鼓励硬撑**，一律先报告教官
- **伤病 → 改锁 `F5`**；严重（中暑晕倒 / 骨折 / 意识不清）→ **先拨 120，其后再报告教官**（120 优先，不加延时动作）
- 志愿时长与第二课堂以学校系统为准，本包只做归档建议
