# 论证式演示

- **归属域**：`S5` 学术表达（学习类）
- **来源**：方法论思路参考 `Gabberflast/academic-pptx-skill`（实抓 frontmatter 标注专有许可证 → **零内容摘录**，以本项目语言全量重写 + DUT 特化）
- **定位**：管「讲什么、按什么顺序讲」的论证结构；不管视觉美化（模板与配色用学校 / 课程规定的模板）。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：课堂汇报 / 开题 / 答辩的逐页内容大纲、论证顺序、口头讲稿结构
- 不覆盖：论文正文结构 → `S3` `imrad-scaffold`；答辩问答演练 → `R4`；PPT 视觉设计 → 走 `library/general-fallback.md` §3 域通用框架

## 执行步骤

1. **定类型**：学术场合默认「论证式」（论点 → 证据 → 推理），只有面向非专业听众的科普场合才允许叙事式
2. **先出逐页大纲再动手**（≥10 页或内容复杂时必须先确认）：每页一行 `标题 | 论据类型 | 要点`，用户确认后才细化
3. **行动标题**：每页标题写成**完整的结论句**（如「实验组错误率下降 40%」），不写主题词（❌「实验结果」）
4. **幽灵测试**：把所有页的标题按顺序连读——必须不依赖正文就能讲通整个论证；讲不通就改大纲，禁止先做后改
5. **一页一论据**：每页只放一个图表 / 一个论点；在图上直接标出关键发现（别让听众自己找）
6. **页内纪律**：正文 ≤ 40 词 / 页；左对齐；结论页放最后且留在屏幕上（Q&A 期间评委看的必须是结论，不是「谢谢」）
7. **引用即纪律**：页内引用写进页脚，末页（或倒数第二页）放参考文献页——学术诚信延伸到幻灯片
8. 输出「逐页大纲（含行动标题）+ 幽灵测试通过声明」

## 方法库 · 判定细则

**论证结构四段**：问题 → 方法 → 结果 → 结论，每段 1 张主图。

| 单页原则 | 说明 |
|---|---|
| 一页一论点 | 标题即结论 |
| 证据可追溯 | 图注标来源 |

**边界**：只管讲什么、按什么顺序讲；视觉美化走学校 / 课程规定模板。

**DUT 特化**：论证结构对接 DUT 开题 / 中期 / 学位答辩与课程汇报的规定模板与时间限制，视觉模板一律沿用学校或课程指定样式，不另造配色。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 下周课堂要做一个 10 分钟的文献汇报，讲一篇大模型幻觉的综述

**澄清判定**：对象（文献汇报）、任务（演示结构）、时长（10 分钟）齐全 → 不追问

**输出**

```
【结论】10 分钟 ≈ 8–10 页论证链：问题→已知→缺口→综述框架→各主线→结论，标题全部写成结论句。
【依据】10 分钟约 8–10 页（1 页/分钟）；幽灵测试保证只读标题即可讲通
【结果】① 大纲：P1 幻觉是大模型落地的主要障碍 | P2 已有综述止于 2023 |
       P3 本综述按「检测-缓解」双线重组证据 | P4–7 各主线一页一结论 |
       P8 结论：评估基准不统一是当前最大缺口
       ② 幽灵测试：8 个标题连读成完整论证 → 通过后再做页
       ③ 纪律：每页 ≤40 词正文；关键发现在图上圈注
       → 产出：slides/outline.md（逐页行动标题 + 论据类型）
【下一步】确认大纲后逐页细化；讲稿另出（口头 1 页 1 分钟）
【建议】图表来自被综述论文，页脚标引用；汇报材料勿用未经授权的图
```
