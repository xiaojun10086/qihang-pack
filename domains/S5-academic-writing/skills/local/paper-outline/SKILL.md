# 论文骨架与预审

- **归属域**：`S5` 学术表达（学习类）
- **来源**：自建
- **定位**：给结构大纲 + 各节字数 + 论证链自查 + 3 条改进建议，再做一次「审稿人视角」预审。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：课程论文 / 综述 / 答辩展示的结构、引用规范、预审
- 不覆盖：不做文献检索管理（→R1）；不投稿（→R4）

## 执行步骤

1. 明确类型（课程论文 / 综述 / 报告）与字数
2. 出结构大纲并分配字数
3. 检查论证链：每节是否有主张 → 证据 → 推理
4. 跑一次模拟审稿（挑 3 个最可能被质疑的点）
5. 给引用格式规范（GB/T 7714 或 APA）
6. 输出文件落点

## 方法库 · 判定细则

**论证链自查**：主张 → 论据 → 反例 → 回应，四环不能断。

| 节 | 字数建议 |
|---|---|
| 引言 | 15% |
| 主体 | 60% |
| 结论 | 15% |

**预审视角**：以审稿人身份问「这个结论证据够不够」，标记证据薄弱处。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 写一篇 3000 字课程论文，题目《人工智能对教育的影响》

**澄清判定**：对象/产出/约束(字数)齐全 → 不追问

**输出**

```
【结论】走「现象—机制—证据—批判—展望」五段，已给字数分配。
【结果】① 引言 400（问题与争议）
       ② 机制 700（个性化/自动化/评估）
       ③ 证据 900（3 项实证研究）
       ④ 批判 700（公平性、教师角色、数据隐私）
       ⑤ 展望 300
       → 产出：paper/ai-in-education.md 大纲
【下一步】先补第 ③ 节的 3 项实证研究（我给了检索式）
【建议】最可能被质疑：把"个性化"当既成事实、缺少反例
```
