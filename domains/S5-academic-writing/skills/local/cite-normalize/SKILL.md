# 引用规范化

- **归属域**：`S5` 学术表达（学习类）
- **来源**：自建
- **定位**：把引文按 GB/T 7714 与目标期刊格式规范化，并给出逐条自查表，不伪造引文。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 0.30）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：引用格式转换、参考文献自查、格式一致性
- 不覆盖：不代写正文；未核验引文不得进终稿（→R1/R5）

## 执行步骤

1. 确认目标格式（GB/T 7714 或指定期刊/学位论文格式）
2. 逐条拆字段：作者 / 题名 / 文献类型 / 出处 / 年 / 卷期页 / DOI
3. 按格式模板重排，标出缺字段的条目
4. 检查顺序与正文引用标号是否一一对应
5. 输出规范化列表 + 缺失字段清单（不臆造补齐）

## 可执行示例

**输入**

> 参考文献现在格式乱七八糟，我要投的期刊要求 GB/T 7714

**澄清判定**：对象（参考文献）、约束（GB/T 7714）明确 → 放行

**输出**

```
【结论】能统一格式，但有 2 条缺卷期页，需要你去补。
【依据】引用规范化流程（库内 skill cite-normalize）
【步骤】① 按 GB/T 7714 重排 12 条
　　　　② 标缺字段：#4 缺卷期页、#9 缺 DOI
　　　　③ 正文标号与列表交叉核对，发现 1 处错位
【产物】cite/references-规范版.md · 待补字段.md
【下一步】先补齐 #4 的卷期页，回我
```
