# 学位论文格式自检

- **归属域**：`S5` 学术表达（学习类）
- **来源**：自建
- **覆盖主体**：G 毕业年级本科生 · M 硕士
- **定位**：按学校学位论文格式规范逐项自检：封面、页码、章节编号、图表题注与参考文献体例，只给检查清单不代排版正文。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：学位论文格式自检（结构 / 编号 / 图表题注 / 参考文献体例 / 摘要要素）
- 不覆盖：论文正文写作（见红线，只给结构）；引文真伪核验（→`R1` `citation-verify`）；答辩演练（→`R4`）

## 执行步骤

1. 取得本校《学位论文格式规定》与学院补充要求
2. 过结构自检表（封面 / 中英文摘要 / 目录 / 章节 / 致谢 / 附录）
3. 检查章节编号与图表题注的连续性
4. 检查参考文献体例（与 `cite-normalize` 联用）
5. 输出「不符项清单 + 定位到页 / 节」，不给改后的正文

## 方法库 · 判定细则

**格式自检表（高频扣分点）**：

| 部位 | 常见不符 |
|---|---|
| 封面 / 页眉 | 校名、日期、密级缺失 |
| 中英文摘要 | 关键词条数不符、英文摘要与中文不对应 |
| 章节编号 | 跳号、缺 2.1 直接到 2.2、图表跨节编号断 |
| 图表题注 | 图下表上位置错、单位缺失、来源未注 |
| 参考文献 | 体例混用（GB/T 7714 与 APA 混排） |

**不做**：代排版、代改正文 —— 只给「哪一页哪一处不符」。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我的硕士论文初稿排版老是不过，帮我自查格式

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】先按学院《格式规定》过 5 类高频扣分点，正文不动。
【依据】学位论文格式自检表
【结果】① 核封面与摘要要素 ② 查章节 / 图表编号连续性 ③ 统一参考文献体例
       → 产出：不符项清单（定位到页 / 节）
【下一步】按清单改完，把参考文献部分发我复核体例
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我写一下论文第三章的内容

**澄清判定**：命中红线（代写正文）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不代写正文；可给第三章的结构大纲与自查清单。
【依据】合规边界：不代写正文
【替代方案】提供章节骨架 + 字数分配
【下一步】把你的提纲发我，一起对齐结构
```

## ⚠️ 红线（不得绕过）

- **不代写正文** —— 只给结构大纲、字数分配与自查
- **不伪造参考文献**；未核验条目不得进终稿（→`R5`）
