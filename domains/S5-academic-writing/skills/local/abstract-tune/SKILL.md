# 摘要打磨

- **归属域**：`S5` 学术表达（学习类）
- **来源**：自建
- **覆盖主体**：M 硕士 · G 毕业年级本科生
- **定位**：按「背景—问题—方法—结果—意义」五要素诊断摘要的缺失与混叠，只做结构与信息完整度建议，不代写整段。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：摘要结构诊断与信息完整度检查、关键词选择建议
- 不覆盖：正文写作（见红线）；综述骨架（→`paper-outline`）；外文摘要润色（→`S6` `academic-english`）

## 执行步骤

1. 按五要素把现有摘要切成 5 块，标出缺失或混叠
2. 检查是否含具体结果（数字 / 结论）而非空泛表述
3. 检查是否混入了正文才该有的铺垫与引用
4. 检查关键词是否覆盖主题词与检索词
5. 给「逐句改写方向」，不整段代写

## 方法库 · 判定细则

**五要素判定细则**：

| 要素 | 缺失信号 | 合格标准 |
|---|---|---|
| 背景 | 上来就说方法 | 一句话说清领域缺口 |
| 问题 | 无明确研究问题 | 有可检验的问题句 |
| 方法 | 只说「进行了研究」 | 有具体方法名 / 数据量 |
| 结果 | 无数字、无结论 | 至少 1 个具体结果 |
| 意义 | 无或夸张 | 克制陈述贡献 |

**判据**：任一要素缺失 → 先补该要素，再谈语言精简。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我这篇论文的摘要导师说太啰嗦，帮我看看问题在哪

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】摘要缺「具体结果」要素，且背景写了 3 句偏多。
【依据】摘要五要素诊断：结果要素缺失
【结果】① 压缩背景为 1 句 ② 补 1 个具体结果（数字 / 结论）③ 关键词补主题词
       → 产出：逐句改写方向清单
【下一步】按方向改一版发我，复核五要素是否齐
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我写一个摘要出来

**澄清判定**：命中红线（代写正文）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不代写摘要正文；可给五要素骨架与自查清单。
【依据】合规边界：不代写正文
【替代方案】给出五要素填空骨架
【下一步】把你的摘要初稿发我，我逐要素标缺失
```
