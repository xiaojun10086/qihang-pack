# R6 · 信息搜集与输出

> 域 ID `R6` ｜ 所属大类 **科研类** ｜ 目录 `domains/R6-info-retrieval/`

## 域边界

- **覆盖**：校内网站**公开信息**的搜集与规范输出——导师 / 教师公开信息、部门与联系方式、通知公告、信息公开栏目、机构与场馆信息
- **不覆盖**：文献检索与管理 → `R1`（文献是学术数据库场景）；需登录的私密站内容（课表 / 成绩 / 一卡通）→ `F1` 按登录档位走；升学选导师的路径规划 → `F7`（本域只管「查资料」，`F7` 管「怎么选」）；找人 / 个人隐私挖掘不属于任何域（红线）

## 触发词（命中任一即锁定本域）

`导师信息` ｜ `老师是谁` ｜ `教师主页` ｜ `联系方式` ｜ `部门电话` ｜ `通知` ｜ `公告` ｜ `信息公开` ｜ `官网是什么` ｜ `查电话`

> 消歧：「导师」单字词面命中 `F7` 与本域——**查公开资料 → R6**；选导师 / 套磁规划 → `F7`。详见 `_registry.md` 触发词消歧。

## 库内 skill（唯一通道，无需安装）

- **`advisor-finder`** — 导师信息搜集（自建 · DUT 特化）
  从教师主页平台与研究生院公开信息中定位导师 / 教师的方向、院系与主页，输出核对过的信息卡。

- **`campus-search`** — 校内公开信息检索（自建 · DUT 特化）
  从 DUT 官方站点体系（信息公开 / 部门联系表 / 新闻 / 组织机构）检索公开信息，按引用规范输出。

- **`notice-track`** — 通知公告追踪（自建）
  帮用户把需要持续跟进的报名 / 考试 / 评奖节点整理成带来源与截止时间的追踪清单，只查公开通知不臆造。

- **`org-lookup`** — 机构场馆查询（自建）
  查校内机构职能、办事地点与场馆开放信息的公开入口，输出带来源与核验状态的查询结果，不臆造 URL / 电话。

## ⚠️ 红线（不得绕过）

- **只查公开信息**——任何尝试获取非公开个人信息（私人联系方式、家庭、行程）一律拒绝；个人隐私受法律保护
- **禁止编造 URL / 电话 / 姓名 / 职称**——`references/dlut-official-sites.md` 未收录的固定回复「信息库未收录，建议访问 https://www.dlut.edu.cn/ 核实」（硬规则 2）
- 涉及师生的负面舆情 / 争议信息不做「情报搜集」式的聚合输出——只提供官方来源原文入口
- 信息输出必须标注来源与核验状态；未经核验（⚠️）的信息不得当作事实输出
