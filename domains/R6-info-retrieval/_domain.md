# R6 · 学生公开信息搜集

> 域 ID `R6` ｜ **核心能力：学生信息搜集** ｜ 目录 `domains/R6-info-retrieval/`

## 域边界

- **覆盖**：学生需要的公开事实检索与整理，优先覆盖 DUT 校园信息、课程与考试公开资料、通知、机构、导师/教师主页；也可用于一般学习与校园议题的公开资料搜集。结果按主张附来源、日期和核验状态。
- **不覆盖**：学术论文与系统综述 → `R1`；需登录的私密站内容（课表 / 成绩 / 一卡通）→ `F1` 按登录档位走；升学选导师的路径规划 → `F7`（本域只查公开资料）；个人隐私挖掘、非公开信息与负面舆情聚合（红线）

## 触发词（命中任一即锁定本域）

`查资料` ｜ `找来源` ｜ `搜集信息` ｜ `比较信息` ｜ `学校信息` ｜ `课程资料` ｜ `导师信息` ｜ `老师是谁` ｜ `教师主页` ｜ `联系方式` ｜ `部门电话` ｜ `通知` ｜ `公告` ｜ `信息公开` ｜ `官网是什么` ｜ `查电话` ｜ `培养方案`

> 消歧：「导师」单字词面命中 `F7` 与本域——**查公开资料 → R6**；选导师 / 套磁规划 → `F7`。详见 `_registry.md` 触发词消歧。

## 库内 skill（唯一通道，无需安装）

- **`advisor-finder`** — 导师信息搜集（自建 · DUT 特化）
  从教师主页平台与研究生院公开信息中定位导师 / 教师的方向、院系与主页，输出核对过的信息卡。

- **`campus-search`** — 学生公开信息检索（自建 · DUT 优先）
  DUT 校情先查本地官方站点库；其他学习/校园主题使用可用的公开搜索工具核验，按来源质量、日期和证据输出。无搜索工具时提供入口或检索式，不声称已检索。

- **`notice-track`** — 通知公告追踪（自建）
  帮用户把需要持续跟进的报名 / 考试 / 评奖节点整理成带来源与截止时间的追踪清单，只查公开通知不臆造。

- **`org-lookup`** — 机构场馆查询（自建）
  查校内机构职能、办事地点与场馆开放信息的公开入口，输出带来源与核验状态的查询结果，不臆造 URL / 电话。

## 工具与来源

外部 skill 平台不是本域前置条件。需要实时资料时优先使用宿主提供的网页搜索工具，先查第一方/官方来源，再用独立可靠来源交叉核对关键事实。若工具不可用，明确说明限制并提供官方入口或可复制检索式。

## 执行顺序

0. **先判红线**（见下文 `## ⚠️ 红线` 节）—— 命中则**拒绝并给合规替代**（追问口径见 `library/clarity.md` §7）
1. 清晰、单一的问题直接处理；只有关键信息缺失会改变结果时，才参考 `library/clarity.md` 澄清。复杂任务再按需参照 `library/domain-review.md`。
2. 按具体任务择一：`advisor-finder`（导师资料）、`campus-search`（校园/一般公开资料）、`notice-track`（通知节点）、`org-lookup`（机构/场馆）。
3. 事实型输出逐项注明来源、发布日期或访问日期，并区分事实与建议；复杂结果可参考 `library/output-spec.md`。仅在用户要求保存偏好时才参考 `library/skill-evolution.md`，不得自动写入或修改资料。

## ⚠️ 红线（不得绕过）

- **只查公开信息**——任何尝试获取非公开个人信息（私人联系方式、家庭、行程）一律拒绝；个人隐私受法律保护
- **禁止编造 URL / 电话 / 姓名 / 职称**——`references/dlut-official-sites.md` 未收录的固定回复「信息库未收录，建议访问 https://www.dlut.edu.cn/ 核实」（硬规则 2）
- 涉及师生的负面舆情 / 争议信息不做「情报搜集」式的聚合输出——只提供官方来源原文入口
- 信息输出必须标注来源与核验状态；未经核验（⚠️）的信息不得当作事实输出

## 失败与降级

机构与场馆类请求超出 `campus-search` 的一般入口时，可改用同域 `org-lookup`；其他请求找不到可靠来源时，明确说明未核实并给出搜索入口，不转到无关 skill，也不虚构结果。
