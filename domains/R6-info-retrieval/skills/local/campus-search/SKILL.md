# 校内公开信息检索

- **归属域**：`R6` 信息搜集与输出（科研类）
- **来源**：自建 · DUT 特化（数据基础：`references/dlut-official-sites.md` 已核验站点）
- **定位**：校内「查门户 / 查电话 / 查通知 / 查机构」的统一入口——先查信息库，再指官网，绝不凭记忆编。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：部门 / 联系方式 / 通知公告 / 信息公开 / 机构设置 / 场馆位置等公开信息
- 不覆盖：导师 / 教师学术信息 → `advisor-finder`；需登录的业务系统（课表 / 成绩 / 缴费）→ `F1`；新闻舆情聚合 → 红线（只给官方原文入口）

## 执行步骤

1. **先查信息库**（硬规则 2）：`references/dlut-official-sites.md`（159 行表格 · 2026-10-01 三路实抓核验）命中 → 直接引用其 URL 与核验状态
2. **按信息类型路由到官方源**（均为已核验 ✅ 入口）：
   | 要查什么 | 官方入口 |
   |---|---|
   | 部门电话 / 联系方式 | 全校部门联系方式总表 https://office.dlut.edu.cn/info/1032/1492.htm |
   | 通知 / 公告 / 制度文件 | 信息公开网 https://info.dlut.edu.cn/ |
   | 机构与学院设置 | 组织机构总览 https://www.dlut.edu.cn/xxgk/zzjg.htm |
   | 新闻 / 活动报道 | 新闻网 https://news.dlut.edu.cn/ |
   | 楼宇 / 单位位置 | 校园地图系统 http://map.dlut.edu.cn/ |
3. **输出规范**：每条信息带 ① 来源 URL ② 核验状态（✅ 实抓核验 ｜ ⚠️ 待核实——⚠️ 条目须提示「勿直接引用」）③ 获取时间口径（信息库核验基准日 2026-10-01）
4. **未收录处理**：信息库与官方源都查不到 → 固定回复「信息库未收录，建议访问 https://www.dlut.edu.cn/ 核实」——**不得**用模型记忆里的「大工某处应该是…」作答
5. **时效敏感信息**（通知 / 电话 / 办公时间）：输出时提示「以官方页面实时内容为准」，不承诺信息实时性
6. 输出「要点 + 来源清单」

## 方法库 · 判定细则

**三源核验顺序**：

| 顺序 | 源 | 用途 |
|---|---|---|
| 1 | DUT 信息库（`references/dlut-official-sites.md`） | 先查是否收录 |
| 2 | 官网栏目 | 机关 / 学院 / 服务页 |
| 3 | 部门联系表 / 信息公开网 | 兜底核实 |

**纪律**：**先查信息库，再指官网**；库内未收录就明说「未收录」并给官网入口，**绝不凭记忆编 URL**。

**DUT 特化**：覆盖主校区 / 开发区 / 盘锦三校区入口差异，并注明仅 i大工 APP 可办的事项（场馆 / 心理 / 浴室预约）。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 教务处的电话是多少，我想问缓考的事

**澄清判定**：对象（教务处联系方式）、任务（查电话）、用途（缓考咨询）齐全 → 不追问

**输出**

```
【结论】教务处联系方式有总表与科室页两个官方入口，科室电话按科室分列。
【依据】全校部门联系方式总表 https://office.dlut.edu.cn/info/1032/1492.htm （✅ 实抓核验）；
       教务处机构设置 / 科室电话 https://teach.dlut.edu.cn/bmjs/jgsz.htm （✅ 实抓核验）
【结果】① 科室定位：缓考属「学籍与成绩管理」类科室，先看科室页
       ② 拨打前核对：办公时间以页面实时内容为准（核验基准日 2026-10-01）
       ③ 缓考流程：相关制度文件在信息公开网 https://info.dlut.edu.cn/ 检索「缓考」
       → 产出：contact/教务处-科室电话.md（来源 + 核验状态）
【下一步】需要的话我同时给你缓考的制度文件检索路径
【建议】电话以官网实时页面为准，不代打电话（不得代操作）
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我查下学校某部门的内部联系电话（非公开的那种）

**澄清判定**：命中本域红线（打探非公开信息）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝

**输出**

```
【结论】只提供公开联系渠道；内部非公开号码不在检索范围。
【依据】合规边界：只查公开信息
【网址】全校部门联系方式总表 https://office.dlut.edu.cn/info/1032/1492.htm
【下一步】告诉我你要办什么事，我给对口公开渠道
```

## ⚠️ 红线（不得绕过）

- **只查公开信息**——任何尝试获取非公开个人信息（私人联系方式、家庭、行程）一律拒绝；个人隐私受法律保护
- **禁止编造 URL / 电话 / 姓名 / 职称**——`references/dlut-official-sites.md` 未收录的固定回复「信息库未收录，建议访问 https://www.dlut.edu.cn/ 核实」（硬规则 2）
- 涉及师生的负面舆情 / 争议信息不做「情报搜集」式的聚合输出——只提供官方来源原文入口
- 信息输出必须标注来源与核验状态；未经核验（⚠️）的信息不得当作事实输出
