# 导师信息搜集

- **归属域**：`R6` 信息搜集与输出（科研类）
- **来源**：自建 · DUT 特化（数据基础：`references/dlut-official-sites.md` 已核验站点）
- **定位**：把「这个老师是谁、做什么方向、怎么联系」变成一张可核验的信息卡——每个字段都标来源。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域（选导师策略 / 套磁规划 → 改锁 `F7`）

## 边界

- 覆盖：导师 / 教师的公开学术信息（院系、职称、研究方向、公开主页、公开联系方式）
- 不覆盖：选导师与升学规划 → `F7`；私人信息（家庭、行程、私人电话）→ 红线拒绝；文献检索 → `R1`

## 执行步骤

1. **锁定检索目标**：明确要查的是「某位具体教师」还是「某方向 / 某学院的教师群体」（群体查询先给检索路径，不逐个罗列）
2. **按序查公开源**（只用 `references/dlut-official-sites.md` 已核验 ✅ 的入口）：
   ① **教师主页平台** https://faculty.dlut.edu.cn/ ——教师自建主页，方向、成果、联系方式最全
   ② **研究生院** https://gs.dlut.edu.cn/ ——研究生导师信息与招生相关公开栏目
   ③ **学部学院导航** https://www.dlut.edu.cn/xbxy.htm ——到具体学院官网查「师资队伍」页
3. **信息卡字段**：姓名 ｜ 院系 ｜ 职称（若公开）｜ 研究方向 ｜ 主页链接 ｜ 公开联系方式（若有）｜ 来源与核验状态
4. **核验纪律**：
   - 每个字段标来源 URL；多个来源冲突时并列呈现，不擅自裁决
   - 未在上述来源找到的字段标「未在公开源找到」——**不留空、不猜、不补**
   - 信息库未收录的站点 → 固定回复「信息库未收录，建议访问 https://www.dlut.edu.cn/ 核实」
5. **群体查询模式**：按方向找导师 → 给「学院师资页 + 教师主页平台的检索入口 + 该学院已知的方向关键词」，由用户自行浏览筛选
6. 输出「信息卡（标注来源与核验状态）」

## 方法库 · 判定细则

**导师信息核验分级**：

| 来源 | 可信度 | 用途 |
|---|---|---|
| 教师主页平台 | 高 | 方向 / 成果 / 联系方式 |
| 学院官网 | 高 | 招生方向 / 团队 |
| 研究生院招生栏目 | 高 | 招生名额 / 流程 |
| 论坛 / 二手转述 | 低 | 仅供参考，须回源核验 |

**纪律**：只查**公开可核验**信息，逐项标来源与核验状态；不臆造联系方式、不代联系导师。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 帮我查一下计算机学院做视觉方向的老师有哪些，我想找导师

**澄清判定**：对象（计算机学院视觉方向教师）、任务（搜集公开信息）、产出（信息卡/检索路径）齐全 → 不追问

**输出**

```
【结论】教师主页平台 + 计算机学院师资页双路检索，输出核对过的教师清单与信息卡。
【依据】DUT 公开信息源：教师主页平台 https://faculty.dlut.edu.cn/ （✅ 已核验）；
       学院导航 https://www.dlut.edu.cn/xbxy.htm （✅）→ 计算机科学与技术学院官网
【结果】① 学院师资页：按「计算机视觉 / 图像 / 模式识别」关键词筛方向
       ② 教师主页平台：逐位核对其自建主页（成果与联系方式以主页为准）
       ③ 信息卡：姓名｜院系｜职称｜方向｜主页｜公开联系方式｜来源
       ④ 冲突处理：学院页与教师主页不一致时并列呈现
       → 产出：advisors/计算机-视觉方向.md（信息卡清单，逐条标来源）
【下一步】选中 3–5 位后做选导师策略与套磁时间线
【建议】只输出公开信息；私人联系方式与行程不搜集（合规要求）
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 你能帮我联系导师、问问有没有内定名额吗

**澄清判定**：命中本域红线（代联系 / 打探非公开信息）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝

**输出**

```
【结论】不代联系、不探非公开名额；可给公开信息与联系礼节模板。
【依据】合规边界：只查公开信息，不代联系
【替代方案】给导师公开信息卡 + 首次联系邮件模板
【下一步】把目标方向 / 学院发我，我整理公开信息卡
```

## ⚠️ 红线（不得绕过）

- **只查公开信息**——任何尝试获取非公开个人信息（私人联系方式、家庭、行程）一律拒绝；个人隐私受法律保护
- **禁止编造 URL / 电话 / 姓名 / 职称**——`references/dlut-official-sites.md` 未收录的固定回复「信息库未收录，建议访问 https://www.dlut.edu.cn/ 核实」（硬规则 2）
- 涉及师生的负面舆情 / 争议信息不做「情报搜集」式的聚合输出——只提供官方来源原文入口
- 信息输出必须标注来源与核验状态；未经核验（⚠️）的信息不得当作事实输出
