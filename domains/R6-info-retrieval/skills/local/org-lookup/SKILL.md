# 机构场馆查询

- **归属域**：`R6` 信息搜集与输出（科研类）
- **来源**：自建
- **覆盖主体**：全体学生
- **定位**：查校内机构职能、办事地点与场馆开放信息的公开入口，输出带来源与核验状态的查询结果，不臆造 URL / 电话。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：机构职能与办事地点、场馆 / 服务开放信息、部门联系方式（公开）
- 不覆盖：非公开个人信息（见红线）；臆造 URL / 电话（见红线）；办事流程（→`F1`）

## 执行步骤

1. 明确要查的机构 / 场馆与目标信息
2. 在公开站（信息公开网 / 组织机构总览 / 学部学院导航）定位
3. 输出职能 / 地点 / 公开联系方式，标注来源与核验状态
4. 未收录项固定回复「信息库未收录」给核实入口
5. 需登录信息提示走 F1 登录档位

## 方法库 · 判定细则

**公开信息查询路径**：

| 要查 | 首选入口 |
|---|---|
| 部门职能 / 电话 | 信息公开网 · 部门联系方式总表 |
| 学院的谁负责 | 学部学院导航 → 学院官网 |
| 场馆开放 | 场馆中心 / 图书馆官网 |

**判据**：信息库未收录 → 固定回复「信息库未收录」+ 给核实入口，**不臆造**。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我想找一个部门的办公地点和公开电话

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】从信息公开网与部门联系方式总表查，输出带来源与核验状态。
【依据】机构场馆查询：公开信息查询路径
【结果】① 定要查的部门 ② 查总表入口 ③ 记职能 / 地点 / 公开电话 ④ 标核验状态
       → 产出：查询结果（含来源）
【下一步】把部门全称发我，帮你定位公开入口
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我查某个同学的联系方式

**澄清判定**：命中红线（获取非公开个人信息）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不查询 / 获取他人非公开联系方式；只提供公开信息的查询入口。
【依据】合规边界：只查公开信息
【替代方案】公开的部门 / 机构联系方式查询
【下一步】如需联系同学，建议经辅导员转达
```

## ⚠️ 红线（不得绕过）

- **只查公开信息**——任何尝试获取非公开个人信息（私人联系方式、家庭、行程）一律拒绝；个人隐私受法律保护
- **禁止编造 URL / 电话 / 姓名 / 职称**——`references/dlut-official-sites.md` 未收录的固定回复「信息库未收录，建议访问 https://www.dlut.edu.cn/ 核实」（硬规则 2）
- 涉及师生的负面舆情 / 争议信息不做「情报搜集」式的聚合输出——只提供官方来源原文入口
- 信息输出必须标注来源与核验状态；未经核验（⚠️）的信息不得当作事实输出
