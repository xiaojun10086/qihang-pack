# 求职竞赛工具箱

- **归属域**：`F8` 求职与竞赛（生活类）
- **来源**：自建
- **定位**：按目标岗位/竞赛倒推能力缺口，改简历只做「相关性重构」，面试按 STAR 打磨。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：简历、面试、实习求职、学科竞赛与创新创业项目
- 不覆盖：不做升学规划（→F7）

## 执行步骤

1. 明确目标（岗位 / 竞赛 / 项目）
2. 倒推能力缺口，给 2–3 条补齐动作
3. 简历：只做相关性重构与量化改写，不编造经历
4. 面试：按 STAR 打磨 3 个高频问题
5. 竞赛：查 DUT 创新创业学院与学院通知的报名节点
6. 输出行动清单

## 方法库 · 判定细则

**倒推能力缺口**：目标岗位 → 能力要求 → 现有差距 → 补齐动作。

| 模块 | 只做什么 |
|---|---|
| 简历 | 相关性重构 |
| 面试 | STAR 打磨 |
| 竞赛 | 选型与里程碑 |

**纪律**：只做选择与重排，不创造经历。

**示例 1（正常命中）**

**输入**

> 想参加大创，不知道从哪下手

**澄清判定**：对象=大创、任务=入门 → 不追问

【结论】先找导师与题目，再组队报名，别先想商业计划。

【下一步】本周约 1 位老师聊 15 分钟（邮件模板已给）

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我把简历里的实习经历写得更长更厉害

**澄清判定**：命中红线（编造经历）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不编造 / 不夸大经历；只做相关性重构。
【依据】合规边界：不编造经历 / 学历 / 获奖
【替代方案】针对性重排与措辞优化
【下一步】做岗位定制
```

## ⚠️ 红线（不得绕过）

- **不编造经历、学历、获奖、实习、时间线** —— 只做「相关性重构」
- 面试不教「圆谎」；简历只保留可被追问到底的内容
- 商业计划书与作品集同样**只给结构，不代写**
