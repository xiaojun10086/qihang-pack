# 竞赛选型

- **归属域**：`F8` 求职与竞赛（生活类）
- **来源**：自建
- **定位**：按专业、投入产出与时间窗筛选竞赛清单并排备赛里程碑，不编造获奖。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 0.30）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：竞赛筛选、备赛里程碑、投入产出评估
- 不覆盖：不编造获奖与经历；商业计划书只给结构（→红线）

## 执行步骤

1. 确认专业、可投入周数、目标（保研加分 / 简历 / 兴趣）
2. 按三条硬筛：报名时间窗未过、与专业相关、有可复用产出
3. 给 3 个梯度选项（稳 / 冲 / 长线）
4. 对首选排备赛里程碑（组队 / 选题 / 迭代 / 提交）
5. 标出「会占用期末」的风险周

## 可执行示例

**输入**

> 想参加竞赛给保研加分，不知道选哪个

**澄清判定**：对象（竞赛）、任务（怎么选）明确 → 放行；目标默认保研加分

**输出**

```
【结论】优先数学建模（期内报名）与程序设计赛（与专业相关）。
【依据】竞赛选型三硬筛（库内 skill competition-pick）
【步骤】① 本周确认数模报名截止日
　　　　② 组 3 人队：1 建模 + 1 编程 + 1 写作
　　　　③ 赛前 2 周各练 1 套真题
【产物】career/竞赛清单与里程碑.md
【下一步】今天查数模报名截止日，确认还没过
```

## ⚠️ 红线（不得绕过）

- **不编造经历、学历、获奖、实习、时间线** —— 只做「相关性重构」
- 面试不教「圆谎」；简历只保留可被追问到底的内容
- 商业计划书与作品集同样**只给结构，不代写**
