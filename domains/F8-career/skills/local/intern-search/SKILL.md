# 实习搜寻

- **归属域**：`F8` 求职与竞赛（生活类）
- **来源**：自建
- **覆盖主体**：G 毕业年级本科生 · U 在读本科
- **定位**：梳理实习搜寻渠道、时间线与投递策略，做岗位-能力匹配自查，不代投递、不推荐具体公司。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：实习渠道梳理、秋招 / 暑期时间线、岗位匹配自查、投递节奏
- 不覆盖：代投递（见红线）；推荐具体公司（见红线）；简历定制（→`resume-tailor`）

## 执行步骤

1. 明确目标岗位方向与可实习时间段
2. 列渠道（就业网 / 官网 / 内推 / 实习平台）
3. 排时间线（暑期实习通常提前 3–6 个月）
4. 做岗位-能力匹配自查，列差距项
5. 给投递节奏与记录表模板

## 方法库 · 判定细则

| 渠道 | 特点 | 提前期 |
|---|---|---|
| 就业信息网 | 校招主力 | 提前 1–3 月 |
| 企业官网 | 信息最准 | 提前 3–6 月 |
| 内推 | 转化高 | 随时 |
| 实习平台 | 量多需甄别 | 随时 |

**判据**：投递前先做一次「岗位 JD 关键词 vs 我的经历」匹配表，命中 < 50% 的先补能力。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 大三想找暑期实习，什么时候开始投

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】暑期实习提前 3–6 个月投，先做岗位匹配再排投递表。
【依据】实习搜寻：渠道 × 时间线
【结果】① 定方向 ② 列渠道 ③ 排时间线 ④ 做匹配自查
       → 产出：投递时间表 + 匹配自查表
【下一步】把目标岗位的 JD 发我，帮你做匹配自查
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我投 20 家公司吧

**澄清判定**：命中红线（代投递）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不代投递；可给你投递清单与节奏表。
【依据】合规边界：不代操作系统 / 不编造时间线
【替代方案】渠道清单 + 投递记录表
【下一步】按清单自己投，把投递记录发我一起复盘
```

## ⚠️ 红线（不得绕过）

- **不编造经历、学历、获奖、实习、时间线** —— 只做「相关性重构」
- 面试不教「圆谎」；简历只保留可被追问到底的内容
- 商业计划书与作品集同样**只给结构，不代写**
