# 讲义转笔记

- **归属域**：`S2` 课堂与笔记（学习类）
- **来源**：摘录+自建
- **定位**：把讲义/录音/PPT 按用户要求整理成可复习笔记；默认覆盖材料中的重要知识，不把摘要当成完整笔记。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：课堂材料 → 结构化笔记 / 概念图 / 知识库沉淀
- 不覆盖：不做题目讲解（→S1）；不写实验报告（→S3）

## 执行步骤

1. 收集并标记每份材料的来源名、章节、页码或时间戳；多份来源先分别识别，不把来源不明的内容拼成事实。
2. 确定粒度：明确要求摘要/速记时提炼核心结论；未要求压缩或要求完整时，按材料章节整理全部重要定义、结论、公式、推导、代表例题和老师强调的考点。
3. 跨来源互补处合并表达，观点冲突处并列标明来源与分歧；保留必要页码、时间戳和来源名。
4. 生成概念图（层级：章 → 节 → 关键概念），保留推导关系和前置概念；根据用户需求加入自测题，默认不以题目数量替代知识覆盖。
5. 标注未理解点和待核验项；推断与原文事实分开标记。
6. 建立材料章节/页码到笔记小节的覆盖核对；长材料按完整章节或主题分批，每批注明范围和未处理部分。仅在用户明确要求保存时写入学习档案，并给出可用的笔记交付方式。

## 方法库 · 判定细则

**粒度口径**：摘要笔记才压缩为 5–8 条核心；完整笔记按原材料章节覆盖重要内容。两者均须保留来源线索，且不得将少量摘要标成完整笔记。

| 保留 | 丢弃 |
|---|---|
| 定义、结论、公式 | 语气词、重复举例 |
| 老师强调的考点 | 跑题的闲谈 |
| 章节 / 页码 / 时间戳与来源名 | 无法核实的补充背景 |

**未理解点**：凡听不懂处一律标出，供下次复考 —— 不猜测、不补全。

**多来源纪律**：按主题综合而非按来源堆叠；每个关键知识点保留来源线索。来源间冲突时并列呈现，不擅自调和。长材料可先按现成章节或主题分段处理，但不依赖联网抓取、并行代理或后台日志。详尽笔记应核对来源范围与笔记小节覆盖；不能因输出长度而隐去关键推导、条件或例题，单轮放不下时按完整主题分批并说明边界。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 把这份《数学分析》第一章的讲义整理成笔记（附 PDF），并把未理解点保存到学习档案

**澄清判定**：对象=讲义、产出=笔记，无需追问

**输出**

```
【结论】已按「核心结论 + 概念图 + 自测题」三段整理，共 7 条核心。
【依据】讲义 PDF 第 1–18 页；
【结果】① 抽 7 条核心结论（附页码）
       ② 生成概念图：实数系 → 确界 → 极限定义
       ③ 出 3 道自测题
       → 产出：notes/数学分析-第1章.md（含概念图 Mermaid 块）
【下一步】先做自测题第 1 题，答完我判
【建议】按你的要求，已保存「确界原理的证明」为复习薄弱点
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 把这段录音原原本本转写成文字就行

**澄清判定**：任务明确但属格式归一而非压缩转笔记 → 依 `clarity.md` §5 例外 2 放行后改锁 `note-normalize`

**输出**

```
[已降级] 由「讲义转笔记」改为「笔记归一」
【结论】这属于「笔记归一」类需求，已改按该方式处理。
【下一步】提交录音转写文本，走统一结构整理
```
