# 讲义转笔记

- **归属域**：`S2` 课堂与笔记（学习类）
- **来源**：摘录+自建
- **定位**：把讲义/录音/PPT 压成「5–8 条核心 + 概念图 + 3 个自测题」，并标注未理解点供下次复考。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 5%）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：课堂材料 → 结构化笔记 / 概念图 / 知识库沉淀
- 不覆盖：不做题目讲解（→S1）；不写实验报告（→S3）

## 执行步骤

1. 判断材料类型（讲义 / 录音 / 视频 / 板书照片）
2. 抽取 5–8 条核心结论（带出处页码或时间戳）
3. 生成概念图（层级：章 → 节 → 关键概念）
4. 生成 3 个可自测问题（覆盖最高频考点）
5. 标注 1–2 处未理解点，写入学习档案
6. 给出笔记文件落点

## 输出

按 `library/output-spec.md` 模板输出，默认 ≤ 6 条要点。
