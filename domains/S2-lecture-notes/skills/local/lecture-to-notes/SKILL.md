# 讲义转笔记

- **归属域**：`S2` 课堂与笔记（学习类）
- **来源**：摘录+自建
- **定位**：把讲义/录音/PPT 压成「5–8 条核心 + 概念图 + 3 个自测题」，并标注未理解点供下次复考。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：课堂材料 → 结构化笔记 / 概念图 / 知识库沉淀
- 不覆盖：不做题目讲解（→S1）；不写实验报告（→S3）

## 执行步骤

1. 判断材料类型（讲义 / 录音 / 视频 / 板书照片）
2. 抽取 5–8 条核心结论（带出处页码或时间戳）
3. 生成概念图（层级：章 → 节 → 关键概念）
4. 生成 3 个可自测问题（覆盖最高频考点）
5. 标注 1–2 处未理解点，写入学习档案
6. 给出笔记文件落点

## 方法库 · 判定细则

**压缩口径**：原始材料 → 5–8 条核心 + 1 张概念图 + 3 道自测题。

| 保留 | 丢弃 |
|---|---|
| 定义、结论、公式 | 语气词、重复举例 |
| 老师强调的考点 | 跑题的闲谈 |

**未理解点**：凡听不懂处一律标出，供下次复考 —— 不猜测、不补全。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 把这份《数学分析》第一章的讲义整理成笔记（附 PDF）

**澄清判定**：对象=讲义、产出=笔记，无需追问

**输出**

```
【结论】已按「核心结论 + 概念图 + 自测题」三段整理，共 7 条核心。
【依据】讲义 PDF 第 1–18 页；
【结果】① 抽 7 条核心结论（附页码）
       ② 生成概念图：实数系 → 确界 → 极限定义
       ③ 出 3 道自测题
       → 产出：notes/数学分析-第1章.md（含概念图 Mermaid 块）
【下一步】先做自测题第 1 题，答完我判
【建议】"确界原理的证明"已记入学习档案，下次复考
```
