# 双链笔记法

- **归属域**：`S2` 课堂与笔记（学习类）
- **来源**：改造自 `kepano/obsidian-skills`（MIT）· 骨架提取重写 + DUT 特化
- **定位**：把零散笔记变成互相连接的知识网——每个概念是一个节点，链接是边，复习时顺着链接走而不是翻文件夹。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：笔记的组织结构设计（链接 / 标签 / 嵌入 / 索引页）、Obsidian 风味 Markdown 语法指导、知识网络构建
- 不覆盖：录音 / 讲义转笔记 → `lecture-to-notes`；已有笔记的格式归一 → `note-normalize`；文献管理 → `R1`

## 执行步骤

1. **建节点命名规范**：一概念一页，文件名 = 概念名（如「极限的定义.md」），不加日期前缀——链接要指向稳定的概念，不是指向某天
2. **三类链接规则**：
   - 双链 `[[概念]]` 指向库内其他概念页（自动跟踪重命名）
   - `[[概念#小节]]` 指向某页的具体小节
   - 外部 URL 才用普通 Markdown 链接（如 DUT 课程平台页面）
3. **标签层级**：`#课程/高数` `#课程/大物` 一级按课程，`#类型/概念` `#类型/错题` `#类型/易混点` 二级按性质——标签管检索，链接管关系，不混用
4. **嵌入引用**：错题页用 `![[原概念]]` 嵌入被考的概念页，复习错题时不用跳转
5. **索引页（MOC）**：每门课建一张「课程地图」页，用链接列出该课全部概念页并按章节组织——新笔记先在地图上找挂点，找不到再开新页
6. **连接仪式**：每次记完新笔记，强制问「这和哪些旧概念有关？」并补 ≥ 1 个双链——没有链接的新页是孤儿页，等于白记
7. 输出「本页链接清单 + 建议挂载点」

## 方法库 · 判定细则

**建链两原则**：

| 原则 | 说明 |
|---|---|
| 概念即节点 | 一个概念一个文件 |
| 链接即关系 | 关联 / 派生 / 对立 三类边 |

**复习路径**：从一个节点出发，沿「关联」边向外走 —— 覆盖度比翻文件夹高。

**DUT 特化**：节点与标签结构对接 DUT 课程教学大纲的章节—知识点层级，双链命名与课程名 / 章节号一致，复习时可按课程与教师授课顺序回溯，直接对齐期中期末考核范围。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 高数笔记记得乱七八糟，想搞成那种点一下就能跳转的知识网

**澄清判定**：对象（高数笔记）、任务（建知识网）、产出（双链结构方案）齐全 → 不追问

**输出**

```
【结论】按「概念页 + 课程地图」建网，先补 5 个核心概念页并互链，再谈扩充。
【依据】网状链接比文件夹检索的复习路径更贴合知识本身的结构（概念间本就互相引用）
【结果】① 命名：「极限的定义.md」「导数的定义.md」…一概念一页
       ② 链接：导数页里 [[极限的定义]]（导数由极限定义）；错题页 ![[导数的定义]] 嵌入
       ③ 标签：#课程/高数 + #类型/概念｜#类型/错题
       ④ 地图：建「高数地图.md」，按章节挂全部概念页
       ⑤ 仪式：每页至少 1 个双链，孤儿页警告
       → 产出：notes/高数地图.md + 首批 5 个概念页（含链接骨架）
【下一步】把你现有的目录发我，我来标出哪些能直接拆成概念页
【建议】笔记自用合规范；若用于提交的作业须改锁 并遵守其合规边界
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**澄清判定**：任务明确但属讲义转笔记 → 依 `clarity.md` §5 例外 2 放行后改锁 `lecture-to-notes`

【下一步】提交讲义或录音，走压缩转笔记
