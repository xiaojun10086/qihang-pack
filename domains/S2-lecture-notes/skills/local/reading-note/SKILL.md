# 精读笔记

- **归属域**：`S2` 课堂与笔记（学习类）
- **来源**：自建
- **覆盖主体**：M 硕士（科研入门，读论文 / 专著）
- **定位**：对论文或专著做段落级精读笔记，用「主张—证据—疑点」三色标记形成可回溯的阅读记录，面向科研入门的研究生。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：论文 / 专著精读笔记、论证结构拆解、疑点与待查记录
- 不覆盖：课堂讲义转笔记（→`lecture-to-notes`）；笔记格式归一（→`note-normalize`）；双链互连（→`link-notes`）

## 执行步骤

1. 先读摘要与结论，写下这篇文献的主张
2. 逐段三色标记：主张（蓝）/ 证据（绿）/ 疑点（红）
3. 抽出论证链：主张 ← 证据 ← 方法
4. 记下 2–3 个可追问的疑点和要查的引文
5. 用自己的话写 3 句摘要

## 方法库 · 判定细则

**三色标记细则**：

| 颜色 | 标记对象 | 判定信号 |
|---|---|---|
| 蓝（主张） | 作者要你相信的结论 | 「we argue / 本文认为」 |
| 绿（证据） | 支撑主张的数据 / 实验 / 引用 | 出现图表、数字、引文编号 |
| 红（疑点） | 你不同意 / 没看懂 / 想查证处 | 样本小、缺对照、结论外推 |

**自用原则**：本域只做自用笔记；若要用于提交，须改锁 `S3`。

