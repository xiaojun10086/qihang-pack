# 笔记归一

- **归属域**：`S2` 课堂与笔记（学习类）
- **来源**：自建
- **定位**：把散乱笔记、讲义、录音转写整成「章节-概念-例题-待补」统一结构，不做讲解。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：多源材料归一、结构统一、待补章节标注
- 不覆盖：不做题目讲解（→S1）；产出若用于提交须改锁 S3

## 执行步骤

1. 收集全部来源（手写笔记 / 讲义 / PPT / 录音转写）
2. 按讲次或章节对齐时间轴，标出各来源的覆盖与空洞
3. 统一成四段结构：章节 → 概念 → 例题 → 待补
4. 对同一概念的多份表述，保留最完整的一份并标注来源
5. 输出「待补章节清单」，供下次上课重点听

## 方法库 · 判定细则

**统一结构四层**：章节 → 概念 → 例题 → 待补。

| 原始形态 | 归一到 |
|---|---|
| 零散便签 | 挂到「概念」层 |
| 拍照板书 | 转写成「概念 + 例题」 |
| 语音转写 | 按章节切段 |

**纪律**：只做结构整理，不做讲解、不做补全 —— 缺的地方标「待补」。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 我录了课、也拍了板书，还有学长给的笔记，能整到一起吗？

**澄清判定**：对象由**具体材料清单枚举**（录音 / 板书 / 学长笔记），类别明确、范围可唯一收窄 → `c_O=0.8`（依 `library/clarity.md` §2.1）；产出（整到一起）明确 → 关键槽 `O/T/D` 齐全 → 依 §5 例外 2 **放行**；自用用途，不触发 S3

**输出**

```
【结论】能合，按 4 段结构归一，缺的是第 5 章的例题。
【依据】笔记归一流程（库内 skill note-normalize）
【步骤】① 以板书讲次为骨架对齐 3 份来源
　　　　② 概念以讲义为准，补充录音里的口述例子
　　　　③ 生成待补清单：第 5 章例题缺失
【产物】notes/归一笔记.md · 待补清单.md
【下一步】下次课只记第 5 章例题，回来补齐
```
