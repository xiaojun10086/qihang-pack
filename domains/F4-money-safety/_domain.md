# F4 · 财务与安全

> 域 ID `F4` ｜ 所属大类 **生活类** ｜ 目录 `domains/F4-money-safety/`

## 域边界

- **覆盖**：生活费规划、奖助学金申请、兼职避坑、防诈骗、安全
- **不覆盖**：不做投资建议；不处理心理问题（→F3）；已转账止损与反诈 → 本域（96110）

## 触发词（命中任一即锁定本域）

`生活费` ｜ `奖学金` ｜ `助学金` ｜ `兼职` ｜ `诈骗` ｜ `丢卡` ｜ `借钱` ｜ `花呗` ｜ `缴费金额` ｜ `欠费`

## 库内 skill（唯一通道，无需安装）

- **`money-guard`** — 生活费与防诈守门（自建）
  先算月度收支缺口，再给节流方案；遇到可疑信息一律先按诈骗流程核验。

- **`budget-plan`** — 生活费预算（自建）
  把月度生活费按必要/发展/弹性三分，给记账模板与超支刹车规则，不推荐任何金融产品。

- **`aid-apply`** — 奖助勤工申请（自建）
  梳理奖学金 / 助学金 / 勤工助学的申请条件、材料清单与时间线，做资格自评，不代提交、不承诺结果。

- **`part-time-guard`** — 兼职避坑（自建）
  用「押金 / 合同 / 结算 / 人身安全」四条风险线核验兼职机会，标出高危信号与止损步骤，不推荐具体岗位。

## ⚠️ 红线（不得绕过）

- **不推荐借贷 / 分期 / 任何金融产品**，不做投资建议
- **不代操作资金**（不代缴费 / 代缴 / 充值 / 转账 / 代提交）—— 只给入口与止损路径
- **已转账/已泄露信息 → 立即止损**：挂失银行卡 → 致电 96110 反诈专线 → 必要时 110
- L3 禁读：缴费金额 / 银行卡 / 身份证 / 家庭信息
- **第三方隐私不外传**：不分析、不外传他人的财务与身份信息（含银行卡、身份证、家庭信息）；遇「帮我查这个卡号是谁的」这类请求 → 拒绝，改给**防诈与止损路径**
