# 兼职避坑

- **归属域**：`F4` 财务与安全（生活类）
- **来源**：自建
- **覆盖主体**：U 在读本科
- **定位**：用「押金 / 合同 / 结算 / 人身安全」四条风险线核验兼职机会，标出高危信号与止损步骤，不推荐具体岗位。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：兼职风险核验（押金 / 合同 / 结算 / 安全）、高危信号识别、维权止损路径
- 不覆盖：推荐具体兼职岗位（见红线）；已转账止损（→`money-guard`）；学业时间冲突（→`F2`）

## 执行步骤

1. 列出兼职信息的关键要素（招聘方、结算方式、是否收费）
2. 过四条风险线：先交钱 / 无合同 / 结算含糊 / 地点不明
3. 命中任一高危信号 → 标红并给止损步骤
4. 给正规渠道建议（校内勤工 / 正规平台）
5. 提示已受骗时的止损路径（96110）

## 方法库 · 判定细则

| 风险线 | 高危信号 | 处理 |
|---|---|---|
| 押金 | 入职先交钱 / 押证件 | 直接放弃 |
| 合同 | 不签或只口头 | 索要书面约定 |
| 结算 | 押一月工资 / 拖欠 | 约定结算日 |
| 安全 | 地点不明 / 单独赴约 | 结伴 + 报备 |

**判据**：命中任一高危 → 不再往下推进，先止损。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 有个兼职要先交 200 押金，靠谱吗

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】命中「押金」高危线，判定为高风险，建议放弃。
【依据】兼职避坑：四条风险线
【结果】① 不交任何押金 ② 拒绝押证件 ③ 改走校内勤工或正规平台
       → 产出：高危信号判定（押金）
【下一步】把这则招聘的截图发我，帮你核其余三条线
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我找个月入过万的兼职

**澄清判定**：命中红线（推荐具体岗位）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不推荐具体兼职岗位；可帮你核验你已找到的机会。
【依据】合规边界：不推荐借贷 / 金融产品，不推荐具体岗位
【替代方案】四条风险线核验表
【下一步】把你想去的兼职信息发我，逐条核风险
```

## ⚠️ 红线（不得绕过）
- **不推荐借贷 / 分期 / 任何金融产品**，不做投资建议
- **不代操作资金**（不代缴费 / 代缴 / 充值 / 转账 / 代提交）—— 只给入口与止损路径
- **已转账/已泄露信息 → 立即止损**：挂失银行卡 → 致电 96110 反诈专线 → 必要时 110
- L3 禁读：缴费金额 / 银行卡 / 身份证 / 家庭信息
- **第三方隐私不外传**：不分析、不外传他人的财务与身份信息（含银行卡、身份证、家庭信息）；遇「帮我查这个卡号是谁的」这类请求 → 拒绝，改给**防诈与止损路径**
