# 生活费与防诈守门

- **归属域**：`F4` 财务与安全（生活类）
- **来源**：自建
- **定位**：先算月度收支缺口，再给节流方案；遇到可疑信息一律先按诈骗流程核验。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：生活费规划、奖助学金申请、兼职避坑、防诈骗、安全
- 不覆盖：不做投资建议；不处理心理问题（→F3）

## 执行步骤

1. 算月度收入（生活费+奖助）与固定支出
2. 定位缺口或结余，给 1 条节流建议（只 1 条）
3. 奖助学金：查条件 → 备材料 → 记 DDL
4. 遇可疑信息：不点链接、不转账、不透露验证码 → 报保卫处
5. 丢卡/丢证：先挂失（一卡通 + 银行卡）再补办
6. 输出行动卡

## 方法库 · 判定细则

**防诈三步**：停（不转钱）→ 核（官方渠道核实）→ 报（96110 / 110）。

| 已发生 | 动作 |
|---|---|
| 刚转账 | 挂失银行卡 → 96110 |
| 已泄露信息 | 改密 + 报警 |

**纪律**：不推荐借贷 / 分期 / 金融产品；不代操作资金。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 这个月生活费还有 10 天就没了

**澄清判定**：缺「剩余金额」→ 追问 1 问；不问也能给通用方案

**输出**

```
【结论】先把剩下的钱锁定日均额度，再砍非必要支出。
【结果】① 算缺口：剩余金额 ÷ 10 = 日均上限（含餐费）
       ② 本周只做 1 条节流：先砍外卖，改食堂
       ③ 应急资源：学生资助（学生处 https://xsc.dlut.edu.cn/ ）
       ④ 警惕：**不碰任何"校园贷/兼职刷单"**
【网址】财务处 http://cw.dlut.edu.cn/ ｜ 资助办 84708317
【状态】✅ 已核验
【下一步】告我剩余金额，我给出日均额度
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我交一下这学期的学费

**澄清判定**：命中红线（代操作资金）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不代缴费；可给缴费入口与流程。
【依据】合规边界：不代操作资金（不代缴费 / 转账）
【替代方案】统一支付入口 + 缴费流程
【下一步】在官方入口与流程获取
```

## ⚠️ 红线（不得绕过）
- **不推荐借贷 / 分期 / 任何金融产品**，不做投资建议
- **不代操作资金**（不代缴费 / 代缴 / 充值 / 转账 / 代提交）—— 只给入口与止损路径
- **已转账/已泄露信息 → 立即止损**：挂失银行卡 → 致电 96110 反诈专线 → 必要时 110
- L3 禁读：缴费金额 / 银行卡 / 身份证 / 家庭信息
- **第三方隐私不外传**：不分析、不外传他人的财务与身份信息（含银行卡、身份证、家庭信息）；遇「帮我查这个卡号是谁的」这类请求 → 拒绝，改给**防诈与止损路径**
