# 奖助勤工申请

- **归属域**：`F4` 财务与安全（生活类）
- **来源**：自建
- **覆盖主体**：U 在读本科
- **定位**：梳理奖学金 / 助学金 / 勤工助学的申请条件、材料清单与时间线，做资格自评，不代提交、不承诺结果。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：奖助勤工条件核对、材料清单、时间线与资格自评
- 不覆盖：代提交申请（见红线）；借贷 / 分期咨询（见红线）；日常预算（→`budget-plan`）

## 执行步骤

1. 明确目标项目（国家奖助 / 校级 / 社会资助 / 勤工岗）
2. 列出该项目申请条件，逐条做资格自评
3. 整理所需材料清单与开具地点
4. 排出截止时间线与提醒点
5. 输出自评表 + 材料清单，提交由本人完成

## 方法库 · 判定细则

| 项目类型 | 关键条件 | 常见材料 |
|---|---|---|
| 奖学金 | 成绩 / 综合测评排名 | 成绩单 + 获奖证明 |
| 助学金 | 家庭经济困难认定 | 认定表 + 佐证 |
| 勤工助学 | 岗位申请 + 课表匹配 | 申请表 + 课表 |

**判据**：资格自评只做「是否满足条件」，不预测评审结果。

**输入**

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行


**示例 2（边界 / 失败例 —— 不该命中的情形）**

## ⚠️ 红线（不得绕过）
- **不推荐借贷 / 分期 / 任何金融产品**，不做投资建议
- **不代操作资金**（不代缴费 / 代缴 / 充值 / 转账 / 代提交）—— 只给入口与止损路径
- **已转账/已泄露信息 → 立即止损**：挂失银行卡 → 致电 96110 反诈专线 → 必要时 110
- L3 禁读：缴费金额 / 银行卡 / 身份证 / 家庭信息
- **第三方隐私不外传**：不分析、不外传他人的财务与身份信息（含银行卡、身份证、家庭信息）；遇「帮我查这个卡号是谁的」这类请求 → 拒绝，改给**防诈与止损路径**
