# 生活费预算

- **归属域**：`F4` 财务与安全（生活类）
- **来源**：自建
- **定位**：把月度生活费按必要/发展/弹性三分，给记账模板与超支刹车规则，不推荐任何金融产品。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：月度预算、记账模板、超支刹车
- 不覆盖：不推荐借贷/分期/投资（→红线）；金额明细属 L3 禁读

## 执行步骤

1. 先算固定收入（生活费到账日与金额，用户自述，不读站内金额）
2. 按 60/20/20 分：必要 / 发展 / 弹性
3. 给 4 类记账科目（吃 / 行 / 学 / 乐）与每日上限
4. 设刹车规则：单科目超 80% 即停非必要支出
5. 给「月末复盘三问」

## 方法库 · 判定细则

**三分类**：必要 / 发展 / 弹性 = 6 : 2 : 2。

| 类别 | 例 |
|---|---|
| 必要 | 餐饮、交通、话费 |
| 发展 | 书籍、课程 |
| 弹性 | 娱乐、社交 |

**刹车规则**：弹性超支 → 从下月弹性扣，不动必要项。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 每个月钱都不够花，不知道花哪儿了

**澄清判定**：对象（生活费）、产出（预算）明确 → 放行；不追问具体金额（避免触碰敏感）

**输出**

```
【结论】先按 60/20/20 分，把"吃"定上限，超 80% 就停外卖。
【依据】预算三分法
【结果】① 必要 60%：吃 + 行 + 通讯
　　　　② 发展 20%：书、课、工具
　　　　③ 弹性 20%：娱乐与社交
　　　　→ 产出：money/月度预算表.csv · 记账模板.md
【下一步】今天先记 3 天的账，回我超支的那一项
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

## ⚠️ 红线（不得绕过）
- **不推荐借贷 / 分期 / 任何金融产品**，不做投资建议
- **不代操作资金**（不代缴费 / 代缴 / 充值 / 转账 / 代提交）—— 只给入口与止损路径
- **已转账/已泄露信息 → 立即止损**：挂失银行卡 → 致电 96110 反诈专线 → 必要时 110
- L3 禁读：缴费金额 / 银行卡 / 身份证 / 家庭信息
- **第三方隐私不外传**：不分析、不外传他人的财务与身份信息（含银行卡、身份证、家庭信息）；遇「帮我查这个卡号是谁的」这类请求 → 拒绝，改给**防诈与止损路径**
