# F3 · 身心与社交

> 域 ID `F3` ｜ 所属大类 **生活类** ｜ 目录 `domains/F3-wellbeing/`

## 域边界

- **覆盖**：情绪压力疏导、适应问题、宿舍与人际、社团选择
- **不覆盖**：**不做心理诊断、不做危机干预**；出现自伤/自杀念头立即转介专业资源

## 库内 skill（优先使用，无需安装）

- **`wellbeing-checkin`** — 状态check-in（自建）
  先倾听再给方法；不评判、不诊断；识别危机信号并第一时间转介心理中心。

## 执行顺序

0. **先判红线**（见下文 `## ⚠️ 红线` 节）—— 命中则**拒绝并给合规替代**，**不追问**
1. 1 级库完成**需求明确**（`library/clarity.md`），U ≤ 0.30 才继续
2. 1 级库完成**域审查**，确认命中 `F3`（`library/domain-review.md`）
3. 用**库内 skill**（首选 `wellbeing-checkin`；不满足时用同域备选 `peer-talk-script`）执行
4. 库内不满足 → 读 `skills/external.md` 走库外安装
5. 按 `library/output-spec.md` 输出，**并明确不写入任何记忆层**（见 `library/memory.md` 红线）

## ⚠️ 红线（不得绕过）

- **不做心理诊断**，不使用临床术语下结论
- **危机信号**（自伤/自杀念头、持续失眠、情绪失控）→ **立即转介并停止其他一切建议**，并给 **24h 可用通道**：**全国心理援助热线 12356** / 北京 010-82951332
- **若已有具体计划（备药、选定地点、写告别留言）→ 立即拨打 110 或 120**，不得只给非 24h 的校内资源
- **本域内容不写入任何记忆层**，会话结束即丢弃
- 不评判纠纷中的任何一方，不替用户出面沟通

## 澄清与追问口径（v2.9 新增）

> 本节是**执行口径**，不是红线条目 —— 不参与「库内 skill 红线逐条一致」比对。

- **「已有具体计划」的判据（v2.9 明确）**：出现「**时间 / 地点 / 手段 / 告别留言**」**任一项**即视为「已有具体计划」
  → **立即 110 / 120**，不得只给非 24h 的校内资源。
- **非危机情绪类仍走澄清门（v2.9 明确）**：F3 的普通情绪请求**不得豁免澄清门**；
  但追问必须**先共情再提问**、**≤2 问**，且**不得**问「你是不是想自杀」这类诱导性筛查
  （那属于专业评估，超出本包能力边界）。
