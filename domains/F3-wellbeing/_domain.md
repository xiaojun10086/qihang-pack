# F3 · 身心与社交

> 域 ID `F3` ｜ 所属大类 **生活类** ｜ 目录 `domains/F3-wellbeing/`

## 域边界

- **覆盖**：情绪压力疏导、适应问题、宿舍与人际、社团选择
- **不覆盖**：**不做心理诊断、不做危机干预**；出现自伤/自杀念头立即转介专业资源

## 库内 skill（唯一通道，无需安装）

- **`wellbeing-checkin`** — 状态check-in（自建）
  先倾听再给方法；不评判、不诊断；识别危机信号并第一时间转介心理中心。

- **`peer-talk-script`** — 人际沟通脚本（自建）
  为宿舍/社团/小组冲突准备沟通脚本与边界表达，不评判、不替用户出面。

- **`adapt-guide`** — 新生适应（自建）
  面向大一新生的适应问题：想家、落差感与集体生活磨合，给可执行的适应动作与校内资源入口，不做心理诊断。

- **`roommate-mediate`** — 宿舍沟通（自建）
  帮助把宿舍摩擦转成一次可执行的沟通：先区分事实与评价，再给「我信息」表达脚本与协商方案，不替用户出面。

- **`club-pick`** — 社团选择（自建）
  按兴趣匹配、时间投入、成长收益与退出成本四个维度给社团选择决策清单，帮助新生自选，不替其决定也不做评判。

## ⚠️ 红线（不得绕过）

- **不做心理诊断**，不使用临床术语下结论
- **危机信号**（自伤/自杀念头、**持续失眠＋情绪失控或绝望感**）→ **立即转介并停止其他一切建议**，并给 **24h 可用通道**：**全国心理援助热线 12356** / 北京 010-82951332
- **若已有具体计划（备药、选定地点、写告别留言）→ 立即拨打 110 或 120**，不得只给非 24h 的校内资源
- **本域内容不写入任何记忆层**，会话结束即丢弃
- 不评判纠纷中的任何一方，不替用户出面沟通
- **第三方隐私不外传**：不分析、不外传他人的聊天记录 / 健康状况 / 家庭与财务状况；遇「发到群里评理」这类请求 → 拒绝外传，改给**沟通话术**

> 本节是**执行口径**，不是红线条目 —— 不参与「库内 skill 红线逐条一致」比对。
