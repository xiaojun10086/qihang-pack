# 新生适应

- **归属域**：`F3` 身心与社交（生活类）
- **来源**：自建
- **覆盖主体**：N 本科新生
- **定位**：面向大一新生的适应问题：想家、落差感与集体生活磨合，给可执行的适应动作与校内资源入口，不做心理诊断。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：新生适应（想家 / 落差 / 集体生活）、校内支持资源入口、适应期节奏建议
- 不覆盖：心理诊断（见红线）；危机干预（走危机红线）；宿舍具体矛盾（→`roommate-mediate`）

## 执行步骤

1. 先确认无危机信号（有则立即走红线转介）
2. 让用户说出最难受的 1 件事，归入想家 / 落差 / 磨合三类
3. 给该类的一条可执行适应动作（如固定联系家人时段）
4. 给校内支持资源入口（咨询中心 / 辅导员 / 社团）
5. 约定一周后回访式自评

## 方法库 · 判定细则

| 类型 | 典型表达 | 适应动作 |
|---|---|---|
| 想家 | 「晚上老想回家」 | 固定每天一个联系家人的时段 |
| 落差 | 「同学都好厉害」 | 把比较对象换成「上周的自己」 |
| 磨合 | 「宿舍作息不一样」 | 先约定一条共同规则 |

**判据**：先确认无危机信号，再谈适应 —— 顺序不可反。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 刚来学校两周，特别想家，晚上老睡不着

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】属「想家」类适应问题，先固定联系家人的时段，再用规律作息托底。
【依据】新生适应：三类对策
【结果】① 每天定一个联系家人时段 ② 睡前例行程序 ③ 加入 1 个兴趣社团
       → 产出：一周适应动作清单
【下一步】先执行 3 天，把睡眠与情绪变化发我复盘
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 我不想活了，撑不下去

**澄清判定**：命中危机信号 → 依 `clarity.md` §5 例外 2 放行域锁定后按红线立即转介

**输出**

```
【结论】立即启动危机转介，停止其他一切建议。
【依据】合规边界：危机信号 → 立即转介并给 24h 通道
【建议】全国心理援助热线 12356；已备具体计划 → 拨 110 / 120
【下一步】现在就拨打 12356，或联系辅导员陪你
```

## ⚠️ 红线（不得绕过）
- **不做心理诊断**，不使用临床术语下结论
- **危机信号**（自伤/自杀念头、**持续失眠＋情绪失控或绝望感**）→ **立即转介并停止其他一切建议**，并给 **24h 可用通道**：**全国心理援助热线 12356** / 北京 010-82951332
- **若已有具体计划（备药、选定地点、写告别留言）→ 立即拨打 110 或 120**，不得只给非 24h 的校内资源
- **本域内容不写入任何记忆层**，会话结束即丢弃
- 不评判纠纷中的任何一方，不替用户出面沟通
- **第三方隐私不外传**：不分析、不外传他人的聊天记录 / 健康状况 / 家庭与财务状况；遇「发到群里评理」这类请求 → 拒绝外传，改给**沟通话术**
