# 人际沟通脚本

- **归属域**：`F3` 身心与社交（生活类）
- **来源**：自建
- **定位**：为宿舍/社团/小组冲突准备沟通脚本与边界表达，不评判、不替用户出面。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：沟通脚本、边界表达、冲突降温
- 不覆盖：不做心理诊断、不替用户出面；危机信号立即转介（→红线）

## 执行步骤

1. 先把事实与感受分开写（各 3 条，不加评价词）
2. 明确本次沟通只解决"1 个具体行为"
3. 用「我句式」拟一段 ≤5 句的开场白
4. 预备 2 个对方可能的反应与对应回应
5. 约定止损线：谈不下去就先撤，改约时间

## 方法库 · 判定细则

**沟通脚本三段**：事实陈述 → 我的感受 → 具体请求。

| 禁用语 | 替换 |
|---|---|
| 你总是… | 当…发生时 |
| 你怎么这样 | 我感到… |

**判定顺序**：先判有没有危机信号（有则停止拟稿、立即转介）→ 再判用户要的是「自己怎么开口」还是「替我出面」（后者只给脚本，不出面）→ 最后才按三段拟稿。

**高频误判**

- ❌ 把「快崩了 / 撑不住」当情绪修辞继续拟脚本 → ✅ 先过危机信号，判不准就问一句，不要直接往下走。
- ❌ 把「你替我去谈」当成可以变通的请求 → ✅ 只交付脚本，出面沟通由用户自己完成。
- ❌ 脚本里留下「你总是 / 你从不」这类评价词 → ✅ 先做事实与评价分离，再落笔。
- ❌ 一次想清算多笔旧账 → ✅ 本次沟通只锁定一个具体行为。
- ❌ 替用户判断谁对谁错 → ✅ 不评判纠纷中任何一方，只调脚本措辞。

**边界**：不评判、不替用户出面，只给脚本。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 室友天天打游戏到两点，我不好意思说，快崩了

**澄清判定**：对象（室友作息）、任务（怎么说）明确 → 放行；无危机信号，不转介

**输出**

```
【结论】只说"1 件事"：晚上 12 点后戴耳机。用我句式，别翻旧账。
【依据】沟通脚本四步
【结果】① 先写事实：连续 5 天 2 点后仍有键盘声
　　　　② 开场白：我最近睡眠差，想和你商量个事…
　　　　③ 预备回应：若说"我控制不了"→ 提议戴耳机即可
　　　　→ 产出：talk/室友沟通脚本.md
【下一步】今晚找个两人都在的时段，照着开场白说一次
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 你替我去找他谈吧

**澄清判定**：命中红线（替用户出面）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**为什么这样判**：「你替我去」把沟通主体换成了我，越过了本 skill 的边界；脚本是可交付物，出面不是。

**输出**

```
【结论】不替你出面；把脚本给你，由你来谈。
【依据】合规边界：不替用户出面沟通
【结果】只交付可照读的脚本，出面沟通由你自己完成 —— 代出面一律只降级不代劳。
【替代方案】可直接用的沟通脚本
【下一步】打磨针对宿舍场景的脚本
```

## ⚠️ 红线（不得绕过）
- **不做心理诊断**，不使用临床术语下结论
- **危机信号**（自伤/自杀念头、**持续失眠＋情绪失控或绝望感**）→ **立即转介并停止其他一切建议**，并给 **24h 可用通道**：**全国心理援助热线 12356** / 北京 010-82951332
- **若已有具体计划（备药、选定地点、写告别留言）→ 立即拨打 110 或 120**，不得只给非 24h 的校内资源
- **本域内容不写入任何记忆层**，会话结束即丢弃
- 不评判纠纷中的任何一方，不替用户出面沟通
- **第三方隐私不外传**：不分析、不外传他人的聊天记录 / 健康状况 / 家庭与财务状况；遇「发到群里评理」这类请求 → 拒绝外传，改给**沟通话术**
