# 人际沟通脚本

- **归属域**：`F3` 身心与社交（生活类）
- **来源**：自建
- **定位**：为宿舍/社团/小组冲突准备沟通脚本与边界表达，不评判、不替用户出面。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 0.30）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：沟通脚本、边界表达、冲突降温
- 不覆盖：不做心理诊断、不替用户出面；危机信号立即转介（→红线）

## 执行步骤

1. 先把事实与感受分开写（各 3 条，不加评价词）
2. 明确本次沟通只解决"1 个具体行为"
3. 用「我句式」拟一段 ≤5 句的开场白
4. 预备 2 个对方可能的反应与对应回应
5. 约定止损线：谈不下去就先撤，改约时间

## 可执行示例

**输入**

> 室友天天打游戏到两点，我不好意思说，快崩了

**澄清判定**：对象（室友作息）、任务（怎么说）明确 → 放行；无危机信号，不转介

**输出**

```
【结论】只说"1 件事"：晚上 12 点后戴耳机。用我句式，别翻旧账。
【依据】沟通脚本四步（库内 skill peer-talk-script）
【步骤】① 先写事实：连续 5 天 2 点后仍有键盘声
　　　　② 开场白：我最近睡眠差，想和你商量个事…
　　　　③ 预备回应：若说"我控制不了"→ 提议戴耳机即可
【产物】talk/室友沟通脚本.md
【下一步】今晚找个两人都在的时段，照着开场白说一次
```

- **不做心理诊断**，不使用临床术语下结论
- **危机信号**（自伤/自杀念头、持续失眠、情绪失控）→ **立即转介并停止其他一切建议**，并给 **24h 可用通道**：**全国心理援助热线 12356** / 北京 010-82951332

- **本域内容不写入任何记忆层**，会话结束即丢弃
- 不评判纠纷中的任何一方，不替用户出面沟通
