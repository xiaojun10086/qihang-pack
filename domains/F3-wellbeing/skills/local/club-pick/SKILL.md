# 社团选择

- **归属域**：`F3` 身心与社交（生活类）
- **来源**：自建
- **覆盖主体**：N 本科新生
- **定位**：按兴趣匹配、时间投入、成长收益与退出成本四个维度给社团选择决策清单，帮助新生自选，不替其决定也不做评判。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：社团 / 学生组织的选择决策清单、时间预算、退出成本评估
- 不覆盖：心理诊断；活动策划（→`F6` `service-log`）；评判优劣或替用户决定（见红线，不评判）

## 执行步骤

1. 列出可考虑的 3–5 个社团 / 组织
2. 按兴趣匹配、每周时间投入、成长收益、退出成本打分
3. 检查与课业时间的冲突
4. 给「先试一个月再决定」的试错建议
5. 输出决策维度表，由用户自选

## 方法库 · 判定细则

| 维度 | 打分口径（1–5） |
|---|---|
| 兴趣匹配 | 不做也会自己去做的事 |
| 时间投入 | 每周固定小时数 |
| 成长收益 | 可迁移技能 |
| 退出成本 | 中途退出是否尴尬 / 违约 |

**判据**：加权后若两选项差距 < 10% → 直接选「可试错成本低」的那个。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 大一进来社团招新，我该选哪个好

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】按四维度打分自选，不替你做决定。
【依据】社团选择：四维度评分口径
【结果】① 列 3–5 个候选 ② 四维打分 ③ 查课业冲突 ④ 先试一个月
       → 产出：决策维度打分表
【下一步】把你的候选社团填进去打分，拿结果来一起看
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 你觉得学生会和辩论队哪个更好

**澄清判定**：关键槽 `O/T/D` 齐全但要求做评判 → 依 `clarity.md` §5 例外 2 放行域锁定后按红线只给维度不评判

**输出**

```
【结论】不做「哪个更好」的评判；只给决策维度让你自选。
【依据】合规边界：不评判、不替用户决定
【替代方案】四维度打分表
【下一步】按你自己的权重给两个候选打分
```

## ⚠️ 红线（不得绕过）
- **不做心理诊断**，不使用临床术语下结论
- **危机信号**（自伤/自杀念头、**持续失眠＋情绪失控或绝望感**）→ **立即转介并停止其他一切建议**，并给 **24h 可用通道**：**全国心理援助热线 12356** / 北京 010-82951332
- **若已有具体计划（备药、选定地点、写告别留言）→ 立即拨打 110 或 120**，不得只给非 24h 的校内资源
- **本域内容不写入任何记忆层**，会话结束即丢弃
- 不评判纠纷中的任何一方，不替用户出面沟通
- **第三方隐私不外传**：不分析、不外传他人的聊天记录 / 健康状况 / 家庭与财务状况；遇「发到群里评理」这类请求 → 拒绝外传，改给**沟通话术**
