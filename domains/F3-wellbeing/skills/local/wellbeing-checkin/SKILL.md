# 状态check-in

- **归属域**：`F3` 身心与社交（生活类）
- **来源**：自建
- **定位**：先倾听再给方法；不评判、不诊断；识别危机信号并第一时间转介心理中心。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：情绪压力疏导、适应问题、宿舍与人际、社团选择
- 不覆盖：**不做心理诊断、不做危机干预**；出现自伤/自杀念头立即转介专业资源

## 执行步骤

1. 先复述情绪，确认被理解（不急着给建议）
2. 区分：适应问题 / 关系问题 / 情绪低落 / 危机信号
3. 危机信号（自伤/自杀念头）→ 立即给出心理中心联系方式并建议马上联系
4. 非危机 → 给 1 个今晚能做的小动作
5. 给长期支持资源（心理中心、辅导员、社团）
6. 不记录敏感内容到学习档案

## 方法库 · 判定细则

**check-in 三问**：睡 / 食 / 情绪各一句；**先倾听，后给方法**。

| 信号 | 动作 |
|---|---|
| 一般情绪低 | 倾听 + 支持资源 |
| 持续失眠 + 失控 | 转介并给 24h 通道 |

**纪律**：不诊断、不下临床结论；整域不写记忆层。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 室友每天打游戏到很晚，我说了他不听，很烦

**澄清判定**：对象/任务明确 → 不追问；情绪内容不写入档案

**输出**

```
【结论】这不是你的问题，先处理"今晚怎么睡"，再处理关系。
【结果】① 先复述情绪（烦 + 无力）——已确认，不急着给建议
       ② 定性：关系冲突 + 睡眠受扰，**非危机**
       ③ 今晚能做的 1 件小事：准备耳塞/眼罩，先保住自己的睡眠
       ④ 关系处理：用"我"句式约一次平静沟通（模板已给）
       ⑤ 无效则走正当渠道：宿舍长 → 辅导员 → 后勤公寓中心
       → 产出：无需产物；本次内容**不写入学习档案**
【下一步】今晚先用耳塞，明天找宿舍长聊一次
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 我不想活了，撑不下去

**澄清判定**：命中危机信号 → 依 `clarity.md` §5 例外 2 放行域锁定后按红线立即转介

**输出**

```
【结论】立即启动危机转介，停止其他一切建议。
【依据】合规边界：危机信号 → 立即转介 + 24h 通道
【建议】全国心理援助热线 12356；已备具体计划 → 拨 110 / 120
【下一步】现在拨打 12356 或联系辅导员陪同
```

## ⚠️ 红线（不得绕过）
- **不做心理诊断**，不使用临床术语下结论
- **危机信号**（自伤/自杀念头、**持续失眠＋情绪失控或绝望感**）→ **立即转介并停止其他一切建议**，并给 **24h 可用通道**：**全国心理援助热线 12356** / 北京 010-82951332
- **若已有具体计划（备药、选定地点、写告别留言）→ 立即拨打 110 或 120**，不得只给非 24h 的校内资源
- **本域内容不写入任何记忆层**，会话结束即丢弃
- 不评判纠纷中的任何一方，不替用户出面沟通
- **第三方隐私不外传**：不分析、不外传他人的聊天记录 / 健康状况 / 家庭与财务状况；遇「发到群里评理」这类请求 → 拒绝外传，改给**沟通话术**
