# 状态check-in

- **归属域**：`F3` 身心与社交（生活类）
- **来源**：自建
- **定位**：先倾听再给方法；不评判、不诊断；识别危机信号并第一时间转介心理中心。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 5%）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：情绪压力疏导、适应问题、宿舍与人际、社团选择
- 不覆盖：**不做心理诊断、不做危机干预**；出现自伤/自杀念头立即转介专业资源

## 执行步骤

1. 先复述情绪，确认被理解（不急着给建议）
2. 区分：适应问题 / 关系问题 / 情绪低落 / 危机信号
3. 危机信号（自伤/自杀念头）→ 立即给出心理中心联系方式并建议马上联系
4. 非危机 → 给 1 个今晚能做的小动作
5. 给长期支持资源（心理中心、辅导员、社团）
6. 不记录敏感内容到学习档案

## 输出

按 `library/output-spec.md` 模板输出，默认 ≤ 6 条要点。
