# AI使用声明

- **归属域**：`R5` 学术规范与伦理（科研类）
- **来源**：自建
- **定位**：生成合规的 AI 使用声明（工具名/使用环节/本人核验范围），不隐藏 AI 痕迹。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门，U ≤ 0.30）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：AI 使用声明、使用环节梳理、核验范围声明
- 不覆盖：不隐藏 AI 使用痕迹；不代改以规避查重（→红线）

## 执行步骤

1. 梳理实际使用环节（检索 / 提纲 / 翻译 / 润色 / 代码 / 数据处理）
2. 逐环节记录工具名与用途
3. 写「本人核验范围」：哪些结论由本人复核、哪些数据由本人重跑
4. 对照学校/期刊要求补齐必要字段
5. 给一句声明落点建议（方法节或致谢）

## 可执行示例

**输入**

> 论文用了 AI 改语法，学校要写 AI 使用声明，怎么写？

**澄清判定**：对象（AI 声明）、任务（怎么写）明确 → 放行；声明合规

**输出**

```
【结论】按"工具 / 环节 / 核验"三段写，落点在方法节末尾。
【依据】AI 使用声明模板（库内 skill ai-disclosure）
【步骤】① 工具：列出所用模型与版本
　　　　② 环节：仅"语言润色"，不含内容生成
　　　　③ 核验：全部结论与数据由本人复核
【产物】submit/ai-disclosure.md
【下一步】先确认学校模板是否要求写明版本号，再定稿
```
