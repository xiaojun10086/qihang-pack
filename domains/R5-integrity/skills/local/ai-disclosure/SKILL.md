# AI使用声明

- **归属域**：`R5` 学术规范与伦理（科研类）
- **来源**：自建
- **定位**：生成合规的 AI 使用声明（工具名/使用环节/本人核验范围），不隐藏 AI 痕迹。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：AI 使用声明、使用环节梳理、核验范围声明
- 不覆盖：不隐藏 AI 使用痕迹；不代改以规避查重（→红线）

## 执行步骤

1. 梳理实际使用环节（检索 / 提纲 / 翻译 / 润色 / 代码 / 数据处理）
2. 逐环节记录工具名与用途
3. 写「本人核验范围」：哪些结论由本人复核、哪些数据由本人重跑
4. 对照学校/期刊要求补齐必要字段
5. 给一句声明落点建议（方法节或致谢）

## 方法库 · 判定细则

**AI 使用声明要素**：

| 要素 | 必填 | 写法 |
|---|---|---|
| 工具名 | 是 | 写具体产品名与版本 |
| 使用环节 | 是 | 构思 / 语言润色 / 代码调试 |
| 本人核验范围 | 是 | 哪些内容经本人复核 |
| 未使用范围 | 建议 | 数据 / 结论未经 AI 生成 |

**纪律**：**如实、完整、可追溯**；不得把 AI 生成内容冒充为本人原创，也不得隐瞒使用环节。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 论文用了 AI 改语法，学校要写 AI 使用声明，怎么写？

**澄清判定**：对象（AI 声明）、任务（怎么写）明确 → 放行；声明合规

**输出**

```
【结论】按"工具 / 环节 / 核验"三段写，落点在方法节末尾。
【依据】AI 使用声明模板
【结果】① 工具：列出所用模型与版本
　　　　② 环节：仅"语言润色"，不含内容生成
　　　　③ 核验：全部结论与数据由本人复核
　　　　→ 产出：submit/ai-disclosure.md
【下一步】先确认学校模板是否要求写明版本号，再定稿
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

> 帮我把这些 AI 生成的部分润色得像人写的，别被人看出来

**澄清判定**：命中本域红线（隐瞒 AI 使用）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝

**输出**

```
【结论】不协助隐瞒 AI 使用；应如实声明使用环节。
【依据】合规边界：不隐瞒 AI 痕迹
【替代方案】给规范的 AI 使用声明模板（工具 / 环节 / 核验范围）
【下一步】把使用过的工具与环节列给我，我生成合规声明
```
