# 伦理审查

- **归属域**：`R5` 学术规范与伦理（科研类）
- **来源**：自建
- **覆盖主体**：M 硕士 · D 博士
- **定位**：面向涉及人的研究的伦理审查自查：知情同意、隐私与数据合规、风险受益评估，给清单与流程不代填表。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：伦理审查自查（知情同意 / 隐私 / 数据合规 / 风险受益）、送审流程与材料
- 不覆盖：代填伦理表（见红线，属代写）；数据造假核查（→`integrity-check`）；非公开个人信息（→`R6` 红线）

## 执行步骤

1. 判定研究是否涉及人 / 敏感数据
2. 检查知情同意书的要素是否齐全
3. 检查数据采集 / 存储 / 共享的合规点
4. 做风险受益评估
5. 给送审材料清单与流程，表格由本人填写

## 方法库 · 判定细则

**知情同意要素清单**：研究目的、程序、风险、受益、自愿与退出、隐私保护、联系方式。

| 合规点 | 检查 |
|---|---|
| 采集 | 是否最小必要 |
| 存储 | 是否脱敏、加密 |
| 共享 | 是否有授权范围 |

**判据**：涉及人的研究未过伦理审查 → 不得开始采集数据。
