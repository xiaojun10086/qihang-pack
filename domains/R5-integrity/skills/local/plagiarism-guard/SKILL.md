# 查重前自检

- **归属域**：`R5` 学术规范与伦理（科研类）
- **来源**：自建
- **覆盖主体**：G 毕业年级本科生 · M 硕士
- **定位**：在提交查重前做自检：识别高相似段落、规范引用与合理改写，只给规范与自查方法，不代改以规避查重。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：查重前自检方法、高相似段落识别、规范引用与合理改写原则、常见误判
- 不覆盖：代改降重（见红线）；引文体例（→`S5` `cite-normalize`）；查重系统操作（→`F1` / `R6`）

## 执行步骤

1. 明确查重系统口径（连续字数 / 比对库）
2. 逐章自查高相似来源（自己引用 / 网络 / 拼接）
3. 对确属引用的加规范引用，对复述不足的给改写原则
4. 检查公式、图表题注、致谢等易漏区
5. 输出问题清单与规范做法，不代改

## 方法库 · 判定细则

**高相似来源分类**：

| 来源 | 规范处理 |
|---|---|
| 直接引用 | 加引号 + 标注出处 |
| 转述 | 彻底改写 + 标注 |
| 自己已发表 | 标注自引，按期刊规定 |
| 公共表述 | 公式、法条类一般不判重 |

**判据**：改造只走「规范引用 + 真正改写」，不走「换词、改语序」以规避。

**示例 1（正常命中）**

**输入**

> 论文要查重了，我怕重复率太高，想先自查一下

**澄清判定**：关键槽 `O/T/D` 齐全且不歧义 → 依 `clarity.md` §5 例外 2 放行

**输出**

```
【结论】按四类来源自查，引用加规范标注，转述彻底改写。
【依据】查重前自检：高相似来源分类
【结果】① 查直接引用 ② 查转述不足 ③ 查自引 ④ 查公式 / 题注区
       → 产出：问题清单 + 规范处理建议
【下一步】把疑似重复段落发我，逐处判类型给规范做法
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

**澄清判定**：命中红线（代改以规避查重）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝并给替代

**输出**

```
【结论】不代改以规避查重；只给引用与改写规范。
【依据】合规边界：不代改以规避查重
【替代方案】规范引用 + 合理改写原则
【下一步】把拟改段落发我，我教你如何规范转述
```
