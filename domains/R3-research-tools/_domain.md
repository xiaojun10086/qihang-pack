# R3 · 科研工具与代码

> 域 ID `R3` ｜ 所属大类 **科研类** ｜ 目录 `domains/R3-research-tools/`

## 域边界

- **覆盖**：科研编程环境、脚本编写、版本管理、仿真工具
- **不覆盖**：不做算法题训练（→S1）；抢课/自动提交脚本 → `F1`

## 触发词（命中任一即锁定本域）

`Python` ｜ `MATLAB` ｜ `仿真` ｜ `Git` ｜ `环境` ｜ `报错` ｜ `脚本` ｜ `代码` ｜ `依赖` ｜ `环境配置`

## 库内 skill（唯一通道，无需安装）

- **`tool-setup`** — 科研环境搭建（自建）
  先问清目标工具与系统，再给最小可用环境步骤；报错按「复现 → 最小化 → 假设 → 插桩验证 → 修复」处理。

- **`repro-env`** — 可复现环境（自建）
  固定依赖版本、随机种子与目录结构，产出可复现运行脚本，不代做课业代码。

- **`code-mentor`** — （改造自外部 MIT 最优解 + DUT 特化）
  使命驱动 + 最近发展区选题 + 检索练习，一课一得的编程私教

- **`git-workflow`** — 科研 Git 协作（自建）
  面向科研代码的 Git 协作规范：分支模型、提交信息、冲突处理与代码 / 数据分离，给命令与流程不代做课业代码。

- **`sim-tool`** — 仿真工具上手（自建）
  面向 MATLAB / COMSOL / 仿真类课程的上手路径：建模流程、参数化、网格与收敛判断，给学习路径与排错思路。
