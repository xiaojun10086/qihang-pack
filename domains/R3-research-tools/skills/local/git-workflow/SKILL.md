# 科研 Git 协作

- **归属域**：`R3` 科研工具与代码（科研类）
- **来源**：自建
- **覆盖主体**：U 在读本科 · M 硕士
- **定位**：面向科研代码的 Git 协作规范：分支模型、提交信息、冲突处理与代码 / 数据分离，给命令与流程不代做课业代码。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：科研 Git 分支模型、提交规范、冲突解决、数据与大文件处理、协作流程
- 不覆盖：代做课业代码（见红线）；环境搭建（→`tool-setup`）；编程教学（→`code-mentor`）

## 执行步骤

1. 判定场景（个人 / 小组 / 开源贡献）
2. 定分支模型（main / dev / feature）与提交信息规范
3. 给日常流转命令（pull / commit / push / merge）
4. 讲冲突定位与解决步骤
5. 处理数据与大文件（.gitignore / LFS 口径）

## 方法库 · 判定细则

| 场景 | 分支模型 |
|---|---|
| 个人 | main + 临时分支 |
| 小组 | main / dev / feature |
| 开源 | fork + PR |

**提交信息**：`类型(范围): 一句话`，如 `feat(train): 加入早停`。

**判据**：数据文件与代码同仓库 → 必须先加 `.gitignore` 或走 LFS，否则库会膨胀到不可用。
