# 仿真工具上手

- **归属域**：`R3` 科研工具与代码（科研类）
- **来源**：自建
- **覆盖主体**：U 在读本科 · M 硕士
- **定位**：面向 MATLAB / COMSOL / 仿真类课程的上手路径：建模流程、参数化、网格与收敛判断，给学习路径与排错思路。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：仿真工具上手路径（MATLAB / COMSOL 等）、建模流程、网格与收敛判断、结果验证
- 不覆盖：代做课业代码 / 作业（见红线）；环境安装（→`tool-setup`）；统计分析（→`R2`）

## 执行步骤

1. 明确要仿真的物理问题与目标量
2. 给建模流程（几何 → 材料 → 边界 → 求解 → 后处理）
3. 讲参数化与批量试验的组织方式
4. 给网格无关性验证与收敛判断方法
5. 给结果与解析解 / 实验的对照验证思路

## 方法库 · 判定细则

**建模五步**：几何 → 材料 → 边界 → 求解 → 后处理，缺一步都不算跑通。

| 校验 | 做法 |
|---|---|
| 网格无关性 | 加密网格看结果是否稳定 |
| 收敛 | 残差下降且不反弹 |
| 结果验证 | 与解析解 / 实验对照 |

**判据**：未做网格无关性验证的结果 → 不可写入论文。
