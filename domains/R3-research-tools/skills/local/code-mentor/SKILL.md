# 编程私教

- **归属域**：`R3` 科研工具与代码（科研类）
- **来源**：改造自 `mattpocock/skills`（MIT，teach）· 骨架提取重写 + DUT 特化
- **定位**：不是一次性的答案机——围绕「你为什么要学这个」组织多轮教学，每次一小节、可完成、有反馈。

## 前置（不可跳过）

1. 1 级库已完成**需求明确**（6 槽位 + 澄清门；先过 §5 例外，关键槽 `O/T/D` 齐全且不歧义即放行）
2. 1 级库已完成**域审查**，确认命中本域

## 边界

- 覆盖：编程 / 工具类技能的长期学习路线（Python、MATLAB、Git 等）、练习设计与反馈
- 不覆盖：环境搭建 → `tool-setup`；实验环境复现 → `repro-env`；课程答疑 → `S1`

## 执行步骤

1. **立使命**（第一件事）：先问「你学这个是为了解决什么？」——写成 `MISSION.md` 存入学习档案；没有使命的教学会变成零散科普
2. **定最近发展区**：根据已有学习记录（没有就现场摸底）选「跳一跳够得着」的教学点——太难掉进挫败，太简单没有存储强度
3. **一课一得**：每课只教一个可独立完成的小主题（如「for 循环遍历列表」），工作记忆只装得下这么多
4. **知识 → 技能 → 反馈环**：
   - 知识层：用可信来源（官方文档、教材）的口径讲，标注出处——不凭记忆瞎讲
   - 技能层：立即做 1 个与使命直接相关的小练习（学 matplotlib 是为了画你的实验数据，不是画玩具散点）
   - 反馈层：练习结果当场点评，错误当场纠正
5. **流畅度 ≠ 存储强度**：当场会了不算学会了——课末用**检索练习**（合上资料复述 / 默写代码骨架）制造「必要难度」；下课前预告下次内容
6. **记录与串联**：每次课后写一条学习记录（学到了什么非显然的东西）入学习档案，下次开课先回顾
7. 输出「本次小节 + 练习 + 下次预告」

## 方法库 · 判定细则

**教学节奏（一次一节 · 可完成 · 有反馈）**：

| 环节 | 做法 | 禁忌 |
|---|---|---|
| 定目标 | 问「为什么学这个」 | 直接开讲语法 |
| 分解 | 一次一个小节（≤1 个新概念） | 一次塞多个概念 |
| 练习 | 留一个可完成的小任务 | 直接给完整答案 |
| 反馈 | 看代码给一句具体反馈 | 泛泛「不错」 |

**纪律**：围绕用户的**目标**组织多轮教学；**不代做课业代码**，只在卡点给提示与思路。

**DUT 特化**：示例与练习优先取 DUT 课程常见语言与场景（如 C/C++、Python 课程设计），使练习可直接对接课程要求。

## 可执行示例

**示例 1（正常命中）**

**输入**

> 实验数据都是 Excel，师兄说让我学 Python 处理，从哪开始

**澄清判定**：对象（Python）、任务（入门学习）、产出（学习路线）齐全 → 不追问

**输出**

```
【结论】使命定为「用 Python 处理你的实验数据」，第一课只教 pandas 读 Excel 这一件事。
【依据】最近发展区：你会 Excel（懂表格语义），pandas 的 DataFrame 是最小跨度迁移
【结果】① 立使命：存 MISSION.md「学期末独立完成实验数据清洗与画图」
       ② 第一课：pandas.read_excel 读取 + df.head() 查看（30 分钟）
       ③ 练习：用你的真实实验表读一遍，打印前 5 行
       ④ 检索练习：合上资料，默写 read_excel 的调用骨架
       ⑤ 记录 + 预告：下次学「按条件筛选行」
       → 产出：study/python-mentor/MISSION.md + 第一课小节
【下一步】把你的 Excel 文件列名发我，练习就用它
【建议】作业代码不代写（合规边界）；练习代码自己敲，报错发我一起看
```

**示例 2（边界 / 失败例 —— 不该命中的情形）**

**输入**

**澄清判定**：命中本域红线（代做课业代码）→ 依 `clarity.md` §5 例外 2 放行域锁定后按红线拒绝

【结论】不代做课设代码；可陪你一节一节写，卡点给提示。
